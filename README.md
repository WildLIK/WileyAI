# WileyAI

Персональный русскоязычный AI-ассистент для Windows с локальными моделями, памятью, голосовым общением и 3D-аватаром на рабочем столе.

**Статус:** проектирование. В репозитории пока находятся исследование и план разработки; готового приложения и установщика ещё нет.

## Возможности, запланированные для первой версии

- Чат, история общения и загрузка документов.
- Настраиваемая личность и редактируемая долговременная память.
- Распознавание русской речи и озвучка ответов.
- Прямые команды Windows: открыть папку, файл, приложение или сайт.
- VRM-аватар с отдельным интерфейсом взаимодействия.
- Менеджер моделей: выбор, скачивание, импорт с диска и подключение внешних серверов.
- Независимая смена моделей общения, распознавания речи и озвучки с сохранением личности и памяти.
- Подключение облачных провайдеров через адаптеры.
- Профили производительности и загрузка компонентов по необходимости.

## Архитектура

Собственное компактное ядро WileyAI и три интерфейса с общим состоянием:

1. **Settings** — модели, голос, личность, память, команды и настройки ресурсов.
2. **Chat** — общение, документы и результаты действий.
3. **Avatar** — персонаж на рабочем столе и голосовое взаимодействие.

Типовые команды выполняются напрямую средствами Windows без обращения к большой языковой модели. Свободные формулировки обрабатываются выбранной моделью. Автоматизация действий внутри приложений будет добавляться по конкретным задачам.

Предварительный стек: Electron / TypeScript / React, Python, SQLite, Three.js / three-vrm. Движки локальных моделей и речи подключаются через адаптеры. Окончательный набор компонентов определяется после измерений качества и нагрузки.

## Данные и модели

Модели, ключи API, переписка, память и пользовательские документы не должны попадать в Git. Для локальных данных предусмотрены исключения в `.gitignore`; библиотека моделей сможет находиться за пределами репозитория.

Поддержка конкретной модели зависит от совместимости её архитектуры и формата с установленным адаптером. Лицензии моделей, голосов и VRM-ассетов учитываются отдельно.
