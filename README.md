# WileyAI

Персональный русскоязычный AI-ассистент для Windows с локальными моделями, памятью, голосовым общением и 3D-аватаром на рабочем столе.

**Статус: первый рабочий прототип v0.1.** Есть настольное приложение для запуска из исходников, адаптеры веб-поиска SearXNG и Brave Search. Готового установщика пока нет; внешние аккаунты требуют отдельной настройки.

## Возможности прототипа

- Раздельные чаты: создание, переименование, удаление, перенос в проекты; история и документы каждого чата.
- Проекты со своей памятью, заметками и задачами, независимыми от общей памяти.
- Компактная панель разговора и сворачиваемые боковые панели.
- Настраиваемая личность и долговременная память: предложения с подтверждением, источники, поиск, редактирование и закрепление.
- Распознавание русской речи, озвучка и непрерывный голосовой разговор.
- Прямые команды Windows: открыть папку, файл, приложение или сайт.
- VRM-аватар с отдельным интерфейсом взаимодействия.
- Менеджер моделей: выбор, скачивание, импорт с диска и подключение внешних серверов.
- Независимая смена моделей общения, распознавания речи и озвучки с сохранением личности и памяти.
- Подключение облачных провайдеров через адаптеры.
- Профили производительности и загрузка компонентов по необходимости.
- Локальные задачи, однократные напоминания, таймеры, будильники и заметки с редактированием.
- Создание задач и заметок русскими командами; уточнения, перенос, отмена и завершение недавней задачи в диалоге.
- Резервные копии и перенос данных: предпросмотр, восстановление и защитная копия перед заменой.
- Явный веб-поиск через SearXNG или Brave Search: поисковые выдержки, ссылки, время поиска и ответ с номерами источников.
- Раздел «Возможности» с фактическими статусами всех 14 направлений развития.

Модели разделены на три категории: **Мозг**, **Озвучка**, **Распознавание голоса**. Первый набор: Ollama / совместимый API, Silero / системные голоса Windows, faster-whisper tiny/base/small.

## Архитектура

Собственное компактное ядро WileyAI и три интерфейса с общим состоянием:

1. **Settings** — модели, голос, личность, память, команды и настройки ресурсов.
2. **Chat** — общение, документы и результаты действий.
3. **Avatar** — персонаж на рабочем столе и голосовое взаимодействие.

Типовые команды выполняются напрямую средствами Windows без обращения к большой языковой модели. Свободные формулировки обрабатываются выбранной моделью. Автоматизация действий внутри приложений будет добавляться по конкретным задачам.

Произвольные действия из ответа модели не исполняются автоматически: первые проверки выявили ошибки LLM в распознавании команд. Память сохраняется явной командой или после принятия предложения из разговора. Для открытия своих файлов и приложений добавьте названия и пути в разделе «Команды».

Предварительный стек: Electron / TypeScript / React, Python, SQLite, Three.js / three-vrm. Движки локальных моделей и речи подключаются через адаптеры. Окончательный набор компонентов определяется после измерений качества и нагрузки.

## Данные и модели

Модели, ключи API, переписка, память и пользовательские документы не должны попадать в Git. Для локальных данных предусмотрены исключения в `.gitignore`; библиотека моделей сможет находиться за пределами репозитория.

Поддержка конкретной модели зависит от совместимости её архитектуры и формата с установленным адаптером. Лицензии моделей, голосов и VRM-ассетов учитываются отдельно.

## Запуск

Нужны Windows, Node.js 24, npm, Python 3.12 и [uv](https://docs.astral.sh/uv/).

```powershell
npm ci
uv sync --extra dev --extra voice --extra tts
npm run build
npm start
```

После подготовки можно запускать `WileyAI.cmd` двойным щелчком. Для разработки: `npm run dev`.

После обновления исходников выполните `npm run build`, полностью завершите старый WileyAI через **«Выйти из WileyAI»** или **«Выйти»** в трее и запустите снова. Крестик скрывает окно в трей; повторный запуск при работающем экземпляре показывает его прежний интерфейс.

Укажите сервер в настройках или установите необязательный переносной Ollama:

```powershell
.\scripts\setup-ollama.ps1
```

Скрипт скачивает официальный архив и проверяет опубликованный SHA-256. WileyAI запускает переносной сервер, если на `127.0.0.1:11434` ещё нет Ollama. Служба Windows и системный PATH не изменяются; уже запущенный внешний сервер приложение не останавливает.

В категории «Мозг» скачайте модель через Ollama или задайте имя и импортируйте текстовый GGUF. При импорте движок создаёт свою копию, исходный файл сохраняется. Если текущий DNS/VPN мешает загрузке через Ollama, используйте импорт GGUF из доверенного источника. Сетевые проверки движка не отключаются.

В категориях «Озвучка» и «Распознавание голоса» скачайте Silero и выбранный Whisper. Системная озвучка доступна без весов Silero, но установленного русского голоса Windows может не быть. После записи распознанный текст можно исправить перед отправкой.

В **«Настройки → Устройства звука»** выберите **«Микрофон»** и **«Динамик / наушники»**, затем нажмите **«Сохранить»**. Выбор применяется в чате и аватаре, при ручной записи и непрерывном разговоре; динамик используется и Silero, и системными голосами Windows. «По умолчанию Windows» следует системному выбору. Сохранённое отключённое устройство нужно подключить или заменить в настройках.

**«Проверить микрофон»** на срок до 7 секунд показывает уровень сигнала: речь не записывается в файл и не отправляется модели. Названия устройств могут открыться после первого доступа к микрофону. **«Проверить динамик»** воспроизводит короткий сигнал в выбранном выходе. Список обновляется при подключении устройств; есть ручная кнопка обновления.

### Разговор голосом

Нажмите **«Начать разговор»** в верхней строке чата или окне аватара. WileyAI подготовит выбранные модели, включит микрофон и будет автоматически отправлять реплики после паузы. Ответ прозвучит вслух, затем прослушивание продолжится. Можно обсуждать обычные темы, рассказывать о своём дне и задавать уточняющие вопросы: используются история выбранного чата, личность и память его пространства. В этом режиме ответы по умолчанию короче и без сложного форматирования.

В настройках регулируются пауза конца реплики (по умолчанию 1 секунда) и порог громкости. Одна запись ограничена 25 секундами. Выделение реплики по громкости работает локально; затем Whisper дополнительно фильтрует участки без речи. Это ещё не определение смыслового конца предложения.

Во время распознавания, подготовки ответа и озвучки входящий звук отбрасывается, чтобы ассистент не отвечал самому себе. Чтобы перебить ответ, нажмите **«Перебить»**. Одновременный разговор с голосовым перебиванием пока не реализован. Выход: **«Завершить разговор»**, фраза «заверши разговор» в момент прослушивания или `Ctrl + Shift + Esc`. Завершение останавливает дорожки микрофона; при следующем запуске программы разговор сам не включается. Один сеанс действует на все окна приложения.

Для персонажа выберите свой VRM 0.x / 1.0 до 64 МБ со встроенными текстурами. Сторонние аватары не включены в репозиторий. Анимация рта пока управляется состоянием озвучки, а не точными фонемами.

- `Ctrl + Shift + Space` — открыть чат.
- `Ctrl + Shift + Esc` — завершить разговор, остановить ответ и озвучку, вернуть клики аватару.
- «Выйти» в интерфейсе или трее — полностью завершить приложение.

### Чаты, проекты и рабочее окно

В левой панели есть **«＋ Новый чат»**, **«＋ Проект»** и поиск по названиям чатов. Кнопка **«⋯»** возле чата открывает переименование, выбор проекта и удаление. Внутри проекта можно создать ещё один чат. В меню проекта доступны переименование и удаление.

У каждого чата своя история, документы и контекст уточнений задач. Общие чаты используют общую память, заметки и задачи. Чаты одного проекта используют память, заметки и задачи этого проекта; общая память и история других чатов в запрос модели не добавляются. Имя, характер ассистента, модели, голос, устройства и команды Windows остаются общими для приложения. Текущее пространство памяти подписано под названием чата и в разделе «Память».

При переносе чата в проект или обратно вместе с ним переходят история и файлы, включая уже написанные в переписке сведения. Подтверждённые факты, заметки и задачи остаются в прежнем пространстве; ссылки на перенесённые сообщения у фактов очищаются. Предложения памяти из этого чата и контекст уточнений сбрасываются. Удаление чата убирает его историю, документы и предложения, сохраняя подтверждённую память, заметки и задачи пространства. Удаление проекта после подтверждения удаляет все его чаты и собственные данные; общая память сохраняется.

Старая история при обновлении становится чатом **«Переписка до обновления»**. Выбор чата сохраняется после перезапуска. Несохранённый текст остаётся в своём чате при переключении в текущем окне; после полного выхода он не восстанавливается.

Кнопка **«☰»** вверху сворачивает левую панель до значков. Кнопка панели ассистента вверху справа и крестик внутри неё скрывают правую панель; выбор сохраняется после перезапуска. Приветствие показывается только в пустом чате, управление голосом находится в компактной строке над перепиской. Во время ответа или разговора сначала остановите текущий сеанс, затем переключайте чаты.

### Задачи и заметки в разговоре

Эти команды работают в чате и после распознавания голоса, без запроса к LLM:

- «Напомни завтра в 10 купить хлеб» → «Перенеси на 11».
- «Напомни позвонить» → Уайли уточнит время → «через пятнадцать минут».
- «Поставь таймер на 5 минут» или «поставь таймер на 1 час 30 минут».
- «Поставь будильник на 7:15».
- «Добавь задачу проверить сборку» → «отметь задачу выполненной».
- «Отмени это напоминание», «отмени таймер», «покажи задачи».
- «Создай заметку Покупки: хлеб и молоко».

Поддерживаются «сегодня», «завтра», «послезавтра», дни недели, даты ДД.ММ.ГГГГ, часы цифрами и русскими числительными, интервалы в секундах, минутах и часах. Если указано только время суток, выбирается ближайшее будущее такое время; явная прошедшая дата отклоняется. Ответ показывает полную дату, время и смещение UTC. Часовой пояс поступает из интерфейса компьютера, срок хранится в UTC.

«Перенеси на 11» сохраняет дату недавней задачи. «Перенеси на 15 минут позже» сдвигает её прежний срок, «перенеси через 15 минут» задаёт срок от текущего момента. Уточнения и ссылка на недавнюю задачу сохраняются после перезапуска в течение 15 минут; другой часовой пояс сбрасывает этот контекст. Если время или название не указано, напоминание ещё не создаётся. «Отмена» прекращает уточнение, «отмени это напоминание» удаляет недавнюю запись. При нескольких старых задачах выберите нужную в разделе «Задачи».

Это ограниченный локальный набор правил, а не распознавание любых формулировок. Повторения и произвольные цепочки действий пока не выполняются. Планировщик проверяет сроки каждые 5 секунд, поэтому короткий таймер не является точным секундомером.

### Память и предпочтения

Скажите или напишите «Я предпочитаю короткие ответы», «Мне удобнее примеры на Python» или «Мой проект называется Альтаир». В чате и разделе **«Память»** появится предложение с исходной репликой. Его можно исправить, выбрать категорию и принять отдельной записью или заменить старую. До принятия оно не становится постоянной памятью; исходная реплика остаётся в обычной истории разговора.

**«Запомни: я предпочитаю короткие ответы»** и ручное добавление в разделе «Память» сохраняют факт сразу. У подтверждённых записей есть редактирование, удаление, закрепление и поиск по словам или их началу. В ответе можно раскрыть **«Передано в контекст из памяти»**, чтобы увидеть записи, переданные модели; это не доказывает, что модель использовала каждую из них. После исправления или удаления записи её прежняя ссылка скрывается из старых ответов, сам текст переписки сохраняется.

Предложения создаются локальными правилами для ограниченного набора прямых высказываний от первого лица. Дополнительные запросы к нейросети не выполняются. Повторные и отклонённые предложения не засоряют список. В **«Настройки»** можно выключить **«Предлагать память из разговоров»**. Это накопление проверенной памяти, а не дообучение весов модели; автоматического понимания любых привычек и семантического поиска пока нет.

### Поиск в интернете

В **«Настройки → Поиск в интернете»** выберите сервис, настройте подключение, включите **«Разрешить веб-поиск по моей команде»** и сохраните настройки. По умолчанию поиск выключен. Доступны два адаптера:

- **SearXNG**: базовый адрес своего сервера, например `http://127.0.0.1:8080`. Для удалённого адреса нужен HTTPS. На сервере должен быть включён формат `json` в `search.formats`; многие публичные серверы его запрещают. Это описано в [официальном Search API SearXNG](https://docs.searxng.org/dev/search_api.html). Локальный SearXNG всё равно обращается к внешним поисковым системам; сервер не устанавливается автоматически.
- **Brave Search**: отдельный ключ из своего аккаунта [Brave Search API](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started). Он хранится в Windows отдельно от ключа модели; в базу и резервные копии не попадает. Лимиты и стоимость определяются аккаунтом провайдера. Отдельный запрос проверки подключения автоматически не отправляется.

Запуск: **«Найди в интернете новости о…»**, **«Поищи в сети…»** или кнопка **«Поиск»** перед отправкой обычного текста. Кнопка действует на одно сообщение. Команды работают и после распознавания голоса. Обычные разговоры не запускают поиск в фоне. Настройка фильтра результатов передаётся выбранному сервису.

В поисковый сервис уходит текст этого запроса (у команды убирается начальная фраза «найди в интернете»). История, память и документы автоматически к запросу не добавляются. Если вы сами написали личные сведения в поисковом запросе, они отправятся сервису. Выдержки передаются выбранной модели, которая также получает обычный контекст чата и выбранные документы согласно своим настройкам.

Под ответом есть карточка **«Источники»**: запрос, сервис, время поиска, заголовки, адреса и короткие выдержки. Номера `[1]`, `[2]` в ответе соответствуют порядку источников; корректность их использования зависит от модели. Источник открывается в системном браузере только по нажатию. Данные сохраняются вместе с ответом, переживают перезапуск и входят в резервную копию. Это снимок поисковой выдачи на указанное время, а не дата публикации и не автоматическая перепроверка старого ответа.

При ошибке поиска или пустой выдаче WileyAI сообщает об этом, не выдавая ответ модели за свежую проверку. Если поиск успешен, но модель недоступна, источники остаются доступны. **«Остановить ответ»** прерывает ожидающий сетевой запрос. После восстановления подключений из копии поиск выключается до повторного разрешения.

Пока используются до пяти результатов и только поисковые выдержки: полные страницы не загружаются. Это не отдельный достоверный источник точной погоды, курсов валют или пробок; для них нужны специальные адаптеры. Содержимое выдачи не исполняет команды и не становится постоянной памятью автоматически.

### Резервные копии и перенос

Внизу **«Настройки»** есть карточка **«Резервные копии и перенос»**. **«Сохранить резервную копию»** открывает системный диалог сохранения файла `.wileyai.json`. В копию входят сохранённые настройки, личность, проекты и чаты, вся переписка, память с источниками и предложениями, результаты веб-поиска, заметки, задачи, состояние уведомлений, команды и извлечённый текст загруженных документов. Принадлежность к чатам и проектам сохраняется. Это согласованный снимок данных, включая записи за пределами последних сообщений, видимых в интерфейсе.

**«Выбрать копию для восстановления»** сначала проверяет файл и показывает состав текущих данных и копии. Для замены нужно отметить подтверждение и нажать **«Восстановить данные»**. Имя, характер и настройка предложений памяти восстанавливаются вместе с данными. Подключение, модели, голос, устройства, путь к аватару и команды текущего ПК сохраняются, пока вы отдельно не включите соответствующие опции. Ключи из хранилища Windows не экспортируются и не перезаписываются. На другом ПК их нужно настроить отдельно.

Перед заменой автоматически сохраняется защитная копия в `data/backups/` (или в `backups/` внутри выбранного каталога данных). Её путь показывается в карточке; для возврата выберите этот файл как обычную копию. Если нужно вернуть также настройки подключения и команды, включите обе опции. При ошибке записи базы изменения откатываются. Если данные изменились после предпросмотра, нужно выбрать копию заново: новые сообщения или задачи не будут молча затёрты. После восстановления несохранённые черновики во всех окнах сбрасываются; перед переносом сохраните нужные изменения.

Файл копии не зашифрован и содержит личные данные. Веса моделей, VRM, оригиналы документов, ключи из системного хранилища и журнал действий в него не входят. Импорт ничего не открывает и не запускает команды. Просроченные недоставленные напоминания после восстановления могут сработать сразу; уже доставленные не ставятся повторно. Временный черновик диалога задач сбрасывается.

Новые копии используют версию формата 2; прежняя версия 1 читается с переносом истории в один общий чат. Лимиты: до 64 МБ и 200 тысяч записей в сумме. При превышении лимитов файл не обрезается. Копии сохраняются вручную; автоматического расписания, шифрования, объединения двух историй и автоматической очистки защитных копий пока нет.

## Границы версии

Календарь, почта, звонки, мессенджеры, специальные сервисы погоды/курсов/пробок, умный дом, медиа/громкость/яркость/радиомодули, камера и чтение экрана пока представлены требованиями и контрактом интеграций. Произвольные многошаговые сценарии, извлечение любых фактов из текста, embeddings, OCR, голосовая аутентификация, пароль и шифрование базы ещё не реализованы. API-ключи хранятся в системном хранилище Windows; SQLite истории и памяти пока не зашифрована.

Напоминания работают при запущенном WileyAI, включая трей; пропущенные срабатывают после запуска. Повторения пока не поддерживаются. Для документов доступны TXT/MD/CSV, PDF с текстом и DOCX, до 15 МБ; ответ использует выбранные фрагменты, без OCR. Импортированный текстовый GGUF без визуального проектора не получает зрение автоматически.

## Проверки

```powershell
npm run check
npm run test:desktop
```

Обычные тесты не скачивают модели и не открывают пользовательские приложения. Для опциональной проверки настоящего Ollama и выбранного VRM:

```powershell
$env:WILEYAI_LIVE_TESTS = '1'
$env:WILEYAI_VRM_TEST_PATH = 'D:\avatars\character.vrm'
npm run test:desktop
.\.venv\Scripts\python.exe -m pytest tests/test_live_voice.py
.\.venv\Scripts\python.exe -m pytest tests/test_live_memory.py
.\.venv\Scripts\python.exe -m pytest tests/test_live_websearch.py
```

`test_live_voice.py` требует также установленных Whisper small и Silero и проверяет полный голосовой маршрут на синтезированной речи, без записи микрофона и воспроизведения в колонках. `test_live_memory.py` проверяет ответ настоящей Qwen по старому факту среди более сотни записей. `test_live_websearch.py` проверяет ответ настоящей Qwen с номером источника по данным контролируемого локального поискового сервера; внешние поисковые аккаунты и платные запросы не используются. Проверки используют временную историю и не меняют пользовательские данные.
