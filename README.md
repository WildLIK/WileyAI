# WileyAI

Персональный русскоязычный AI-ассистент для Windows с локальными моделями, памятью, голосовым общением и 3D-аватаром на рабочем столе.

**Статус: прототип v0.8.0.** Самостоятельный установщик Windows x64 со встроенным ядром и Python, мастер первого запуска, загрузка дополнительных компонентов из интерфейса и уведомления о новых выпусках GitHub. Есть [четыре темы и анимированные состояния процессов](docs/appearance.ru.md): стеклянные панели, светло-голубая и чёрно-красная палитры, живая «Туманность», настройка движения и прозрачности. Внешние аккаунты требуют отдельной настройки. [Что уже есть и что ещё предстоит](docs/roadmap.ru.md).

В 0.8 добавлено [сканирование знакомых приложений](docs/applications.ru.md) по шести категориям с добавлением в команды. Исправлены просьбы «открой мне сайт YouTube/GitHub», «прибавь громкости» и сдвиги чата при разговоре. «Включи музыку» открывает добавленный проигрыватель или предлагает выбрать источник; состояние воспроизведения трека пока не проверяется.

## Установка готовой программы

Скачайте `WileyAI-Setup-0.8.0-x64.exe` из [выпусков](https://github.com/WildLIK/WileyAI/releases) и запустите. Python и Node.js устанавливать не нужно. [Мастер первого запуска](docs/setup.ru.md) проведёт через подключение мозга, установку компонентов и настройку звука. Его можно отложить или открыть повторно в **Настройки → Данные и копии**. Все модели также доступны в категориях «Мозг», «Озвучка», «Распознавание голоса». Для облачных API локальные движки не нужны. Данные сохраняются отдельно от программы.

Репозиторий закрытый: другому человеку можно передать сам установщик; для скачивания и проверки обновлений через GitHub ему нужен доступ к проекту. [Подробная инструкция, ограничения и сборка](docs/distribution.ru.md).

## Возможности прототипа

- Раздельные чаты: создание, переименование, удаление, перенос в проекты; история и документы каждого чата.
- Проекты со своей памятью, заметками, задачами и календарём, независимыми от общих данных.
- Компактная панель разговора и сворачиваемые боковые панели.
- Библиотека документов: локальный поиск по названию и содержимому, просмотр текста, явный выбор для вопроса и отдельные копии проекта для его чатов.
- Источники документов под ответом: точные отрывки, имена файлов и диапазоны, сохранённые с перепиской.
- Настраиваемая личность и долговременная память: предложения с подтверждением, источники, поиск, редактирование и закрепление.
- Локальный поиск по переписке: чат, проект или все чаты, фильтр автора и переход к старому сообщению с выделением совпадения.
- Распознавание русской речи, озвучка и непрерывный голосовой разговор.
- Прямые команды Windows: открыть папку, файл, приложение или сайт.
- [Поиск известных установленных приложений](docs/applications.ru.md): музыка, видео, графика и работа, мессенджеры, браузеры, программы Windows; импорт без перезаписи существующих имён и русские названия для запуска.
- Свободные команды открытия: подбор вариантов из каталога выбранной моделью и уточнение выбором в разговоре.
- Сохранённые сценарии запуска до 12 открытий, редактор порядка шагов и отдельный доступ к файлам, приложениям и сайтам.
- VRM-аватар с отдельным интерфейсом взаимодействия.
- Менеджер моделей: выбор, скачивание, импорт с диска и подключение внешних серверов.
- Независимая смена моделей общения, распознавания речи и озвучки с сохранением личности и памяти.
- Подключение облачных провайдеров через адаптеры.
- Профили производительности и загрузка компонентов по необходимости.
- Локальные задачи, однократные и [повторяющиеся напоминания](docs/reminders.ru.md), таймеры, будильники и заметки с редактированием.
- [Выбор старых задач по названию и сроку](docs/task-selection.ru.md), уточнение номером, перенос/удаление/завершение в диалоге и проверка изменений из другого окна.
- Создание задач и заметок русскими командами; уточнения, перенос, отмена и завершение недавней задачи в диалоге.
- Локальный календарь: события, расписание на неделю, пересечения, связанные напоминания, создание и перенос встреч из чата и голосом.
- Резервные копии и перенос данных: предпросмотр, восстановление и защитная копия перед заменой.
- Явный веб-поиск через SearXNG или Brave Search: поисковые выдержки, ссылки, время поиска и ответ с номерами источников.
- Раздел «Возможности» с фактическими статусами всех 14 направлений развития.

Модели разделены на три категории: **Мозг**, **Озвучка**, **Распознавание голоса**. Первый набор: Ollama / совместимый API, Silero 5/5.6 / Piper / OpenVoice поверх локального TTS / системные голоса Windows, faster-whisper tiny/base/small. Облачная озвучка подключается отдельно через OpenRouter, RouterAI или совместимый API: готовые варианты Fish Free, Gemini TTS и Grok Voice находятся в настройках речи.

Монитор нагрузки доступен в разделе **«Нагрузка»** и по индикатору CPU / ОЗУ в шапке. Он показывает процессы программы, модели, работу и простой, выделенную память Windows и NVIDIA GPU.

Настройки разделены на категории: личность, мозг, озвучка, микрофон и разговор, поиск, аватар, данные и копии. Черновики сохраняются при переходах между категориями; кнопка «Сохранить» закреплена сверху. Голос и движок, как и прежде, сохраняются сразу.

В **Настройки → Микрофон и разговор → Память моделей речи** можно настроить автоматическую выгрузку Whisper, Silero и Piper: через 1, 5 или 15 минут простоя, по профилю производительности либо оставить их загруженными. По профилю сроки — 1 минута для экономичного, 5 для сбалансированного и 15 для максимального качества. Простой считается отдельно для распознавания и каждого движка озвучки; первое обращение после выгрузки требует повторной загрузки. Сохраните выбор кнопкой «Сохранить». Временные процессы Qwen/OpenVoice завершаются по жизненному циклу сессии озвучки. Подробнее — [управление памятью речи](docs/voice-resources.ru.md).

Кнопка **«Освободить память речи»** выгружает Whisper, Piper/Silero и простаивающие процессы Qwen/OpenVoice. Следующее обращение загружает модели снова. Текущие распознавание и синтез защищены от выгрузки; веса, история и выбор голосов остаются на месте. Размер возвращённой ОС памяти зависит от нативных библиотек; интерфейс сообщает список выгруженных моделей без обещания конкретного числа мегабайт.

## Архитектура

Собственное компактное ядро WileyAI и три интерфейса с общим состоянием:

1. **Settings** — модели, голос, личность, память, команды и настройки ресурсов.
2. **Chat** — общение, документы и результаты действий.
3. **Avatar** — персонаж на рабочем столе и голосовое взаимодействие.

Типовые команды выполняются напрямую средствами Windows без обращения к большой языковой модели. Свободные формулировки обрабатываются выбранной моделью. Автоматизация действий внутри приложений будет добавляться по конкретным задачам.

Произвольные действия из ответа модели не исполняются автоматически: первые проверки выявили ошибки LLM в распознавании команд. Память сохраняется явной командой или после принятия предложения из разговора. Для открытия своих файлов и приложений добавьте названия и пути в разделе «Команды».

Предварительный стек: Electron / TypeScript / React, Python, SQLite, Three.js / three-vrm. Движки локальных моделей и речи подключаются через адаптеры. Окончательный набор компонентов определяется после измерений качества и нагрузки.

## Данные и модели

Модели, ключи API, переписка, память и пользовательские документы не должны попадать в Git. Для локальных данных предусмотрены исключения в `.gitignore`; библиотека моделей сможет находиться за пределами репозитория.

Поддержка конкретной модели зависит от совместимости её архитектуры и формата с установленным адаптером. Лицензии моделей, голосов и VRM-ассетов учитываются отдельно.

## Запуск

Нужны Windows, Node.js 24, npm, Python 3.12 и [uv](https://docs.astral.sh/uv/).

```powershell
npm ci
uv sync --extra dev --extra voice --extra tts
npm run build
npm start
```

После подготовки можно запускать `WileyAI.cmd` двойным щелчком. Для разработки: `npm run dev`.

После обновления исходников выполните `npm run build`, полностью завершите старый WileyAI через **«Выйти из WileyAI»** или **«Выйти»** в трее и запустите снова. Крестик скрывает окно в трей; повторный запуск при работающем экземпляре показывает его прежний интерфейс.

Укажите сервер в настройках или установите необязательный переносной Ollama:

```powershell
.\scripts\setup-ollama.ps1
```

Скрипт скачивает официальный архив и проверяет опубликованный SHA-256. WileyAI запускает переносной сервер, если на `127.0.0.1:11434` ещё нет Ollama. Служба Windows и системный PATH не изменяются; уже запущенный внешний сервер приложение не останавливает.

В категории «Мозг» скачайте модель через Ollama или задайте имя и импортируйте текстовый GGUF. При импорте движок создаёт свою копию, исходный файл сохраняется. Если текущий DNS/VPN мешает загрузке через Ollama, используйте импорт GGUF из доверенного источника. Сетевые проверки движка не отключаются.

В категориях «Озвучка» и «Распознавание голоса» скачайте Silero и выбранный Whisper. Системная озвучка доступна без весов Silero, но установленного русского голоса Windows может не быть. После записи распознанный текст можно исправить перед отправкой.

В **«Настройки → Устройства звука»** выберите **«Микрофон»** и **«Динамик / наушники»**, затем нажмите **«Сохранить»**. Выбор применяется в чате и аватаре, при ручной записи и непрерывном разговоре; динамик используется и Silero, и системными голосами Windows. «По умолчанию Windows» следует системному выбору. Сохранённое отключённое устройство нужно подключить или заменить в настройках.

**«Проверить микрофон»** на срок до 7 секунд показывает уровень сигнала: речь не записывается в файл и не отправляется модели. Названия устройств могут открыться после первого доступа к микрофону. **«Проверить динамик»** воспроизводит короткий сигнал в выбранном выходе. Список обновляется при подключении устройств; есть ручная кнопка обновления.

### Длина ответа и род речи

В «Настройки → Подключение модели» задаётся **максимальная длина ответа**: по умолчанию 2048 токенов вместо прежних 768. Для ответа резервируется до половины выбранного контекста; размер самого контекста автоматически не растёт. Системные инструкции сокращены, чтобы оставить место для текста и документов. Если сервер сообщает о достижении лимита или обрывает поток, полученная часть сохраняется с пояснением. **«Продолжить ответ»** выполняет следующий запрос только по нажатию владельца, с сохранением конца предыдущего ответа в контексте. При длинной истории старые реплики передаются фрагментами; это не безграничный контекст. [Описание завершения ответа Ollama](https://docs.ollama.com/api/chat).

В «Настройки → Личность» доступен **род речи персонажа**: женский (по умолчанию), мужской или без указания рода. Он не зависит от тембра TTS и входит в инструкции каждой новой реплики; фиксированные ответы локальных команд тоже учитывают выбор. Старые сообщения не переписываются. Имена файлов с буквами и цифрами подготавливаются отдельно для TTS: например, «Пс2.docx» читается как «пэ эс два точка докс», а не теряет цифру и расширение. Текст на экране сохраняется.

### Разговор голосом

Нажмите **«Начать разговор»** в верхней строке чата или окне аватара. WileyAI подготовит выбранные модели, включит микрофон и будет автоматически отправлять реплики после паузы. Ответ прозвучит вслух, затем прослушивание продолжится. Можно обсуждать обычные темы, рассказывать о своём дне и задавать уточняющие вопросы: используются история выбранного чата, личность и память его пространства. В этом режиме ответы по умолчанию короче и без сложного форматирования.

В настройках регулируются пауза конца реплики (по умолчанию 1 секунда) и порог громкости. Одна запись ограничена 25 секундами. Выделение реплики по громкости работает локально; затем Whisper дополнительно фильтрует участки без речи. Это ещё не определение смыслового конца предложения.

Во время распознавания, подготовки ответа и озвучки входящий звук отбрасывается, чтобы ассистент не отвечал самому себе. Чтобы перебить ответ, нажмите **«Перебить»**, **«Остановить озвучку»** или **Escape**. Кнопка остановки появляется уже при подготовке звука и работает также для прослушивания голоса в настройках, чтения сообщения и из окна аватара. В режиме разговора прерывается текущая реплика, затем снова включается прослушивание. В других приложениях доступна глобальная клавиша `Ctrl + Shift + Esc`, которая завершает весь разговор. Одновременный разговор с голосовым перебиванием пока не реализован. Выход: **«Завершить разговор»** или фраза «заверши разговор» в момент прослушивания. Завершение останавливает дорожки микрофона; при следующем запуске программы разговор сам не включается. Один сеанс действует на все окна приложения.

### Дополнительные голоса

В **«Модели → Озвучка»** можно скачать **Silero 5.6** и отдельные голоса **Piper: Ирина, Денис, Дмитрий**. Для Piper установите модуль и перезапустите приложение:

```powershell
uv sync --extra dev --extra voice --extra tts --extra piper
```

Выберите движок и голос в **«Настройки → Озвучка»** и нажмите **«Прослушать голос»**. Движок, голос, устройство Qwen и переключатель автоматической озвучки сохраняются сразу, без общей кнопки «Сохранить». Прослушивание, чат и голосовой разговор используют один выбор. В действующем разговоре новый голос применяется со следующей реплики. Остальные настройки сохраняются общей кнопкой; обновление чата не стирает их черновик. Для женского тембра сравните **Silero 5.6 → Бая / Ксения** и **Piper → Ирина**. Все эти варианты синтезируют речь локально на CPU; качество и тембр лучше оценить на своих фразах. Silero 5.6 добавляет поддержку интонаций вопросов и восклицаний ([описание моделей](https://github.com/snakers4/silero-models#v5)).

Перед озвучкой Markdown преобразуется в обычный текст: убираются звёздочки выделения, маркеры списков, заголовков и кодовых блоков; у ссылок читается подпись. Исходное сообщение в чате и истории сохраняется. Это предотвращает ошибку Silero 5.6 «Некорректная разметка эмфазы», когда `**целая фраза**` из ответа ошибочно принималась за команду выделить одно слово голосом. Подготовка действует для всех движков и до разбиения текста на короткие фрагменты. Границы предложений учитываются при разбиении; очень длинные предложения всё ещё делятся по словам.

Проверка WAV и распознавание Whisper не подтверждают естественность тембра и отсутствие слышимого шума. Шум Баи и роботизированное звучание отдельных голосов остаются ограничениями текущего набора; фильтрация, гарантирующая улучшение на устройствах пользователя, пока не проверена.

Голоса Piper скачиваются с фиксированной версии официального каталога, ONNX и конфигурация проверяются SHA-256 и устанавливаются вместе. Silero 5.6 также проверяется SHA-256. Лицензия движка Piper — GPL-3.0; условия датасетов показаны в каталоге: CC0 у Дениса/Дмитрия, у Ирины в MODEL_CARD лицензия не указана. Silero — CC BY-NC 4.0. Веса остаются в `data/models` и не включаются в Git или резервные копии.

Отмена немедленно ставит воспроизведение на паузу и освобождает его источник. Отдельный ID запроса предотвращает остановку новой озвучки поздней отменой старой. Синтез проверяет отмену между короткими фрагментами; уже начатое вычисление одного фрагмента на CPU может завершиться, но его результат не воспроизводится и следующие фрагменты не запускаются.

### Освобождение моделей при завершении

Ядро и запускаемый WileyAI переносной Ollama на Windows работают под защитой Job Object. При выходе или аварийном закрытии окна приложения завершается всё принадлежащее ему дерево процессов, включая рабочие процессы моделей. Уже работающий внешний сервер Ollama сохраняется. Такое владение деревом поддерживается [Windows Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects).

Во время проверки обнаружены и завершены четыре старых процесса переносной модели из каталога WileyAI без родительского процесса и активных соединений. Они занимали около 19 ГБ выделенной памяти Windows и приводили к ошибке 1455 даже после закрытия окон. После очистки настоящая Serena снова синтезировала речь на CPU. Для проверки защиты используются отдельные тестовые процессы, а не пользовательские модели.

### Экспериментальная озвучка Qwen3-TTS

Добавлен [Qwen3-TTS 0.6B CustomVoice](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice) с девятью готовыми тембрами. По [описанию автора](https://github.com/QwenLM/Qwen3-TTS) Serena — мягкий женский голос; также доступны Vivian, Anna, Sohee и мужские варианты. Русский поддерживается, но готовые тембры не являются русскими по происхождению и могут звучать с акцентом. Это кандидат для сравнения на слух, а не гарантия лучшего качества.

1. `npm run setup:qwen` устанавливает отдельное окружение в `local/qwen-tts/.venv`: Qwen-TTS 0.1.1, PyTorch/Torchaudio 2.9.1 с CUDA 12.8. Основное Python-окружение WileyAI остаётся прежним. Для установки только CPU выполните `powershell -NoProfile -File scripts/setup-qwen.ps1 -Backend cpu`. CUDA-вариант тоже работает на CPU.
2. В **«Модели → Озвучка»** скачайте **Qwen3-TTS 0.6B**: около 2,5 ГБ весов и токенизатора. Файлы закреплены на конкретной ревизии и проверяются по размерам и SHA-256; завершённые файлы повторной загрузки не требуют. Установочный движок занимает дополнительное место.
3. В **«Настройки → Озвучка»** выберите Qwen3-TTS, Serena и устройство. **CPU** работает без свободной видеопамяти, но медленнее. **CUDA** требует NVIDIA и минимум 3,5 ГБ свободной видеопамяти перед загрузкой; это начальная проверка, без гарантии достаточности для любого текста. **Автоматически** выбирает CUDA, если она доступна и хватает свободной памяти; иначе использует CPU. После подготовки приложение сообщает фактически использованное устройство. При явном выборе CUDA нехватка памяти остаётся ошибкой, без смены устройства.
4. Прослушайте голос. Выбор сохраняется автоматически. Движок работает локально, с отключёнными сетевыми загрузками во время синтеза. Выбранные LLM и Whisper остаются независимыми от озвучки.

Ответ читается по мере появления законченных фраз, без ожидания всего текста. Подготовка следующего аудиофрагмента может идти во время воспроизведения предыдущего; одновременно хранится не более одного подготовленного фрагмента. В Qwen один скрытый процесс и загруженная модель используются для всех фраз ответа. По завершении воспроизведения или остановке процесс закрывается; при потере окна/соединения без запроса закрытия действует таймаут простоя 30 секунд. Остановка отменяет текущий синтез, воспроизведение и оставшуюся очередь, поздние фразы ответа не запускают её снова. Для Windows-кода аварии 0xC0000005 предусмотрен один повтор запуска той же модели и голоса; повторная ошибка показывается владельцу, перехода на Silero нет.

Генерация проверена на CPU, включая создание WAV и остановку настоящего рабочего процесса; физические микрофон/динамики при тестировании не используются. Скорость и качество на GPU ещё требуют проверки при достаточном объёме свободной видеопамяти. Создание голоса по описанию и клонирование требуют других вариантов Qwen3-TTS и пока не подключены.

При неожиданном завершении Qwen показывается код выхода, а технические подробности сохраняются в `logs/qwen-error.json` внутри папки данных (обычно `data/logs/qwen-error.json`). Ошибка Windows 1455 означает недостаток памяти с учётом файла подкачки: освободите ресурсы и повторите озвучку. Выбранный движок автоматически не меняется. Аудиозапись и исходный текст туда не записываются; полный текст и его фрагменты исключаются из диагностики. Проверка `tests/desktop/qwen-live.spec.ts` с `WILEYAI_QWEN_TESTS=1` запускает настоящий движок из Electron, проверяет WAV в renderer и показ выбранного CPU/CUDA. Она использует временную историю и общий каталог весов; воспроизведение заглушено.

Первое измерение на Ryzen 9 7945HX, CPU/BF16 и 4 потоках: около **19 секунд подготовки для 3,9 секунды речи** Serena, с новой загрузкой процесса. Для очереди коротких фраз повторная проверка на CPU дала около 12 секунд на первую фразу с загрузкой и 6 секунд на следующую в том же процессе. Время зависит от текста и загрузки ПК. Это не режим мгновенного разговора и не обещание качества звучания. Образец распознан Whisper; тембр нужно оценить на слух. Для локальной проверки используйте `WILEYAI_QWEN_TESTS=1` с `pytest tests/test_live_qwen.py`; тесты не включают физический микрофон/динамики.

Для персонажа выберите свой VRM 0.x / 1.0 до 64 МБ со встроенными текстурами. Сторонние аватары не включены в репозиторий. Анимация рта пока управляется состоянием озвучки, а не точными фонемами.

- `Ctrl + Shift + Space` — открыть чат.
- `Ctrl + Shift + Esc` — завершить разговор, остановить ответ и озвучку, вернуть клики аватару.
- «Выйти» в интерфейсе или трее — полностью завершить приложение.

### Чаты, проекты и рабочее окно

В левой панели есть **«＋ Новый чат»**, **«＋ Проект»** и поиск по названиям чатов. Кнопка **«⋯»** возле чата открывает переименование, выбор проекта и удаление. Внутри проекта можно создать ещё один чат. В меню проекта доступны переименование и удаление.

У каждого чата своя история, документы и контекст уточнений задач. Общие чаты используют общую память, заметки и задачи. Чаты одного проекта используют память, заметки и задачи этого проекта; общая память и история других чатов в запрос модели не добавляются. Имя, характер ассистента, модели, голос, устройства и команды Windows остаются общими для приложения. Текущее пространство памяти подписано под названием чата и в разделе «Память».

При переносе чата в проект или обратно вместе с ним переходят история и файлы, включая уже написанные в переписке сведения. Подтверждённые факты, заметки и задачи остаются в прежнем пространстве; ссылки на перенесённые сообщения у фактов очищаются. Предложения памяти из этого чата и контекст уточнений сбрасываются. Удаление чата убирает его историю, документы и предложения, сохраняя подтверждённую память, заметки и задачи пространства. Удаление проекта после подтверждения удаляет все его чаты и собственные данные; общая память сохраняется.

Старая история при обновлении становится чатом **«Переписка до обновления»**. Выбор чата сохраняется после перезапуска. Несохранённый текст остаётся в своём чате при переключении в текущем окне; после полного выхода он не восстанавливается. Во время загрузки контекста выбранного чата ввод временно недоступен.

Кнопка **«☰»** вверху сворачивает левую панель до значков. Кнопка панели ассистента вверху справа и крестик внутри неё скрывают правую панель; выбор сохраняется после перезапуска. Приветствие показывается только в пустом чате, управление голосом находится в компактной строке над перепиской. Во время ответа или разговора сначала остановите текущий сеанс, затем переключайте чаты.

Для поиска по тексту переписки нажмите значок поиска рядом с **«Найти чат»** или **Ctrl+F** в открытом чате. Выберите текущий чат, его проект / общие чаты либо все проекты; при необходимости оставьте сообщения только пользователя или ассистента. Выбор результата открывает фрагмент истории вокруг совпадения и выделяет найденное слово, даже если сообщение старше последних 250 реплик. Кнопка **«Вернуться к последним сообщениям»** и стрелка вниз возвращают к актуальному концу. Новое сообщение также отправляется в текущий конец чата. Поиск локальный, по словам и их началам; он не обращается к нейросети и не добавляет найденные сообщения в её контекст автоматически.

### Сценарии запуска и доступ к открытиям

В разделе **«Команды»** создайте сценарий, например **«Работа»**: добавьте папку проекта, редактор и нужные сайты. В **«Готовое действие»** доступны встроенные открытия и ваши команды; **«Добавить свой шаг»** позволяет указать другой путь или адрес. Шаги можно редактировать, переставлять и удалять. Сценарий хранит собственные пути: последующее изменение команды в каталоге не меняет его шаги.

**«Проверить»** проверяет все шаги без запуска. **«Запустить»** открывает чат и выполняет сценарий; можно также написать или произнести **«Запусти сценарий Работа»** или **«Выполни сценарий Работа»**. Модель для этого не вызывается. У общего пространства и каждого проекта свои сценарии; чаты одного проекта используют общий список сценариев проекта.

Перед запуском проверяются все пути и доступ. Если любой шаг не проходит проверку, ничего не открывается. При ошибке во время выполнения оставшиеся шаги прекращаются; результат каждого выполненного шага виден в чате и журнале. Запускаются до 12 открытий по порядку. Это передача команд Windows, без ожидания готовности окон и управления внутри приложений. **«Стоп»** останавливает оставшиеся шаги; уже переданные Windows команды и открытые окна сохраняются.

В карточке **«Доступ к инструментам»** можно отдельно включить или выключить файлы/папки, приложения, сайты и управление звуком Windows, затем нажать **«Сохранить доступ»**. По умолчанию эти действия разрешены. Настройка общая для окон и применяется к прямым командам, сценариям и открытию поисковых источников. Поиск в интернете включается отдельно в его настройках. Изменение доступа проверяется перед каждым следующим шагом.

**Команды → Звук Windows**: ползунок и кнопки громкости, отключение/включение звука, предыдущий/следующий трек, воспроизведение/пауза и остановка проигрывателя. Можно написать или произнести «громкость тридцать пять процентов», «можешь сделать тише?», «выключи звук», «следующий трек». Модель для выполнения этих команд не загружается. Меняется системное устройство воспроизведения по умолчанию; выбранный динамик Уайли может отличаться. Медиаклавиши получает активный проигрыватель, воспроизведение/пауза переключает состояние. Подробнее: [управление звуком](docs/device-audio.ru.md).

### Свободные команды

В разделе **«Команды → Доступ к инструментам»** включите **«Понимать свободные команды с помощью модели»** и нажмите **«Сохранить доступ»**. Режим выключен по умолчанию и использует текущую модель категории «Мозг», локальную или подключённую через совместимый API.

Например: **«Можешь открыть программу для заметок?»** или **«Уайли, открой мой редактор»**. Если точной команды нет, модель предложит до трёх доступных вариантов из каталога. Ответьте **«да»** для одного варианта, **«второй»** или **«открой 2»** для нескольких. Поддерживаются также «да, открывай», обращение по имени и «пожалуйста». Это работает текстом и после распознавания голоса. Точные названия по-прежнему открываются напрямую без дополнительного обращения к модели.

В разбор передаются текущая фраза, типы и названия команд; пути каталога, история, память и документы автоматически не добавляются. Поиск ограничен 40 вариантами и бюджетом контекста; сначала отбираются названия с совпадениями слов. Модель возвращает только ID вариантов. Она не может добавить свой путь или действие. Если нужного объекта в каталоге нет, добавьте его название и путь в разделе «Команды».

Предложение привязано к чату и последнему вопросу, действует пять минут и сохраняется при перезапуске. **«Отмена»**, **«нет»** или другая тема прекращают выбор. Новое предложение открытия заменяет незавершённое уточнение задачи в этом чате. Перед исполнением заново проверяются каталог, доступ и существование пути; изменившуюся команду нужно запросить снова. В голосовом режиме варианты озвучиваются без длинных путей. После переноса чата или восстановления копии выбор нужно повторить.

Это ограниченный разбор открытий, а не универсальное исполнение намерений. Модель должна следовать формату JSON; некорректный ответ приводит к сообщению об ошибке без открытия. Проверена локальная Qwen3.5:4b; качество других моделей зависит от их способности выбирать варианты из каталога. Обычные разговоры не запускают дополнительную классификацию.

### Задачи и заметки в разговоре

Эти команды работают в чате и после распознавания голоса, без запроса к LLM:

- «Напомни завтра в 10 купить хлеб» → «Перенеси на 11».
- «Напомни позвонить» → Уайли уточнит время → «через пятнадцать минут».
- «Поставь таймер на 5 минут» или «поставь таймер на 1 час 30 минут».
- «Поставь будильник на 7:15».
- «Добавь задачу проверить сборку» → «отметь задачу выполненной».
- «Отмени это напоминание», «отмени таймер», «покажи задачи».
- «Создай заметку Покупки: хлеб и молоко».

Поддерживаются «сегодня», «завтра», «послезавтра», дни недели, даты ДД.ММ.ГГГГ, часы цифрами и русскими числительными, интервалы в секундах, минутах и часах. Если указано только время суток, выбирается ближайшее будущее такое время; явная прошедшая дата отклоняется. Ответ показывает полную дату, время и смещение UTC. Часовой пояс поступает из интерфейса компьютера, срок хранится в UTC.

«Перенеси на 11» сохраняет дату недавней задачи. «Перенеси на 15 минут позже» сдвигает её прежний срок, «перенеси через 15 минут» задаёт срок от текущего момента. Уточнения и ссылка на недавнюю задачу сохраняются после перезапуска в течение 15 минут; другой часовой пояс сбрасывает этот контекст. Если время или название не указано, напоминание ещё не создаётся. «Отмена» прекращает уточнение, «отмени это напоминание» удаляет недавнюю запись. При нескольких старых задачах выберите нужную в разделе «Задачи».

Это ограниченный локальный набор правил, а не распознавание любых формулировок. Повторения и произвольные цепочки действий пока не выполняются. Планировщик проверяет сроки каждые 5 секунд, поэтому короткий таймер не является точным секундомером.

### Библиотека документов

В разделе **«Документы»** доступны файлы текущего чата и явно добавленные файлы его проекта. Можно загрузить TXT, MD, CSV, текстовый PDF или DOCX, найти слова в названии и содержимом, просмотреть извлечённый текст и выбрать до 10 файлов для вопроса. Поиск работает локально без LLM и embeddings: не зависит от регистра, нормализует «ё/е», поддерживает начала слов и числа. Все слова запроса должны присутствовать; максимум 12 слов. Это поиск по словам, без исправления опечаток и понимания синонимов. Список разбит на страницы, просмотр — на фрагменты по 12 тысяч символов.

Обычная загрузка сохраняет файл только в текущем чате. В чате проекта можно выбрать **«Загрузить в → Библиотеку проекта»** или нажать **«Создать копию для проекта»** у файла чата. Копия независима от исходного файла и доступна другим чатам этого проекта. Удаление исходного чата её не удаляет; перенос чата оставляет библиотеку в прежнем проекте. Удаление файла проекта затрагивает все его чаты, удаление проекта удаляет его библиотеку. Общие чаты и другие проекты этих файлов не видят.

Отметьте нужные файлы и нажмите **«К вопросу»**. Над полем сообщения видны только выбранные документы. **«×»** снимает выбор, сам файл остаётся в библиотеке; удалить его можно в разделе «Документы». Загрузка через **«＋»** в чате или через раздел «Документы» сразу прикрепляет файл, пока не достигнут лимит 10. Рядом с именем видно число извлечённых символов. DOCX читается с таблицами, вложенными таблицами, текстовыми рамками и колонтитулами. Выбор хранится отдельно для каждого чата и восстанавливается при возвращении в него и после перезапуска. Файлы другого чата не прикрепляются автоматически. При восстановлении резервной копии старый выбор очищается. Списки обновляются между окнами. При удалённом или недоступном файле запрос отклоняется с пояснением, без обращения к модели.

В обычный запрос модели входят подобранные фрагменты выбранных документов, до 2000 символов суммарно, с именами источников и позициями текста. Над источниками видно, какая часть файла использована. При нескольких файлах место распределяется между ними. Можно попросить обычными словами: **«Мне нужен краткий пересказ от начала до конца»**. Модель может сама запросить чтение всех частей по смыслу просьбы и контексту диалога; точные команды не требуются. Кнопка **«Пересказать целиком»** рядом с прикреплённым файлом запускает чтение напрямую. Видны анимированный прогресс, счётчик частей, отбор исходных цитат и кнопка остановки. Пересказ проверяется по цитатам до показа и озвучки; неподтверждённый черновик заменяется дословными отрывками с пояснением. Ссылки [1], [2] раскрываются в блоке «Опорные фрагменты пересказа». Большая книга требует многих запросов и времени; облачная модель использует свой тариф, контекст автоматически не увеличивается. Подробнее — [полный пересказ](docs/document-summary.ru.md).

Содержимое документов считается данными и не исполняет команды. Уже написанные ответы остаются в истории чата после снятия выбора или удаления файла. В библиотеке сохраняется извлечённый текст, оригинальный PDF/DOCX не копируется. Лимиты: 15 МБ исходного файла, 1 миллион символов текста, 300 страниц PDF; сканам нужен OCR, который пока не подключён.

### Локальный календарь

В разделе **«Календарь»** можно добавить, изменить и удалить событие с началом, окончанием, местом и описанием. Справа — расписание на семь дней от выбранной даты; стрелки меняют неделю, **«Сегодня»** возвращает текущую дату. Пересекающиеся события отмечаются, соседние по границе времени — нет. События, начавшиеся до выбранного периода и продолжающиеся в нём, также показываются. Даты отображаются в часовом поясе компьютера, хранятся в UTC. Неоднозначное или несуществующее местное время при переводе часов отклоняется.

В чате и после распознавания речи работают явные команды без обращения к LLM:

- «Создай встречу Обсуждение проекта завтра в 10 на 30 минут».
- «Добавь в календарь Обзор завтра в десять на полчаса».
- «Создай встречу Обзор завтра в 10 на 30 минут, напомни за 15 минут».
- «Напомни о встрече за десять минут», «отключи напоминание о встрече» — для недавнего события этого чата.
- «Создай встречу Обзор» → «завтра в 10» — уточнение времени.
- «Покажи расписание завтра», «покажи расписание на неделю».
- «Перенеси встречу на 11», «перенеси встречу на завтра в 12» — длительность сохраняется.
- «Отмени встречу» — удаление недавнего события из этого чата.

Без длительности создаётся встреча на один час. В команде длительность — от минуты до суток; в форме — до 31 дня. Перенос и отмена из чата относятся к недавно созданному или перенесённому событию этого чата в течение 15 минут. «Отмена» прекращает уточнение, другая тема закрывает незавершённый черновик. Для произвольной старой встречи используйте форму. Редактор проверяет, не изменилось ли событие в другом окне, прежде чем перезаписать его.

Общие чаты разделяют общий календарь, чаты проекта — его собственный. Перенос или удаление чата сохраняет события в прежнем пространстве; удаление проекта удаляет его календарь. События входят в резервные копии. Google Calendar, Outlook, CalDAV, повторения и встречи на весь день пока не подключены. По умолчанию напоминание выключено. В форме включите **«Напомнить о встрече»** и задайте целое число минут: 0 — в начале, от 1 до 10080 — заранее, максимум за неделю. В чате «напомни в начале» включает уведомление на старте встречи. Перенос сохраняет выбранный интервал до начала; отключение, удаление события или проекта отменяет ожидающую доставку. Изменение названия или описания не создаёт повторное уведомление. Отдельная задача в «Задачах» для этого не создаётся.

Уведомления появляются в Windows и в открытых окнах WileyAI, пока программа работает, включая трей. После сна или перезапуска пропущенное уведомление показывается, если встреча ещё не закончилась. Завершившиеся события не вызывают запоздалых уведомлений. Если при включении напоминания его срок уже наступил, оно появится при следующей проверке планировщика. В уведомлении видны дата, время, часовой пояс и проект.

### Память и предпочтения

Скажите или напишите «Я предпочитаю короткие ответы», «Мне удобнее примеры на Python» или «Мой проект называется Альтаир». В чате и разделе **«Память»** появится предложение с исходной репликой. Его можно исправить, выбрать категорию и принять отдельной записью или заменить старую. До принятия оно не становится постоянной памятью; исходная реплика остаётся в обычной истории разговора.

**«Запомни: я предпочитаю короткие ответы»** и ручное добавление в разделе «Память» сохраняют факт сразу. У подтверждённых записей есть редактирование, удаление, закрепление и поиск по словам или их началу. В ответе можно раскрыть **«Передано в контекст из памяти»**, чтобы увидеть записи, переданные модели; это не доказывает, что модель использовала каждую из них. После исправления или удаления записи её прежняя ссылка скрывается из старых ответов, сам текст переписки сохраняется.

Предложения создаются локальными правилами для ограниченного набора прямых высказываний от первого лица. Дополнительные запросы к нейросети не выполняются. Повторные и отклонённые предложения не засоряют список. В **«Настройки»** можно выключить **«Предлагать память из разговоров»**. Это накопление проверенной памяти, а не дообучение весов модели; автоматического понимания любых привычек и семантического поиска пока нет.

### Поиск в интернете

В **«Настройки → Поиск в интернете»** выберите сервис, настройте подключение, включите **«Разрешить веб-поиск по моей команде»** и сохраните настройки. По умолчанию поиск выключен. Доступны два адаптера:

- **SearXNG**: базовый адрес своего сервера, например `http://127.0.0.1:8080`. Для удалённого адреса нужен HTTPS. На сервере должен быть включён формат `json` в `search.formats`; многие публичные серверы его запрещают. Это описано в [официальном Search API SearXNG](https://docs.searxng.org/dev/search_api.html). Локальный SearXNG всё равно обращается к внешним поисковым системам; сервер не устанавливается автоматически.
- **Brave Search**: отдельный ключ из своего аккаунта [Brave Search API](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started). Он хранится в Windows отдельно от ключа модели; в базу и резервные копии не попадает. Лимиты и стоимость определяются аккаунтом провайдера. Отдельный запрос проверки подключения автоматически не отправляется.

Запуск: **«Найди в интернете новости о…»**, **«Поищи в сети…»** или кнопка **«Поиск»** перед отправкой обычного текста. Кнопка действует на одно сообщение. Команды работают и после распознавания голоса. Обычные разговоры не запускают поиск в фоне. Настройка фильтра результатов передаётся выбранному сервису.

В поисковый сервис уходит текст этого запроса (у команды убирается начальная фраза «найди в интернете»). История, память и документы автоматически к запросу не добавляются. Если вы сами написали личные сведения в поисковом запросе, они отправятся сервису. Выдержки передаются выбранной модели, которая также получает обычный контекст чата и выбранные документы согласно своим настройкам.

Под ответом есть карточка **«Источники»**: запрос, сервис, время поиска, заголовки, адреса и короткие выдержки. Номера `[1]`, `[2]` в ответе соответствуют порядку источников; корректность их использования зависит от модели. Источник открывается в системном браузере только по нажатию. Данные сохраняются вместе с ответом, переживают перезапуск и входят в резервную копию. Это снимок поисковой выдачи на указанное время, а не дата публикации и не автоматическая перепроверка старого ответа.

При ошибке поиска или пустой выдаче WileyAI сообщает об этом, не выдавая ответ модели за свежую проверку. Если поиск успешен, но модель недоступна, источники остаются доступны. **«Остановить ответ»** прерывает ожидающий сетевой запрос. После восстановления подключений из копии поиск выключается до повторного разрешения.

Пока используются до пяти результатов и только поисковые выдержки: полные страницы не загружаются. Это не отдельный достоверный источник точной погоды, курсов валют или пробок; для них нужны специальные адаптеры. Содержимое выдачи не исполняет команды и не становится постоянной памятью автоматически.

### Резервные копии и перенос

Внизу **«Настройки»** есть карточка **«Резервные копии и перенос»**. **«Сохранить резервную копию»** открывает системный диалог сохранения файла `.wileyai.json`. В копию входят сохранённые настройки, личность, проекты и чаты, вся переписка, память с источниками и предложениями, результаты веб-поиска, заметки, задачи, события календаря, сценарии запуска, состояние уведомлений, команды и извлечённый текст загруженных документов. Принадлежность к чатам и проектам сохраняется. Это согласованный снимок данных, включая записи за пределами последних сообщений, видимых в интерфейсе.

**«Выбрать копию для восстановления»** сначала проверяет файл и показывает состав текущих данных и копии. Для замены нужно отметить подтверждение и нажать **«Восстановить данные»**. Имя, характер и настройка предложений памяти восстанавливаются вместе с данными. Подключение, модели, голос, устройства, путь к аватару и команды текущего ПК сохраняются, пока вы отдельно не включите соответствующие опции. Ключи из хранилища Windows не экспортируются и не перезаписываются. На другом ПК их нужно настроить отдельно.

Перед заменой автоматически сохраняется защитная копия в `data/backups/` (или в `backups/` внутри выбранного каталога данных). Её путь показывается в карточке; для возврата выберите этот файл как обычную копию. Если нужно вернуть также настройки подключения и команды, включите обе опции. При ошибке записи базы изменения откатываются. Если данные изменились после предпросмотра, нужно выбрать копию заново: новые сообщения или задачи не будут молча затёрты. После восстановления несохранённые черновики во всех окнах сбрасываются; перед переносом сохраните нужные изменения.

Файл копии не зашифрован и содержит личные данные. Веса моделей, VRM, оригиналы документов, ключи из системного хранилища и журнал действий в него не входят. Импорт ничего не открывает и не запускает команды. Просроченные недоставленные напоминания после восстановления могут сработать сразу; уже доставленные не ставятся повторно. Временный черновик диалога задач сбрасывается.

Новые копии используют версию формата 6; читаются также версии 1–5. Библиотеки документов проектов включены в копию; в старых версиях остаются только документы чатов. События календаря и состояние их уведомлений восстанавливаются со своим пространством. В копиях v4 напоминания событий выключены, в v1–v3 календарь пуст. История версии 1 переносится в один общий чат. Сценарии восстанавливаются как данные и сами не запускаются; пути другого ПК нужно проверить. Текущий доступ к открытиям сохраняется даже при импорте настроек подключения. Лимиты: до 64 МБ и 200 тысяч записей в сумме. При превышении лимитов файл не обрезается. Копии сохраняются вручную; автоматического расписания, шифрования, объединения двух историй и автоматической очистки защитных копий пока нет.

## Границы версии

Синхронизация календарей, почта, звонки, мессенджеры, специальные сервисы погоды/курсов/пробок, умный дом, медиа/громкость/яркость/радиомодули, камера и чтение экрана пока представлены требованиями и контрактом интеграций. Произвольные многошаговые сценарии, извлечение любых фактов из текста, embeddings, OCR, голосовая аутентификация, пароль и шифрование базы ещё не реализованы. API-ключи хранятся в системном хранилище Windows; SQLite истории и памяти пока не зашифрована.

Напоминания работают при запущенном WileyAI, включая трей; пропущенные срабатывают после запуска. Повторения пока не поддерживаются. Для документов доступны TXT/MD/CSV, PDF с текстом и DOCX, до 15 МБ; обычный ответ использует выбранные фрагменты, полный пересказ читает все части последовательно, OCR не подключён. Импортированный текстовый GGUF без визуального проектора не получает зрение автоматически.

## Проверки

```powershell
npm run check
npm run test:desktop
```

Обычные тесты не скачивают модели и не открывают пользовательские приложения. Для опциональной проверки настоящего Ollama и выбранного VRM:

```powershell
$env:WILEYAI_LIVE_TESTS = '1'
$env:WILEYAI_VRM_TEST_PATH = 'D:\avatars\character.vrm'
npm run test:desktop
.\.venv\Scripts\python.exe -m pytest tests/test_live_voice.py
.\.venv\Scripts\python.exe -m pytest tests/test_live_memory.py
.\.venv\Scripts\python.exe -m pytest tests/test_live_websearch.py
.\.venv\Scripts\python.exe -m pytest tests/test_live_intents.py
```

`test_live_voice.py` требует также установленных Whisper small и Silero и проверяет полный голосовой маршрут на синтезированной речи, без записи микрофона и воспроизведения в колонках. `test_live_memory.py` проверяет ответ настоящей Qwen по старому факту среди более сотни записей. `test_live_websearch.py` проверяет ответ настоящей Qwen с номером источника по данным контролируемого локального поискового сервера; внешние поисковые аккаунты и платные запросы не используются. `test_live_intents.py` проверяет выбор настоящей Qwen по ID каталога и отдельное подтверждение владельца; вызов Windows подменён, приложения не открываются. Проверки используют временную историю и не меняют пользовательские данные.
