# WileyAI: оставшиеся возможности и порядок работы

Сверено с кодом 17 октября 2026 года, версия 0.4.0. Это рабочая очередь расширений исходного плана. Наличие класса адаптера или строки в «Возможностях» само по себе не означает готовую функцию. Подробное состояние 14 направлений — в [таблице реализации](implementation-status.ru.md).

## Уже есть

Локальный/облачный мозг, отдельные категории моделей и загрузка поддержанных компонентов, чат и голос по очереди, выбор микрофона/динамика, несколько TTS, остановка озвучки, VRM, чаты/проекты с независимой памятью, заметки, задачи и однократные напоминания, локальный календарь, документы и поэтапный пересказ, поиск по истории/документам, память с подтверждением, открытия Windows и сценарии запусков, веб-поиск, мониторинг, резервные копии, установщик, мастер первого запуска, уведомления GitHub.

**В 0.4 выполнен следующий шаг управления ПК:** громкость/mute Windows, медиаклавиши, русские команды без LLM, отдельное разрешение и панель. Это часть управления устройством; яркость и радиомодули ещё не готовы.

## Ближайшие этапы

| Порядок | Работа | Как проверять завершение |
| --- | --- | --- |
| 1 | Повторяющиеся напоминания: ежедневно, по будням, по дням недели; выбор старой задачи в диалоге | Одинаково работают форма и русская фраза; перенос/отмена серии; следующий срок переживает перезапуск, часовой пояс и пропущенный запуск |
| 2 | Понимание задач/дат через структурированный результат модели | Модель выбирает разрешённое действие и сущность; валидатор проверяет дату, неоднозначность уточняется. Фраза из документа не создаёт задачу |
| 3 | Чтение полной веб-страницы и специальные данные погоды/курсов | Видны источник и время, ограничения размера/типа, понятные ошибки, защита от доступа к локальной сети; ответ подтверждён полученным содержимым |
| 4 | Семантический поиск памяти и документов | Отдельная категория embeddings; перестройка индекса после смены модели, ссылки на оригинал, изоляция проектов и работа без векторной модели через обычный поиск |
| 5 | Голосовое перебивание, активационная фраза, длинные реплики | Реальный микрофон и колонки: собственный TTS не запускает новые команды, прерывание отменяет очередь и генерацию, затем разговор продолжается; задержка и нагрузка измерены |
| 6 | Автозапуск, запланированные резервные копии и тихие часы | Настройки обратимы, нет дубликатов процессов/уведомлений, копии восстанавливаются; тихие часы не теряют напоминания |

## Следующие расширения

| Направление | Пока отсутствует | Подход к реализации |
| --- | --- | --- |
| Календарь | Google Calendar, Outlook, CalDAV, повторяющиеся события и весь день | Сначала один адаптер и явная настройка аккаунта; внешние ID, синхронизация в обе стороны, разрешение конфликтов и часовых поясов |
| Коммуникации | Почта, мессенджеры, контакты, SMS/звонки | Подключаемые адаптеры; сначала чтение и черновик, затем отправка по явной команде пользователя с видимыми адресатами |
| Интеграции | Home Assistant, Todoist/Trello, Spotify и прочие API | Операции и области доступа каждого сервиса; проверка соединения, отдельные ключи, обработка квот и недоступности |
| Заметки и списки | Отдельные списки покупок с пунктами, тегами и поиском | Локальные списки с отметками, команды добавления/удаления пунктов и независимые проекты |
| Персонализация | Семантика, обратная связь, устойчивое распознавание привычек и конфликтов памяти | Извлечение предложений с источником, управляемое принятие/отклонение, история изменений; это не автоматическое дообучение весов |
| Сценарии | Ветвления, ожидание условий, несколько типов инструментов, планирование LLM | Общие типизированные шаги, показ плана, проверка перед исполнением, остановка, понятный результат каждого шага |
| Устройство | Яркость, Wi-Fi/Bluetooth, управление конкретными медиасессиями | Отдельные Windows-адаптеры с обнаружением поддержки; медиаклавиша не заменяет API состояния проигрывателя |
| Изображения и экран | Изображения на входе, камера, снимок экрана, визуальная модель, действия внутри приложений | Явно выбранный источник/окно, поддержанная vision-модель, затем UI Automation для конкретных задач. Полный доступ к ПК сам по себе не даёт визуального понимания |
| Персонаж | Развитые выражения, жесты, реакция на эмоции, проверка сна/нескольких мониторов | Согласованные состояния чата, речи и VRM; измерение GPU/FPS и проверка скрытого окна |
| Приватность | Пароль, шифрование базы/копий, голосовая идентификация | Отдельная схема ключей, восстановление доступа и тесты миграции; голос не единственный способ авторизации |
| Проактивность | Предложения по привычкам, месту/времени и обучению на отказах | Включаемые правила, тихие часы, понятная причина предложения и отключение; внешние действия по явной команде |
| Распространение | Подпись установщика и автоматическая установка обновлений | Подпись требует сертификата; автоматическое обновление отдельно от уже готовых уведомлений |

Аккаунты и ключи вводятся в программе. Добавление подключения не означает автоматическое подключение ко всем личным сервисам. Новые модели и внешние сервисы проверяются по их реальным возможностям; поддержка любого API не предполагает одинаковый формат речи, изображений и инструментов.
