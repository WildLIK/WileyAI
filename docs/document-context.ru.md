# Документы в контексте ответа

После нового ответа по прикреплённому файлу под репликой появляется сворачиваемый блок **«Документы в контексте»**. Он показывает точные отрывки, подготовленные для этой реплики:

- полное имя файла;
- начало и конец отрывка в символах извлечённого текста;
- общую длину документа;
- сам отрывок без пересказа и преобразования в Markdown.

Блок добавляется к новым ответам; источники старых ответов задним числом не восстанавливаются. В качестве источников сохраняются только отрывки, фактически выбранные в пределах бюджета контекста. При достаточном бюджете небольшой файл может попасть целиком. Обычный вопрос к большому файлу использует отбор по совпадениям слов; над блоком показано число выбранных символов и явно отмечено частичное чтение. Для всего файла есть отдельный режим [«Пересказать целиком» с анимированным прогрессом](document-summary.ru.md). Его итог строится по конспектам всех частей и не выдаётся за дословные отрывки. Семантический поиск пока не подключён.

Диапазон относится к тексту после извлечения из TXT/MD/CSV, PDF или DOCX, включая служебные метки страниц и прочитанные колонтитулы. Это не номер страницы исходного Word-файла. Содержимое блоков — контекст вопроса, а не автоматически проверенные доказательства каждого утверждения модели.

## Хранение и границы чатов

Отрывок сохраняется как снимок вместе с ответом, включая ответ, прерванный лимитом длины или ошибкой потока после начала генерации. Изменение исходного текста или удаление файла из библиотеки не переписывает историю. Для удаления сохранённых отрывков удалите соответствующий чат; удаление проекта удаляет и историю его чатов. При явном переносе чата отрывки переносятся как часть его истории.

Отрывки не становятся общей памятью. Они не подставляются в следующие запросы автоматически. Следующий вопрос использует заново выбранные файлы и обычную историю этого чата. История соседнего чата или другого проекта их не получает. Обычная локальная команда с прикреплённым файлом не создаёт блок источников, поскольку документ не отправляется модели.

Новая резервная копия имеет формат **7** и включает снимки отрывков в сообщениях. Чтение форматов 1–6 сохраняется; для старых сообщений список источников пуст. Восстановление проверяет роли сообщений, число и размер отрывков, идентификаторы и границы диапазонов. Снимки не требуют наличия исходного документа в библиотеке. Миграция старой SQLite добавляет пустое поле источников без изменения текста переписки.

## Проверки

`tests/test_document_context.py` проверяет точное совпадение отрывков с отправленным контекстом и диапазонами, несколько файлов, малый бюджет, большие смещения, Unicode, полные имена, частичный ответ, отдельные проекты, отсутствие автоматического добавления в память, миграцию, резервное копирование и повреждённые записи. Обычные API-тесты подменяют только генерацию ответа моделью.

`tests/desktop/documents.spec.ts` загружает настоящий DOCX в временную базу Electron, захватывает HTTP-запрос к тестовому серверу модели и сравнивает его с показанным отрывком. Проверяются свёрнутый блок, раскрытие, удаление файла, полный перезапуск и отсутствие блока в следующем ответе без вложения.
