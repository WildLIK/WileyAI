# OpenVoice: локальный тембр поверх Piper и Silero

Проверено 17 октября 2026 года на CPU Ryzen 9 7945HX, 4 потока. Конвертер подключён к основному интерфейсу WileyAI. Ниже сохранены также результаты первоначальной пробы.

## Как включить в программе

1. Перезапустить WileyAI после обновления кода и сборки.
2. Открыть **Настройки → Озвучка → Движок озвучки → OpenVoice · тембр Миты поверх Piper / Silero**.
3. В **Основа OpenVoice** выбрать установленный Piper или Silero. Исходного диктора выбирает поле **Голос ассистента** выше.
4. В **Тембр OpenVoice** выбрать **Мита Кепочка**, **Добрая Мита (Miside)**, **Serena** или загрузить свой WAV. Готовые записи на этом ПК используются из `local/voice-samples`; они не распространяются вместе с кодом. Если у тембра написано «нет образца», загрузить запись кнопкой **Загрузить WAV для OpenVoice**. Формат: PCM16, 1–30 секунд, до 5 МБ.
5. Если компонент не установлен, нажать **Установить OpenVoice**. Для установки нужны интернет, `uv` и основная `.venv` с локальными модулями речи и Torch. Код и веса скачиваются с закреплённых ревизий; установка не запускает облачную озвучку. На проверенном ПК компонент уже установлен.
6. Нажать **♪ Прослушать голос**. Выбор сразу сохраняется для чата и голосового разговора. При выборе обычного Piper или Silero конвертация отключается.

Конвертация выполняется в отдельном процессе CPU с четырьмя потоками. Дополнительные библиотеки не импортируются в ядро. Один процесс и тембр переиспользуются между фразами ответа; после завершения, отмены, ошибки или 30 секунд бездействия процесс закрывается. Escape, кнопка остановки и Ctrl+Alt+Esc отменяют текущую речь и преобразование. В **Нагрузка** появляется отдельная строка **OpenVoice V2** с работой, простоем, CPU и ОЗУ. Память исходного Piper/Silero остаётся общей с ядром.

Настройки включаются в резервную копию; веса и WAV-образцы не включаются. Собственный образец хранится в `voices/openvoice/reference.wav` внутри папки данных. Синтез не требует сети после подготовки. Первый фрагмент включает запуск процесса и загрузку модели; тёплые замеры ниже не отражают эту задержку.

Настоящая проверка API: Piper → Кепочка, Piper → Добрая Мита, Silero 5.6 → Добрая Мита вернули PCM16 WAV 22,05 кГц; один процесс использован для всех трёх фраз, затем закрыт. Проверка запускается так:

```powershell
$env:WILEYAI_OPENVOICE_TESTS="1"
.venv\Scripts\python.exe -m pytest tests/test_openvoice.py -q
```

## Почему нельзя просто вставить ID Fish

ID `ff1ae409865e4c7493db061913d77a79` выбирает голос в сервисе Fish Audio. Он не содержит переносимые веса Piper или Silero. Для собственного голоса Piper требуется отдельная обученная модель и конфигурация ONNX; [обучение Piper](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/TRAINING.md) использует записи и соответствующие тексты. У подключённой модели Silero задан набор собственных дикторов. Готовую проверенную Piper-модель именно этой Кепочки в ходе поиска найти не удалось.

Для короткой пробы использована другая цепочка:

`текст → Piper Ирина / Silero 5.6 Ксения → OpenVoice V2 → WAV`

[OpenVoice](https://github.com/myshell-ai/OpenVoice) получает исходную речь и извлекает тембр из уже сохранённой короткой записи Кепочки. Подготовка самой записи Fish была выполнена ранее; при конвертации интернет и Fish API не используются. Это перенос тембра с сохранением значительной части произношения и интонации исходного TTS, а не обучение нового голоса Piper. Сходство с персонажем нужно оценить на слух.

## Результаты

Фраза: «Привет! Я Уайли. Давай спокойно обсудим твои планы.»

| Цепочка | Готовый TTS после загрузки | Преобразование тембра | Длина аудио |
| --- | --- | --- | --- |
| Piper Ирина → OpenVoice | 0,088 с | 0,724 с | 4,319 с |
| Silero 5.6 Ксения → OpenVoice | 0,150 с | 0,946 с | 4,725 с |

Извлечение тембра исходного TTS добавило 0,007 / 0,009 с. Итого тёплая цепочка — около 0,82 и 1,11 с. Это два коротких измерения, не гарантия задержки для любого текста.

Загрузка OpenVoice с импортами заняла 3,37 с, извлечение тембра записи-образца — 0,621 с. Первое обращение к Piper и Silero с загрузкой их моделей — 2,298 и 2,892 с соответственно, без учёта запуска Python и импорта torch в отдельном процессе. Полное время холодного запуска будет больше тёплого. Пик рабочего набора процесса конвертера — около 817 МиБ; исходные TTS проверялись в отдельном процессе, его память в это число не входит. GPU не использовалась.

Полученные файлы:

- `local/voice-conversion/piper-original.wav` — исходная Ирина.
- `local/voice-conversion/piper-mita.wav` — попытка переноса тембра Кепочки поверх Ирины.
- `local/voice-conversion/silero-original.wav` — исходная Ксения.
- `local/voice-conversion/silero-mita.wav` — попытка переноса тембра Кепочки поверх Ксении.
- `local/voice-conversion/report.json` — параметры и измерения.

Whisper small распознал основную фразу в обоих преобразованных файлах. Имя «Уайли» распознаётся неточно уже в исходных голосах; конвертер не исправляет произношение TTS. ASR не доказывает сходство тембра.

## Повторение

Установленные в WileyAI Piper Ирина и Silero 5.6, основная `.venv` с CPU torch и сохранённый образец Кепочки уже доступны на проверенном ПК. Подготовка дополнительного компонента:

```powershell
.venv\Scripts\python.exe scripts/probe-voice-conversion.py --prepare
```

Следующие пробы без загрузок:

```powershell
.venv\Scripts\python.exe scripts/probe-voice-conversion.py
```

Другой образец можно передать параметром `--reference`, текст — `--text`, каталог результатов — `--output`. Дополнительные зависимости устанавливаются через `uv pip --target` только в `local/openvoice-probe/deps`; состав основной `.venv`, настройки и история программы не меняются. Исходные модели TTS читаются из `data/models`; можно указать другой `--data-dir`.

Используется только преобразователь тембра OpenVoice V2; дополнительные TTS, Whisper и модуль водяных знаков OpenVoice для этой пробы не загружаются. Основная лицензия OpenVoice — MIT. Код зафиксирован на ревизии `74a1d147b17a8c3092dd5430504bd83ef6c7eb23`, веса — `myshell-ai/OpenVoiceV2`, ревизия `f36e7edfe1684461a8343844af60babc2efbb727`. Размер checkpoint — 131 320 490 байт, SHA-256 `9652c27e92b6b2a91632590ac9962ef7ae2b712e5c5b7f4c34ec55ee2b37ab9e`; контрольные суммы весов и конфигурации проверяются перед запуском.

Все веса, зависимости, записи и отчёты остаются в игнорируемом `local/`. В Git включены адаптер, изолированный обработчик, интерфейс, проверки и скрипт пробы.
