# Память речевых моделей

Настройка находится в **Настройки → Микрофон и разговор → Память моделей речи**.

| Выбор | Простой до выгрузки |
| --- | --- |
| По профилю: экономичный | 1 минута |
| По профилю: сбалансированный | 5 минут |
| По профилю: максимальное качество | 15 минут |
| Фиксированный срок | 1, 5 или 15 минут |
| Оставлять загруженными | Автовыгрузка отключена |

По умолчанию используется профиль производительности. Изменения применяются после **«Сохранить»**, сохраняются при перезапуске и включаются в резервную копию. Старая конфигурация и копия без этого поля получают значение «По профилю». Формат резервной копии — 7. При обычном восстановлении сохраняется настройка текущего ПК; при переносе с подключениями применяется настройка копии.

Выгружаются только загруженные CPU-модели Whisper, Silero и Piper. Простой отсчитывается отдельно для распознавания, Silero и Piper, с окончания последней операции, включая ошибки. Подготовка разговора защищает модели до завершения загрузки всех компонентов. Временные процессы Qwen/OpenVoice управляются сессией озвучки: клиент закрывает их по завершении ответа, движки также имеют резервный срок простоя 30 секунд. Выбор «Оставлять загруженными» относится к Whisper, Silero и Piper.

Фоновая проверка проходит раз в 15 секунд. Выполняющееся распознавание, подготовка моделей, синтез и ожидающая озвучка откладывают выгрузку. Время перепроверяется под блокировками непосредственно перед освобождением. Для пустого набора моделей не читаются настройки и не запускается сборка мусора. После реальной выгрузки появляется запись `voice.idle_unload` в журнале действий, а монитор нагрузки обновляет состояние загруженности.

Первый запрос после выгрузки загружает модель с диска, поэтому может начаться медленнее. Веса, настройки голоса, API-ключи и история сохраняются. Отправки запросов моделям или облачным сервисам для проверки простоя нет. Фактический возврат памяти ОС зависит от нативных библиотек и их аллокаторов; определённый объём освобождённой ОЗУ не обещается.

Кнопка **«Освободить память речи»** запускает ручную выгрузку всех простаивающих речевых компонентов, включая Qwen/OpenVoice. Во время работы API сообщает о занятости. Автовыгрузка пропускает занятые модели и повторяет проверку позже.

## Проверки

`tests/test_voice_idle_resources.py`: сроки профилей и явного выбора, раздельное время использования, границы таймера, длинное распознавание, незавершённая подготовка разговора, ошибка синтеза, защита занятых операций, независимые сессии Qwen/OpenVoice, отсутствие работы при пустом кеше, применение новой настройки, журнал, восстановление после ошибки фонового обслуживания, запуск и остановка вместе с ядром, перезапуск и старые копии.

`tests/test_voice_resources.py`: ручная выгрузка и дополнительная проверка настоящих Whisper small, Silero 5.6 и Piper Irina. С управляемыми часами моделируется минута простоя; проверяются выгрузка, повторная загрузка, синтез и распознавание созданной фразы без скачивания весов. Для запуска установленного набора: `WILEYAI_RESOURCE_TESTS=1`.

`tests/desktop/settings-layout.spec.ts`: выбор политики через настоящий Electron и API, сохранение черновика между разделами, сохранение после перезагрузки, ручная выгрузка и размещение настроек в узком окне. Голосовые проверки Electron используют искусственный микрофон.
