# Приложения на компьютере

В **Команды → Приложения на компьютере** нажмите **«Сканировать приложения»**. Пока идёт поиск, виден анимированный индикатор. Сканирование читает локальную регистрацию Windows, известные папки установки и ярлыки меню «Пуск». Оно не запускает программы и не добавляет команды само.

| Категория | Примеры из каталога |
| --- | --- |
| Музыка | AIMP, Яндекс Музыка, Spotify, foobar2000 |
| Видео | VLC, MPC-HC, PotPlayer, KMPlayer |
| Графика и работа | Photoshop, Illustrator, GIMP, Krita, Blender, VS Code, Word, Excel, PowerPoint |
| Мессенджеры | Telegram, Discord, WhatsApp, Viber |
| Браузеры | Chrome, Яндекс Браузер, Firefox, Edge, Opera |
| Программы Windows | Блокнот, Калькулятор, Проводник, Paint, Ножницы, Диспетчер задач, Панель управления, Параметры, Терминал и другие доступные утилиты |

В категории видны найденные программы, пути, источник обнаружения и пример команды. **«Добавить»** регистрирует выбранную программу; **«Добавить все найденные»** добавляет доступные новые имена. Совпадающее имя с другим путём помечается **«Имя занято»** и не перезаписывается. Совпадающая команда не дублируется, в том числе при одновременном добавлении из другого окна. Перед импортом существование файла проверяется повторно.

После добавления можно говорить и писать «открой аимп», «запусти фотошоп», «открой мне мозиллу». Используются поддержанные формы названий: например, для Firefox — «мозилла», «мозиллу», «мозила», «файрфокс», «firefox». Универсального склонения любого имени пока нет. Видимый пример под каждой карточкой содержит поддержанную форму. Дословное пользовательское имя имеет приоритет перед встроенными синонимами. Для запуска проверяется разрешение **«Приложения»** и сохраняется результат действия.

Удалить или изменить добавленные команды можно в обычном списке ниже. Сканирование повторяется по кнопке после установки новых программ. Настройки команд общие для компьютера и входят в резервную копию; это не память отдельного проекта.

## Музыка и естественные просьбы

- «Открой мне сайт YouTube», «можешь открыть GitHub?», «открой кит-хаб» выполняются без языковой модели.
- «Прибавь громкости», «убавь мне громкости на пять» изменяют громкость Windows и сообщают прочитанный результат.
- «Открой, открой, открой» требует назвать объект. Ответ модели о якобы выполненном открытии не генерируется.
- «Включи мне музыку»: при одном добавленном музыкальном приложении WileyAI открывает его; при нескольких предлагает до трёх вариантов, выбор — номером. Без добавленного проигрывателя предлагает указать источник. Локальный выбор работает и с выключенным пониманием свободных команд моделью.

Открытие плеера не подтверждает воспроизведение трека. Для уже открытого проигрывателя есть медиакоманда «переключи воспроизведение», но состояние конкретного трека не считывается. Запуск мессенджера также не означает отправку сообщений или подключение аккаунта.

## Границы обнаружения

Это каталог известных приложений, а не инвентаризация каждого EXE на всех дисках. Портативные и нестандартно установленные программы могут отсутствовать; их можно добавить вручную. Просмотр меню «Пуск» ограничен числом записей, глубиной и временем, без перехода по каталогам-ссылкам. При частичной ошибке остальные результаты сохраняются, выводится пояснение. Сетевые пути не сканируются.

Поддержаны обычные EXE и ярлыки с существующим EXE-назначением. Чистые приложения Microsoft Store без такого пути/ярлыка могут не обнаружиться. Некоторые стандартные компоненты отсутствуют в отдельных версиях Windows; показаны только найденные файлы. Выбор браузера по умолчанию для всех сайтов и управление внутри приложений — отдельные будущие расширения.

Регистрация App Paths описана в [документации Microsoft](https://learn.microsoft.com/en-us/windows/win32/shell/app-registration). Проверки включают настоящий поиск на Windows, изолированные ярлыки и пути, недоступные файлы, конкурирующий импорт, категории в Electron и разбор русских названий без запуска настоящих приложений.
