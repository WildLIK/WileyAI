# Приложения на компьютере

В **Команды → Приложения на компьютере** нажмите **«Сканировать приложения»**. Сканирование читает ярлыки меню «Пуск», регистрации App Paths и сведения об установленных программах, известные пути каталога, а также список зарегистрированных приложений Microsoft Store текущего пользователя. Оно ограничено по времени и числу записей, не запускает программы и не добавляет команды само. Неизвестные каталогу приложения отображаются в категории **«Другие»**; поле поиска ищет по всем категориям.

| Категория | Примеры из каталога |
| --- | --- |
| Музыка | AIMP, Яндекс Музыка, Spotify, foobar2000 |
| Видео | VLC, MPC-HC, PotPlayer, KMPlayer |
| Графика и работа | Photoshop, Illustrator, GIMP, Krita, Blender, VS Code, Word, Excel, PowerPoint |
| Мессенджеры | Telegram, Discord, WhatsApp, Viber |
| Браузеры | Chrome, Яндекс Браузер, Firefox, Edge, Opera |
| Программы Windows | Блокнот, Калькулятор, Проводник, Paint, Ножницы, Диспетчер задач, Панель управления, Параметры, Терминал и другие доступные утилиты |

В карточке видны название, путь или идентификатор, источник и пример команды. Программы можно открывать без импорта. **«Добавить»** сохраняет название в командах; поле собственного названия позволяет добавить свой псевдоним. Существующие имена не перезаписываются. При повторном сканировании обновляется кэш; старый формат `applications.json` сохраняет совместимость.

Например, «открой RPGReactor» запускает единственное точное совпадение после проверки разрешения и цели. Пользовательские команды имеют приоритет. Версионные суффиксы учитываются: если одному названию соответствует несколько путей, Уайли перечисляет до трёх вариантов и ждёт номер; остальные можно выбрать в интерфейсе. Доступ **«Приложения»** проверяется повторно перед выполнением. Отмена во время поиска не запускает приложение позже.

Используются поддержанные формы названий: для Firefox — «мозилла», «мозиллу», «мозила», «файрфокс», «firefox». Для Яндекс Браузера поддержаны «Яндекс, браузер», «Яндекс Праузер» и «Яндекс броузер». Это ограниченный словарь, а не нечёткое исполнение любых путей. Видимый пример под каждой карточкой содержит поддержанную форму. Дословное пользовательское имя имеет приоритет перед встроенными синонимами. Ручное добавление сохраняет выбранный пользователем путь.

«Проверь Яндекс Браузер», «найди в системе Firefox» выполняют настоящий поиск без запуска и показывают найденный путь; результат `app.inspect` сохраняется в журнале. Формулировка «не найдено» относится к проверенным местам, а не ко всем дискам. Типовые выдуманные утверждения модели «проверила/проверю» в коротких репликах об управлении перехватываются до вывода и озвучки.

Удалить или изменить добавленные команды можно в обычном списке ниже. Сканирование повторяется по кнопке после установки новых программ. Настройки команд общие для компьютера и входят в резервную копию; это не память отдельного проекта.

С 0.8.1 список результатов с датой хранится в `applications.json` внутри папки данных. Переход между разделами и полный перезапуск его не сбрасывают. Новый поиск нужен по желанию после установки/удаления программ. У существующей установки до первого сохранённого сканирования показываются уже добавленные приложения из команд. Кэш относится к текущему компьютеру и не входит в резервную копию; команды в копию входят как прежде.

## Проверка запуска

Для EXE и проверяемых LNK используется ShellExecuteEx Windows. До и после запроса сравниваются процессы с **точным путём EXE**, а не только похожим именем. Ответ содержит «процесс запущен и подтверждён», «процесс уже работает» с PID либо «запрос принят, процесс за 3 секунды не подтверждён». Путь и результат сохраняются в **Журнале действий Windows** ниже панели звука. Для ярлыка с недоступными метаданными возможна только передача запроса, без выдуманного PID.

Наличие процесса не подтверждает готовность окна, воспроизведение музыки или выполнение задачи внутри программы. Для файлов/папок и сайтов подтверждается передача Windows/браузеру, а не открытие конкретного содержимого. Ошибка Windows сохраняется отдельно. [ShellExecuteEx](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shellexecuteexw).

## Музыка и естественные просьбы

- «Открой мне сайт YouTube», «можешь открыть GitHub?», «открой кит-хаб» выполняются без языковой модели.
- «Прибавь громкости», «убавь мне громкости на пять» изменяют громкость Windows и сообщают прочитанный результат.
- «Открой, открой, открой» требует назвать объект. Ответ модели о якобы выполненном открытии не генерируется.
- «Включи мне музыку», «запустим музыку»: сначала проверяется доступный плеер и запрашивается воспроизведение. Если плеера нет, при одном добавленном музыкальном приложении WileyAI открывает его; при нескольких предлагает до трёх вариантов, выбор — номером. Без добавленного проигрывателя предлагает указать источник. Локальный выбор работает и с выключенным пониманием свободных команд моделью.

Открытие плеера не подтверждает воспроизведение трека. Для поддержанного проигрывателя есть [пауза, продолжение и проверка состояния](device-audio.ru.md). Поддержана форма «открой Яндекс.Музыку». Запуск мессенджера не означает отправку сообщений или подключение аккаунта.

## Границы обнаружения

Поиск не обходит диск целиком. Портативные и нестандартно установленные программы без регистрации и ярлыка могут отсутствовать; их можно добавить вручную. Просмотр меню «Пуск» ограничен числом записей, глубиной и временем, без перехода по каталогам-ссылкам. При частичной ошибке остальные результаты сохраняются. Сетевые пути и опасные имена установщиков, деинсталляторов и командных оболочек не допускаются к автоматическому запуску. Совпадение выполняется по целому нормализованному имени или известному синониму, без приблизительного выбора EXE.

Для ярлыка проверяется локальная EXE-цель, затем запускается сам EXE: аргументы ярлыка не выполняются. Программы, которым эти аргументы необходимы, могут работать иначе. Приложения MSIX/UWP из меню «Пуск» сопоставляются с зарегистрированным пакетом текущего пользователя и активируются системным API по AUMID. Регистрация проверяется перед запуском; ответ Windows об активации и PID не подтверждает появление или исправность окна. Приложения Store, не представленные в меню «Пуск», не обнаруживаются. Запрос «программу, установленную вчера» показывает недавно обнаруженные варианты без утверждений о дате установки и ничего не запускает.

Регистрация App Paths описана в [документации Microsoft](https://learn.microsoft.com/en-us/windows/win32/shell/app-registration). Проверки включают настоящий поиск на Windows, изолированные ярлыки и пути, недоступные файлы, конкурирующий импорт, категории в Electron и разбор русских названий без запуска настоящих приложений.
