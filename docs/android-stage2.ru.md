# Android: второй этап — диалоги WileyAI и локальная речь

Обновление 0.5.0: разделены компоненты, исправлен сетевой транспорт; установка модели и 15 Android-тестов проверены на Galaxy S23+. [Результаты](releases/android-0.5.0.ru.md). Ниже описание исходной реализации 0.4.0, до проверки на устройстве.

28 октября 2026. Второй этап реализован в коде; приёмка настоящего голоса на Android
остаётся открытой. Подключённых устройств и AVD в окружении нет. Весов моделей
в APK нет, в ходе разработки они не скачивались и не устанавливались.

## Диалоги

`WileyDialogs` и `res/values/styles.xml` применяют палитры WileyAI к заголовкам,
спискам, тексту, кнопкам и фону. Окна имеют скругление 24 dp, тонкую рамку,
статичный градиент и умеренное затемнение фона. Строки списка переносятся;
кнопки не переводятся в верхний регистр. Ширина ограничена экраном и 560 dp.
Используются те же четыре палитры, что и в `src/themes.css`.

Обновлены все диалоги Activity: выбор места обработки сообщений, подключение к ПК,
чаты, тема, диагностика, подтверждения, ошибки и формы. Выбор неоднозначного
приложения в `PhoneActionEngine` использует тот же компонент. Windows UI не менялся.
Внешний вид на конкретном телефоне ещё не проверен; сборка не заменяет визуальную приёмку.

## Выбор речевого стека

| Кандидат | Что подтверждают первичные источники | Решение этого этапа |
| --- | --- | --- |
| sherpa-onnx | Android, локальные ASR/TTS/VAD, несколько ABI; есть примеры и сборка AAR с нативными библиотеками | Оставлен кандидатом для общего речевого runtime. Подключение его NDK/Kotlin/AAR и конкретных русских моделей требует отдельной проверки |
| Vosk | Готовая Android AAR 0.3.75, Java API, компактная русская ASR-модель | Единственный встроенный ASR-движок этого выпуска; CPU, без LLM |
| Android TextToSpeech | API предоставляет язык голоса, требование сети и признак отсутствующих данных | Используем уже установленные русские голоса, помеченные как офлайн. Без автоматического сетевого резерва |
| Piper | Локальный нейросетевой TTS; текущий piper1-gpl публикуется под GPL-3.0, модели имеют отдельные условия | Не встраивается параллельно. Собственные загружаемые голоса — последующий этап после выбора runtime и моделей |
| Silero VAD | Отдельный детектор речи, включая ONNX-путь | Не добавляется отдельной тяжёлой зависимостью: для ограниченной записи достаточно завершения фразы Vosk и таймаута |

Источники: [sherpa Android](https://k2-fsa.github.io/sherpa/onnx/android/index.html),
[сборка sherpa AAR](https://github.com/k2-fsa/sherpa-onnx/tree/master/android/SherpaOnnxAar),
[официальный пример Vosk](https://github.com/alphacep/vosk-android-demo),
[модели Vosk](https://alphacephei.com/vosk/models),
[Android Voice](https://developer.android.com/reference/android/speech/tts/Voice),
[Piper](https://github.com/OHF-Voice/piper1-gpl), [Silero VAD](https://github.com/snakers4/silero-vad).

Это инженерный выбор минимального расширения существующего Java-клиента, а не
результат сравнительного бенчмарка на телефоне. Скорость, точность и потребление
памяти моделей на устройстве владельца не измерены.

## Установка русского ASR

В разделе «Модели» появился комплект `vosk-model-small-ru-0.22` (Apache-2.0).
Архив: **46 236 750 Б / 44,1 МиБ**. Точный распакованный размер не объявляется;
400 МиБ — консервативный бюджет свободного места для безопасной установки, а не
размер модели. Совместимость не выводится только из объёма RAM.

- Явное подтверждение загрузки и её объёма; по умолчанию только Wi-Fi.
- Загрузка привязывается к выбранной Wi-Fi-сети, без автоматического перехода
  на мобильный интернет. При VPN доступность такого режима зависит от того,
  какую сеть Android сообщает приложению; можно явно разрешить любую сеть.
- Прогресс/объём, остановка с сохранением `.part`, продолжение через HTTP Range.
  При ответе 200 на Range файл перезаписывается с начала; неправильный Content-Range
  отклоняется. Скорость загрузки отдельным числом пока не показывается.
- Импорт **точного официального ZIP** через системный выбор файла. Произвольные
  модели и другие версии этим импортом не поддерживаются.
- Проверяются точный размер, SHA-256 и MD5, затем границы путей ZIP, отсутствие
  повторяющихся файлов и предельный распакованный размер. ZIP не исполняет код.
- SHA-256 опубликован **зеркалом** в LFS-метаданных закреплённой ревизии, а не
  приписывается автору Vosk. URL/размер/MD5 взяты из официального каталога.
  Для установки должны совпасть обе суммы. [Зафиксированные метаданные](research/android-speech-catalog.json).
- Повреждённая завершённая загрузка удаляется после несовпадения сумм; повтор
  получает файл заново. Незавершённую загрузку можно удалить отдельной кнопкой.
- Обязательные файлы проверяются, затем Vosk действительно загружает модель
  и декодирует короткую тишину. Это проверяет загрузку/декодер, но не точность речи.
- Только после успешной проверки атомарно меняется указатель активной модели.
  Ошибки, отмена, нехватка памяти или несовместимая библиотека не заменяют её.
  Незавершённые каталоги очищаются при восстановлении. Повреждённый указатель
  требует явного удаления речевого комплекта; история чатов не затрагивается.

Ни установка, ни проверка загрузки не объявляются пройденными до выполнения
этого пути на устройстве. В данном окружении реальный комплект не устанавливался.

## Каталог установленных приложений

`AppCatalog` асинхронно читает `PackageManager.queryIntentActivities(MAIN/LAUNCHER)`:
отображаемое название, package, Activity и стабильный ComponentName. Отключённые,
неэкспортируемые и лишённые экрана запуска компоненты не предлагаются. Подписка
на PACKAGE_ADDED/REMOVED/REPLACED/CHANGED обновляет снимок; есть ручная проверка.
Дополнительных разрешений или отправки каталога на ПК/в облако нет.

`AppCatalogPanel` в разделе «Функции» показывает поиск, пакет, адрес запуска и
собственные названия пользователя. До 12 псевдонимов на компонент сохраняются
в закрытых SharedPreferences вне UI-потока. Открытый список обновляется вместе
с каталогом; нажатие относится к фактически отображённой записи.

`AppRegistry` отделяет точное разрешение имени от поиска по подстроке.
Нормализуются Unicode, регистр, ё/е, пробелы и известные варианты названий.
Несколько совпадений всегда уточняются; результат поиска по части имени сам
по себе не становится командой запуска. Перед Intent проверяется доступность
компонента, а отложенный запуск после ухода WileyAI в фон отменяется.

Сканирование не переучивает Vosk. Для иностранного имени можно назначить понятный
русский псевдоним. Хостовые тесты проверяют разрешение/коллизии/удаление из снимка,
а инструментальный тест — реальный launcher-каталог и сохранение псевдонима после
повторного создания каталога. Последний пока только собран, устройства нет.

## Микрофон и озвучка

`OfflineSpeechEngine` запускает одну явную сессию PCM 16 кГц, mono, 16 bit.
Максимум 15 секунд, завершение первой распознанной фразы или повторное нажатие ■.
Тишина возвращает понятное сообщение. При уходе в фон сессия отменяется; поздний
результат не запускает приложение. Модель и микрофон освобождаются после сессии.
Постоянного прослушивания, foreground service и активационной фразы нет.
Если поле ввода уже содержит черновик, речь добавляется к нему для проверки;
автоматическое выполнение команды доступно при изначально пустом поле.

По умолчанию распознанные ограниченные команды телефона исполняются сразу:
сначала текст сохраняется в локальной истории, затем работает `PhoneCommands`.
Это объясняется в приветствии и подтверждении установки. В настройках голоса
можно включить проверку текста перед отправкой. Остальная речь всегда остаётся
в поле ввода; она не отправляется автоматически в LLM, облако или ПК.

Добавлены русские точные псевдонимы приложений и словесные проценты 0–100.
Похожие приложения не выбираются нечётким поиском; совпадения требуют выбора.
Медиакоманды/запуск обозначают отправку Android, а громкость читается после изменения.

`LocalVoice` выбирает установленный русский голос с `isNetworkConnectionRequired=false`
и без признака отсутствующих данных. Есть выбор, скорость, прослушивание и остановка.
Длинный текст делится на очередь частей. При отсутствии голоса предлагаются
системные настройки TTS; сетевой голос автоматически не выбирается.
Проверка основана на признаках, сообщённых установленным TTS-движком, а не на
независимом аудите его сетевого поведения. Собственные голоса Piper пока не загружаются.

Озвучка ответов включается прежним переключателем. В режиме ПК сохраняется прежняя
озвучка компьютером; в настройках можно явно выбрать синтез на телефоне. Сам текст
ответа получает выбранный на ПК провайдер, второй облачный TTS не подключается.

## Проверки и границы

Хостовые тесты исполняют настоящий Java-установщик на синтетических ZIP: сохранение
старого комплекта, повторное открытие указателя, замена, неверные SHA/MD5, неполная
загрузка, опасные пути, лимит распаковки, отмена до/после проверки и отказ движка.
Ни модель, ни акустическое качество такими тестами не имитируются.

На Windows одна ранняя попытка атомарного переименования получила AccessDenied;
добавлен ограниченный повтор для временно заблокированных файлов, без отказа от
атомарности. Последующие проверки установщика прошли.

Инструментальный APK содержит **12 тестов**, в том числе проверку четырёх тем
диалогов загрузки нативной библиотеки Vosk для ABI устройства и настоящего сканирования приложений с восстановлением псевдонимов. Они собраны,
но **не выполнены**: устройств/AVD нет. Реальная загрузка/продолжение архива,
установка модели, микрофон, ASR/TTS, фон/возврат и визуальная приёмка остаются открытыми.

Повтор настоящего loopback HTTPS-теста столкнулся с занятым портом 48443; процесс,
занимающий порт, не завершался. Этот тест отключается в итоговом наборе отдельно;
остальные регрессии шлюза проверяются через изолированные фикстуры.
Команды проверки — в [инструкции Android](android.ru.md).
