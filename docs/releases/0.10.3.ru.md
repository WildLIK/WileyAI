# WileyAI 0.10.3

- Исправлена команда из обращения «найти песню турбина туриста»: форма «найти», а также «поищи» и вежливое «можешь найти» вызывают настоящий поиск Яндекс Музыки.
- Исправлен запуск найденного результата в YandexMusicMod. Вместо синтетического нажатия отправляется нативное после наведения, с повторной проверкой конкретного результата и кнопки.
- Поиск подтверждает воспроизведение только при совпадении ID выбранного трека и продвижении его позиции. Другой трек, пауза, отсутствующее или застывшее время возвращают явное «запуск не подтверждён».
- «Так, включи её» повторяет последний запрос песни пользователя в том же чате. Выдуманное моделью название не используется для управления плеером.
- Неподтверждённые ответы модели вроде «Найдено: … Воспроизведение: …» блокируются до показа и озвучки.

Исправление проверено на установленном YandexMusicMod 5.86.0: поиск «турбина туриста» вернул «Турбина Туриста» исполнителя НейроGul'dan; нативное нажатие изменило ID текущего трека на выбранный, воспроизведение и продвижение позиции подтверждены. Иван Дорн в прежнем ответе был выдуман моделью. Проверка состояния плеера не является измерением слышимости через динамики.

Изолированный Electron-плеер принимает только настоящие события нажатия; проверены неверный трек, пауза, застывшая/недоступная позиция и повторный поиск уже играющей песни. Также прошли 50 проверок голосовых/desktop-модулей и 9 сценариев Electron.

Полная проверка ядра: 976 тестов прошли, 25 проверок необязательных живых компонентов пропущены.

Самостоятельная Windows-сборка проверена без системных Python/Node/Git, включая полный повторный запуск с сохранением профиля и настроек.

Установщик: `WileyAI-Setup-0.10.3-x64.exe`. После обновления перезапустите WileyAI; повторное подключение уже подключённого плеера не требуется.
