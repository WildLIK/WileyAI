# Android 0.11.0 — модель как мозг помощника

30.10.2026. Новый этап после 0.10.0/Gateway preview.

## Что изменилось

Модель теперь может предложить типизированный план Android-действий. Один реестр
из 29 инструментов используется локальной Qwen, прямым совместимым API,
экспериментальным ChatGPT SIWC и дополнительным Gateway. JSON и native calls
проходят одинаковую проверку, разрешения и подтверждение. Код модели не исполняется.

Добавлены свои заметки/напоминания, передача будильника часам с UI, открытие
системных настроек/календаря/поиска, чтение состояния устройства и явная погода по
городу. Для приложений/плееров повторно используются существующие каталог,
псевдонимы, предпочитаемые приложения и MediaController.

Раздел **Настройки → Мозг** отделяет локальную модель, прямое облако, аккаунт и
необязательный Gateway. Есть получение моделей API, адрес Gemini, безопасная
проверка native tools, отдельное разрешение передавать результаты инструментов
выбранному источнику и ручной резерв на локальную модель.

Вход ChatGPT реализован непосредственно на Android через официальный SIWC:
системный браузер, собственная регистрация, PKCE/state/nonce, проверка подписанной
личности, Keystore, refresh/revoke, динамический каталог, Responses/SSE.
**Реальный допуск личного аккаунта и именно WileyAI Android пока не подтверждён.**
Наличие реализации не равно успешной интеграции Plus или истории веб-чата.

Существующие API, локальные веса, ASR/TTS, фоновый вызов, последующий вопрос,
музыка/YouTube и локальная история сохраняются. Новые веса не скачивались.

Итоговые планы Qwen заняли 5.3–8.5 секунды каждый. Это не измерение
задержки полного голосового цикла. Первая версия модели добавляла `()` к названию
инструмента: валидатор отверг ответ без исполнения, затем grammar была ограничена
реальными названиями и полями. Для одиночной просьбы грамматика ограничивает план одним шагом; составной
запрос ограничивается числом поручений (максимум четыре). Удалены непрошеные
media tools для громкости. Повторные шаги отвергаются до первого действия.
Обнаруженный в Android несовместимый regexp flag устранён. Обычный разговор
локальной модели отделён от планировщика; модель не получает инструменты для
проверенного арифметического вопроса. Итоговый прогон выполнен.

Тест `brainNative` — подставная модель и реальные Android-вызовы. Его результаты
не могут служить проверкой облачного аккаунта. Ранее выполненные 30 физических
проверок 0.10.0 остаются историческими, не объявляются приёмкой новых функций.

Локальные журналы проверок находятся в игнорируемой папке
`local/review/brain-0.11.0/`; личные токены, пароли и содержимое настоящих чатов
в отчёт не включаются. Новая полная копия базы телефона не извлекалась.

`local/releases/WileyAI-Android-0.11.0-preview-debug.apk`, 54 787 819 байт.

Подпись совпадает с предыдущей установленной версией:
`4643c2b21b75084b431880154c9417a1fa42c1759f089df50a88768e4537a521`.

Android снова привязан к WileyVoiceService: `mBound=true`, `mService=...Stub$Proxy`.

## Известные ограничения и следующий этап

- Полный цикл нового исполнителя и повторный живой голосовой тест требуют
  разблокированного S23+; блокировка не обходится.
- Маленькая Qwen может неверно понять смысл корректного JSON. План показывается
  до изменений, сложные просьбы лучше делить. Четыре действия/180 секунд — предел,
  а не бесконечный агент. Быстрые простые команды не ждут LLM.
- В JSON fallback выполняется один план. Динамические зависимые цепочки
  «найди приложение → подставь найденное имя в следующий запрос» ограничены;
  native tools могут продолжить разговор с результатами в общем лимите.
- Запуск Intent, создание будильника и поиск в плеере не доказывают фактическое
  открытие/сохранение/воспроизведение. Результат явно отличает requested/verified.
- Напоминания принадлежат WileyAI и используют неточные системные alarms;
  уведомления/энергосбережение Android могут задержать доставку.
- Usage Access не включается автоматически; история приложений за вчера,
  чтение календаря/контактов, отправка сообщений и платежи не реализованы.
- Резервный мозг переключается вручную. Мультимодальные функции веб-сайтов и
  перенос их истории не являются готовой частью этого выпуска.
- Поддержанные прямые web OAuth DeepSeek/Qwen/GLM и готовые Android adapters
  Puter/Pollinations не подтверждены/не реализованы. Публичные cookies-прокси
  и чужие CLI client IDs не используются.

Следующая практическая приёмка: разблокированный телефон → полный локальный цикл
и отрицательные проверки → восстановление обычного APK/голосовой привязки →
вход владельца в официальный ChatGPT → каталог/ответ/probe инструментов, если
провайдер действительно выдаёт доступ. При отказе облака локальная работа
сохраняется; обход ограничений не добавляется.
