# WileyAI 0.4.0 — управление звуком Windows

Из чата, голосовой реплики и панели **Команды → Звук Windows** теперь можно менять системную громкость, отключать/включать звук и передавать медиаклавиши активному проигрывателю.

- «Громкость тридцать пять процентов», «можешь сделать тише?», «увеличь громкость на десять процентов».
- «Выключи звук», «включи звук», «следующий трек», «предыдущий трек», «переключи воспроизведение», «останови музыку».
- Ползунок применяется отдельной кнопкой, есть чтение текущего состояния. Черновик не сбрасывается при обновлении громкости.
- Отдельное разрешение **Управлять звуком и медиаклавишами Windows** в доступе к инструментам; действия и ошибки видны в журнале. Разрешение сохраняется при восстановлении резервных копий.
- Команды звука обходятся без LLM и дополнительных компонентов. COM-ресурсы освобождаются после запроса. Уже начатое действие Windows завершается до приёма следующей команды, его результат сохраняется при остановке ответа.

Меняется **системное устройство воспроизведения Windows по умолчанию**, которое может отличаться от динамика Уайли. Установка громкости сохраняет mute. Медиаклавиша воспроизведение/пауза переключает состояние; поддержка зависит от активного проигрывателя, его состояние WileyAI пока не читает. Остановка медиаплеера не заменяет Escape для озвучки Уайли.

Сверен исходный план, добавлена [дорожная карта](https://github.com/WildLIK/WileyAI/blob/main/docs/roadmap.ru.md) с незавершёнными возможностями и критериями готовности. Следующий приоритет — повторяющиеся напоминания, затем структурированное понимание задач/дат и чтение веб-страниц целиком.

Проверены 679 тестов ядра, 35 тестов голосового клиента и 14 проверок Electron. 22 проверки с настоящими моделями/сервисами пропущены, они требуют отдельных условий. Готовая сборка запускается с пустыми данными без Python/Node/Git в PATH; чтение настоящего Windows-аудиоустройства работает без докачки библиотек. Тестовые изменения громкости и медиаклавиши используют подставные адаптеры и не меняют звук пользователя.

Windows 10/11 x64, прототип. Установщик включает Python и ядро; веса, ключи и документы не включены. При обновлении полностью выйдите из WileyAI через трей перед запуском установщика. Данные установленной программы сохраняются отдельно; перенос из исходников выполняется резервной копией.

Установщик без подписи разработчика, SHA-256 — в `SHA256SUMS.txt`. Для скачивания из закрытого репозитория нужен доступ к GitHub; EXE можно передать отдельно.
