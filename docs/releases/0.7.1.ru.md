# WileyAI 0.7.1 — распознавание команд и кристаллическая Аврора

- Исправлена команда «прибавь громкость на 10», добавлены варианты «убавь», «звук», числительные и вежливые просьбы. Результат приходит от Windows.
- Искажённая короткая команда громкости вызывает уточнение. До подтверждения громкость не меняется; неясная фраза не получает выдуманный отчёт о выполнении.
- Whisper по умолчанию использует более тщательный поиск, русский словарь команд и имя ассистента. Точность/скорость можно выбрать в **Настройки → Микрофон и разговор**. Скачивать новую модель не требуется.
- В «Авроре» квадратная сетка заменена кристаллическими гранями и связями. Усилены градиенты фона и панелей всех трёх тем.
- Исправлено сохранение уточнений напоминаний с местным часовым поясом Windows после работы Piper.

Установите `WileyAI-Setup-0.7.1-x64.exe`, предварительно завершив WileyAI через трей. Данные и модели сохраняются. Синтетические команды проверены на Whisper small; точность живой речи зависит также от микрофона и записи.
