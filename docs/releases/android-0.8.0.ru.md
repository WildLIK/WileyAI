# WileyAI Android 0.8.0 — музыка, YouTube и последовательный разговор

28–29 октября 2026. Этап установлен и проверен на Samsung Galaxy S23+
(SM-S916B, Android 16). Сохраняются история, модели, сопряжение, выбранная озвучка
и системная роль помощника из 0.7.0.

## Музыка и YouTube

В **Компоненты → Музыка и YouTube** есть отдельный экран: выбранные приложения,
пауза/продолжение, предыдущий/следующий, перемотка на 30 секунд, текущее состояние,
поиск по названию и запрос воспроизведения. По желанию владельца оставлена
**КИОН Музыка**, для видео выбран **обычный YouTube**, а не установленный ReVanced.
Команда «открой YouTube» тоже использует этот выбор.

Примеры:

- «Пауза в Ютубе», «поставь Ютуб на паузу», «продолжи музыку».
- «Следующее видео», «предыдущая песня в КИОН Музыке».
- «Перемотай видео вперёд на тридцать секунд», «перемотай назад на минуту в музыке».
- «Перемотай на 2:30 в Ютубе», «начни видео сначала».
- «Какая песня играет», «какое видео в Ютубе».
- «Найди песню Вальс цветов», «найди видео про космос».
- «Включи на Ютубе Big Buck Bunny», «включи песню … в музыке».
- «Громкость 50 в Ютубе» меняет общий поток медиа Android, а не отдельную громкость приложения.

Команды направляются только в выбранные медиаприложения. Если несколько выбранных
плееров одновременно подходят для общей команды, WileyAI просит назвать плеер.
Явная команда YouTube не перенаправляется в КИОН при отсутствии видеосессии.
Неподдерживаемые действия не подменяются другими командами.

Состояние читается через `MediaSessionManager` / `MediaController`. После команды
до 3,5 секунды проверяется заявленное плеером состояние, позиция или смена трека.
Неизвестный результат так и обозначается; повторной команды для «уверенности» нет.
Идемпотентные play/pause не превращаются в слепое переключение. У КИОН учтена
публикация `ACTION_PLAY_PAUSE` без отдельного `ACTION_PAUSE` во время воспроизведения.
«Предыдущий» может вернуть начало текущего трека по правилам плеера; это отдельно
отмечается, без дополнительного нажатия, способного пропустить песню.

При отсутствии активной музыкальной сессии команда продолжения пробует публичную
`MediaBrowserService` выбранного приложения. Пустая очередь не означает успешное
воспроизведение: иногда сначала требуется выбрать один трек в самом плеере.
Поиск и запрос воспроизведения передаются адресованными Android intents.
Результат выбирает приложение; открытие поиска не называется началом песни.
Для КИОН подтверждён официальный маршрут `https://music.mts.ru/search?text=…`.
Произвольные сайты, внутренние API приложений, чтение экрана и автоклики в плеерах
в продукт не добавлялись.

## Системный доступ

Для адресованного управления и проверки результата Android требует доступ к
медиасессиям через **Доступ к уведомлениям**. На S23+ владелец отдельно разрешил
его включение. Кнопка настройки находится в том же разделе, там же доступ отзывается.

`MediaAccessService` защищён системным `BIND_NOTIFICATION_LISTENER_SERVICE`,
не экспортирован для сторонних приложений. В metadata задан пустой список типов
уведомлений и отключены conversations, alerting, silent, ongoing. Обработчиков
содержимого, чтения списка уведомлений, ответов, удаления уведомлений и управления
«Не беспокоить» в коде нет. Из медиасессий рассматриваются только выбранные пакеты.
Метаданные трека не отправляются в облако; ответ на команду может сохраняться
в локальном чате как обычный ответ помощника.

Без специального доступа прежние общие play/pause/next/previous остаются
медиаклавишами активному плееру с явным указанием, что результат не проверен.
Выбор конкретного плеера и точная перемотка требуют подключённого доступа.

## Следующий вопрос и режим разговора

После обычного ответа помощник подаёт сигнал и ещё **8 секунд** слушает следующий
вопрос без повторного вызова. Например: «Какая дата?» → ответ → сигнал → «А время?».
Это отдельная короткая сессия распознавания; собственная озвучка не прослушивается.
При тишине окно помощника закрывается и возвращается ожидание «Окей, Вайли».

**«Окей, Вайли, давай поговорим»** распознаётся одной фразой и включает разговор.
Можно также сказать «давай поговорим» после сигнала или нажать **Начать разговор**.
Между репликами ожидание составляет **30 секунд**. Выход: «Закончили», «Хватит
разговаривать», «Заверши разговор», «Спасибо, пока». При тишине разговор завершается.
Защитная граница — 20 ответов или 15 минут, затем помощника можно позвать снова.

В **Компоненты → Голосовой помощник** есть выключатель ожидания следующего вопроса,
короткие интервалы 3/5/8/12/15 секунд и интервалы разговора 15/30/60 секунд.
После запуска другого приложения автоматическое ожидание следующего вопроса
не продолжается. Сохраняются уведомление остановки, запрет открытия приложений
с заблокированного экрана и отдельная локальная история помощника.

## Исправление времени

Владелец подтвердил оба сценария разговора, но сообщил ответ «15:00» при времени
телефона 23:47. Причина установлена по последним временным запросам помощника:
ASR выдал **«время какое»**, эта форма не распознавалась прямой командой и ушла
в маленькую локальную LLM. Часы Android показывали правильное время и пояс
`Asia/Yekaterinburg`, +05:00.

Добавлены «время какое», «время сколько сейчас», «который сейчас час», «который час
сейчас», «скажи какое сейчас время» и разговорные продолжения «а …», «а теперь …».
Такие вопросы получают ответ из `ZonedDateTime.now()` телефона, без LLM.
Для вопросов о дате/времени модель также получает фактические дату, время и часовой
пояс с указанием приоритета над старыми ответами истории. Обычные вопросы не получают
лишних временных чисел: это существенно для небольшой Qwen3 0.6B. Запрос о длительности дороги не превращается в часы,
а поиск видео «какое время» остаётся поиском.
