# Проверка Android 0.10.0 на Samsung Galaxy S23+

30 октября 2026. Физический Samsung SM-S916B, Android 16, USB ADB.
Телефон обновлён **с 0.8.0 до 0.10.0**, versionCode 10, с прежней debug-подписью.
Это дополнение к [предыдущему отчёту](../gateway-validation.ru.md), где телефон
ещё не был доступен.

## Результат

**30 физических проверок прошли:** 28 сценариев регрессии, отдельный составной
Gateway-тест и заключительная проверка истории/текущего TTS. Gateway-сценарий
дополнительно повторён с raw-выводом для сохранения структурированных результатов.

| Проверено на телефоне | Результат |
| --- | --- |
| Обновление и история | Миграция SQLite v1→v2; исходный чат, его черновик и 14 сообщений сохранены. Контрольные суммы строк вычислены внутри телефона и совпали с исходными. После этого пользователь выполнил новый контрольный голосовой запрос, поэтому число сообщений может увеличиться. |
| Keystore | Сохранение/чтение Gateway-профиля через реальный Android Keystore; ciphertext не содержит токен. Перестановка ciphertext profile→pending отклонена через AAD. |
| Gateway HTTPS/SSE | Физический S23+ → USB `adb reverse` → временный Python Gateway на loopback HTTPS. Получены модели и 6 частичных обновлений первого ответа. Провайдер — явно тестовый, не облачная нейросеть. |
| Проверка сертификата | Обычный клиент отклонил недоверенный самоподписанный сертификат. Только экземпляр транспорта теста получил доверие к конкретному временному сертификату. Системное хранилище доверия и production TLS policy не менялись. |
| Восстановление | Симулирован потерянный ACK; Android восстановил тот же request_id без повторной генерации. Ответ и ссылки на источники сохранены локально однократно. |
| Ограничения | Неизвестный vision выключен; неподдержанное вложение вернуло 422, отменённый до отправки request_id — 409. Миграция и dedupe не воскрешают удалённый чат. |
| Интерфейс | Категории «Подключения», навигация компонентов/команд, отдельное окно приложений и диалоги четырёх тем проверены на устройстве. Экран подключений дополнительно просмотрен на реальном скриншоте. |
| Приложения и команды | Сканирование launcher-приложений, сохранение псевдонимов, команды даты/времени и управление громкостью прошли. Громкость изменилась с 6 до 4 при max15 и возвращена к 6. Это реальные значения AudioManager, не обещание одинаковой шкалы Samsung 0–150 и процентов. |
| Vosk | Синтезированная тестовая фраза распознана как «громкость пятьдесят процентов» → volume:50; команда из аудиофайла не исполнялась. Общие веса и отдельные декодеры: начальная проверка 877 мс, тёплая 44 мс. Это не замер полной задержки от живого микрофона. |
| Фраза вызова | Синтезированное «Окей Вайли» распознано как «окей вай ли» и принято; одно «Окей» не принято. После завершения instrumentation владелец отдельно подтвердил **живой фоновый вызов «Окей, Вайли» и голосовой ответ на «Сколько времени?»**. |
| Локальная Qwen | Установленная Qwen3 0.6B, 396 705 472 bytes, выполнила генерацию за 4060 мс и ответила «Два плюс два равно четыре». Проверка через интерфейс чата также сохранила правильный ответ. |
| Озвучка | Текущий движок `com.google.android.tts` произнёс короткую проверочную фразу; completion callback пришёл один раз. Это подтверждение выполнения, не субъективная оценка качества голоса. |

После instrumentation Android временно показывал `mBound=true mService=null`.
Обычный APK переустановлен с сохранением данных; подтверждено живое соединение
`IVoiceInteractionService$Stub$Proxy`. Через штатный интерфейс восстановлен ранее
разрешённый фоновый режим: `HandsFreeService isForeground=true`, уведомление77,
статус «Скажите „Окей, Вайли“». После этого пользователь подтвердил вызов голосом.
Тестовый пакет удалён; WileyAI оставлен свёрнутым с работающим голосовым вызовом.

Временный HTTPS fixture остановлен, USB reverse 48593 удалён, fixture asset удалён.
Ни один личный аккаунт нейросети не использовался. Production Gateway на телефоне
не настроен, тестовый токен/адрес не сохранены в пользовательском профиле.


Выводы находятся в `local/review/phone-0.10.0/`:
`gateway-device-raw.log`, `device-regression.log`, `final-checks.log`,
`host-gateway.log`, `build-clean.log`, `apk-signature.log`, `connections.png`.
Исходные сообщения/токены в отчёт не включены. Повторное копирование базы телефона
не выполнялось: заключительная сверка использовала только хеши, вычисленные Android.

В этом этапе **27 host-проверок Gateway прошли**, сборка/линт успешны:
0 ошибок и 30 предупреждений. В production-код добавлены package-private фабрики
транспорта для изолированных тестов; штатные конструкторы продолжают использовать
обычную HTTPS-проверку. Обновлены тесты версии схемы и счётчик сценариев runner.

Для повторения Gateway-теста из корня проекта: запустить
`python scripts/gateway-device-fixture.py` с `PYTHONPATH` на корень проекта,
пробросить `adb -s SERIAL reverse tcp:48593 tcp:49793`, собрать приложение и test APK,
затем выполнить:

```sh
adb -s SERIAL shell am instrument -w -r -e only gatewayDevice \
  ru.wildlik.wileyai.mobile.test/ru.wildlik.wileyai.mobile.StageOneInstrumentation
```

Сервер теста слушает только 127.0.0.1. Сгенерированный fixture JSON игнорируется Git
и входит только в test APK. По завершении остановить fixture через аутентифицированный
`POST /api/v1/fixture-shutdown` либо Ctrl+C, удалить reverse и fixture JSON, удалить
test package, восстановить обычный APK и проверить привязку/фоновый режим помощника.
Физические тесты вмешиваются в lifecycle voice service; не оставляйте устройство
в состоянии после instrumentation без этой проверки.

## Что остаётся непроверенным

Реальные облачные аккаунты/квоты/мультимодальность, публичный VPS/Docker/HTTPS,
мобильная сеть и длительный расход батареи. Локальный HTTPS fixture не заменяет
эту приёмку. Проверка не является полным сканированием всех установленных
приложений на совместимость с голосовыми командами или тестом всех функций YouTube.
