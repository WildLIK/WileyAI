# WileyAI 0.14.45

- На Android появилась первоначальная настройка разрешений, распознавания, озвучки и голосового вызова. К мастеру можно вернуться из настроек.
- Микрофон, уведомления и Bluetooth запрашиваются при выборе соответствующей функции. Текстовые команды доступны без этих разрешений и без разговорной модели.
- Регистрация голоса проверяет компонент CAM++ до записи фраз. В Android APK входит проверенная модель CAM++. Голосовой профиль хранится на телефоне.
- Сообщения о недостающих компонентах ведут к их настройкам. Для фонового вызова в публичной сборке доступен Vosk.
- Если Android не предоставляет русский офлайн-голос, экран озвучки показывает статус и открывает системные настройки голосов.
- При сетевом сбое загрузки Vosk, GigaAM и Qwen переключаются на резервный источник и продолжаются с сохранённого места. Загруженные файлы проверяются по SHA-256. Проверенные копии моделей доступны в отдельном наборе ресурсов на GitHub Releases.
