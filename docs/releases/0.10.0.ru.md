# WileyAI 0.10.0

- Отдельное локальное подключение Яндекс Музыки и YandexMusicMod в разделе «Команды»: плей, пауза, предыдущий/следующий трек, громкость плеера, добавление и удаление из любимых, поиск песни с запуском достаточно точного совпадения.
- После подключения голос и чат используют выбранный плеер. Результат проверяется чтением состояния и сохраняется в журнале; старые результаты поиска и неоднозначные совпадения не запускаются.
- Если плееру нужен перезапуск, программа показывает отдельную кнопку и предупреждение об остановке музыки. Файлы Яндекс Музыки и данные входа не меняются.
- Исправлены загрузка встроенных текстур VRM и положение камеры при изменении размера окна. Аватар остаётся видимым при озвучке и восстанавливает отображение после потери 3D-контекста.
- Журнал показывает последние действия первыми и понятные статусы подключения/уточнения.

[Подключение, команды и ограничения Яндекс Музыки](../yandex-music.ru.md). Канал управления проверяется на изолированном Electron-плеере; совместимость вошедшего в аккаунт пользовательского приложения проверяется при подключении. Это адаптер интерфейса приложения, а не публичный API Яндекса.

Установщик: `WileyAI-Setup-0.10.0-x64.exe`. WebSocket-компонент входит в базовое ядро; дополнительные модели для управления плеером не требуются.

Проверки: 908 тестов ядра, 50 проверок голосовых/desktop-модулей, 3 проверки камеры/встроенных текстур и 43 сценария Electron, включая настоящий VRM во время озвучки. 24 проверки живых компонентов Python и два сценария живых моделей Electron пропущены. Самостоятельный установщик проверен без системных Python/Node/Git и после повторного запуска. Пользовательская Яндекс Музыка в автоматических проверках не перезапускалась.
