# WileyAI 0.7.0 — стекло, подсветка и темы

- Три темы: тёмная «Аврора», светло-голубой «Ледяной свет», чёрно-красный «Красный контур».
- Полупрозрачные панели, мягкое свечение, общая палитра для чата, моделей, документов, настроек и других разделов.
- Быстрый выбор темы в верхней панели и отдельный раздел «Настройки → Оформление». Сохранение сразу, синхронизация окон и сохранение после перезапуска.
- Анимированные состояния ответа модели, поиска, документов, загрузок, микрофона и озвучки. Подготовка звука и воспроизведение показываются отдельно.
- Отключение прозрачности и уменьшение движения. Учитывается системная настройка уменьшения движения; в скрытых окнах анимации приостанавливаются.

Установите `WileyAI-Setup-0.7.0-x64.exe`, предварительно завершив WileyAI через трей. Данные и модели сохраняются. Новые модели или дополнительные компоненты для оформления не нужны.

Полупрозрачность относится к панелям внутри интерфейса. [Оформление и индикаторы](https://github.com/WildLIK/WileyAI/blob/v0.7.0/docs/appearance.ru.md).
