# Android 0.10.0 и WileyAI Gateway preview

30.10: [проверено и установлено на физическом S23+](android-0.10.0-device.ru.md).
Владелец подтвердил живой фоновый вызов «Окей, Вайли» и голосовой ответ.

Это первый отдельный удалённый Gateway, а не завершённая поддержка всех веб-чатов.

Добавлены серверный пакет `gateway`, versioned REST/SSE, owner isolation,
AEAD-хранилище сессий/истории/вложений, admin/client токены, динамические модели,
durable jobs, отмена по request_id, восстановление событий и защита от повторной
генерации. После server restart ответ помечается interrupted, скрытой отправки нет.

В Android: **Настройки → Нейросети → Подключения**, категории источников,
HTTPS-профиль под Android Keystore, системный браузер и loopback PKCE callback,
выбор модели и объявленных режимов, SSE-ответы/источники, условные вложения,
восстановление оборвавшегося ответа. Роль помощника, локальные команды, ASR/TTS,
локальная Qwen, прямые API и приватное подключение ПК сохранены.
SQLite телефона мигрирует v1→v2 добавлением таблицы дедупликации восстановлений,
без пересоздания чатов и сообщений.

ChatGPT SIWC реализован по документированному интерфейсу; подпись identity token,
nonce/state, refresh/revoke, discovery и terminal acknowledgement проверены на
mock-ответах. Сам веб-чат/история сайта и генерация изображений не обещаются.
Все остальные web services явно недоступны до поддержанного адаптера.
[Матрица](../gateway-support.ru.md), [исследование 24 репозиториев](../research/gateway-comparison.ru.md),
[VPS и вход](../gateway-deploy.ru.md), [архитектура](../gateway-architecture.ru.md).

Проверки и точные границы приёмки перечислены в
[отчёте о проверках](../gateway-validation.ru.md). Реальные аккаунты/VPS/телефон
не заменяются компиляцией и mock-тестами. APK с debug-подписью предназначен для
локальной проверки; публикационный signing key этим этапом не создаётся.
