# WileyAI 0.8.1

Исправления общей панели, «Туманности», сохранения списка приложений и управления плеером.

- **Поиск и разговор** находятся в верхней панели рядом с темой и доступны в других вкладках. Фаза «Слушаю вас» встроена в кнопку разговора. Из поиска по истории можно явно отправить введённый запрос в интернет через настроенный сервис.
- **«Туманность»** движется заметнее и продолжает анимацию в видимом окне без фокуса. Скрытое/свёрнутое окно останавливает фон. Настройки уменьшения движения приложения и Windows по-прежнему учитываются.
- **Список приложений сохраняется** после перехода между разделами и полного перезапуска. Уже добавленные команды доступны и до нового сканирования.
- **Проверка запуска приложения**: точный путь EXE и PID, отдельные результаты нового/уже работающего процесса и неподтверждённого запроса. «Команды → Журнал действий Windows» показывает реальные результаты инструментов и ошибки.
- **Музыка**: «запустим музыку», «поставь музыку на паузу», «продолжи музыку», «проверь проигрыватель». AIMP управляется через его Remote API, другие поддержанные плееры — через текущую медиасессию Windows. Повторная пауза не возобновляет плеер; ответ различает отправленную команду и подтверждённое состояние. При нескольких плеерах AIMP имеет приоритет.
- Исправлена форма **«открой Яндекс.Музыку»**. Типовые неподтверждённые заявления модели о запуске в коротких репликах об управлении заменяются уточнением до вывода и озвучки.

Подтверждённый процесс не гарантирует готовность окна; состояние плеера не гарантирует слышимость звука. Некоторые приложения не предоставляют медиасессию. Для неподдержанного плеера старые медиаклавиши остаются неподтверждённой передачей команды.

Установщик: `WileyAI-Setup-0.8.1-x64.exe`, контрольная сумма — в `SHA256SUMS.txt`. Пользовательские данные сохраняются отдельно.

Проверки: 858 тестов ядра, 44 проверки голосовых/desktop-модулей и 38 сценариев Electron прошли. 23 проверки живых компонентов Python и два сценария живых моделей Electron пропущены. Самостоятельная сборка без системного Python/Node/Git запустила отдельный тестовый EXE, подтвердила его точный путь/PID и запись журнала. Полный повторный запуск сохранил список приложений без сканирования, профиль, тему и расписание. Управление воспроизведением в автоматических тестах изолировано от личного плеера.
