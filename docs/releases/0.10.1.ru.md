# WileyAI 0.10.1

- Исправлено подключение установленного YandexMusicMod 5.86.0: поддержан внутренний адрес окна `music-application://desktop/` и чтение трека, когда ссылки не содержат ID, а Discord RPC выключен.
- Запуск через оболочку Windows поддерживает сборки с запросом прав администратора. Отмена системного подтверждения и отказ в доступе возвращают понятную ошибку, которая сохраняется в журнале.
- При перезапуске дескрипторы ожидания открываются до завершения процесса. Это устраняет `AccessDenied` при повторном открытии уже закрытого PID и последующий `Failed to fetch`.
- Выбор Яндекс Музыки сохраняется при попытке подключения. При недоступном соединении музыкальная команда не перенаправляется в другой плеер.
- «Включи песню», «включи трек», «сними песню с паузы» продолжают текущую песню. Просьба с исполнителем/названием остаётся поиском. Неподтверждённые заявления модели о проверке плеера заменяются пояснением.
- Громкость читается и при скрытой всплывающей панели. Ошибки подключения и ожидаемое подтверждение Windows видны в интерфейсе.

Исправление проверено на установленном пользовательском YandexMusicMod: соединение установлено, воспроизведение запущено, прочитаны ID/название/исполнитель и увеличение позиции трека. Автоматические проверки используют отдельные тестовые процессы и плеер.

Установщик: `WileyAI-Setup-0.10.1-x64.exe`. После обновления перезапустите WileyAI. Перезапускать уже подключённую Яндекс Музыку не требуется.

Проверки: полная проверка ядра — 919 пройденных и 24 пропущенных теста живых компонентов; после добавления обработки опечатки отдельно прошёл 171 тест звука, подключения и запуска. Также прошли 50 проверок голосовых/desktop-модулей, 9 сценариев Electron и запуск самостоятельной сборки без системных Python/Node/Git с повторным запуском.
