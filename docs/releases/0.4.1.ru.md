# WileyAI 0.4.1 — исправление повторного запуска

Исправлено зависание на «Запускаю локальное ядро…» с ошибкой `Cannot read properties of undefined (reading 'url')`. Повторный запуск во время загрузки Python мог создать окно раньше, чем ядро сообщало свой адрес. Интерфейс сохранял пустое подключение и уже не восстанавливался после готовности ядра.

- Все окна ожидают общее подключение, готовность подтверждается `/health`.
- Второй экземпляр не запускает дополнительное ядро. Готовое свёрнутое окно восстанавливается.
- Адрес порта считывается только из полной строки stdout, включая случай разделения строки на несколько порций.
- Интерфейс проверяет ответ IPC перед запуском запросов. При ожидании есть анимированная полоса; при некорректном подключении — понятная ошибка и кнопка повторного подключения.
- Исправлена очистка файлов автоматических проверок: временные данные Playwright, pytest и готовой сборки направляются в `local/test-runs`, удаляются после прогона; остатки прерванных запусков очищаются при следующем запуске проверок. Модели и пользовательские данные не удаляются.

До исправления ошибка воспроизведена в Electron с намеренно задержанным настоящим процессом Python и повторным запуском приложения. После исправления проверены ожидание ядра, один процесс/окно, восстановление свёрнутого окна, повторный запуск с прежними данными, некорректный ответ IPC и кнопка повтора. Проверено, что очистка тестовой ссылки на модель сохраняет её целевой файл.

Проверки: 679 тестов ядра (22 проверки с настоящими моделями/сервисами пропущены), 44 проверки клиента и 12 проверок Electron; запуск готовой сборки с пустым профилем без системных Python/Node/Git и её полный перезапуск с сохранённой памятью.

Windows 10/11 x64, прототип. Для обновления полностью выйдите из WileyAI через трей, затем запустите установщик. Переустановка не требует удаления личных данных или моделей. Репозиторий закрытый: человеку без доступа можно передать EXE. Установщик без подписи разработчика; SHA-256 — в `SHA256SUMS.txt`.
