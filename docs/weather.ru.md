# Погода

Доступно в 0.12.0. Прогноз получается напрямую из Open-Meteo, место — из GeoNames через геокодирование Open-Meteo. Модель общения, SearXNG/Brave и ключ API для этого не нужны.

## Настройка и запросы

В **«Настройки → Поиск → Погода»** включите получение погоды, укажите основной город и нажмите общую кнопку «Сохранить». Например, `Москва, Россия`. При необходимости можно добавить регион, чтобы различить одноимённые места.

Примеры для чата и распознанной речи:

- «Какая сейчас погода?» — основной город.
- «Погода завтра в Москве, Россия» — отдельное место без смены основного города.
- «Погода послезавтра в Москве, Россия».
- «Покажи прогноз на неделю» — семь дней, начиная с сегодняшнего по времени выбранного места.
- «Погода через 3 дня в Москве, Россия» — один день в пределах ближайших семи дней.

Другие даты и почасовой прогноз не поддержаны. Неоднозначный период требует уточнения. Если справочник возвращает несколько мест, WileyAI предлагает уточнить регион или страну; крупнейший город автоматически не выбирается. Автоматического определения местоположения нет.

В этом же разделе есть отдельная кнопка **«Проверить погоду»**, выбор периода и поле **«Другой город для проверки»**. Пустое поле использует основной город из формы. Нажатие явно разрешает один запрос, даже если постоянное разрешение для чата выключено. Проверка не сохраняет город и не включает погоду в чате. При смене города, периода или DNS старый результат очищается, ожидающий запрос отменяется.

## Что показывается

Для сегодняшнего дня видны текущая расчётная температура, ощущаемая температура, состояние неба и ветер в м/с; на каждый день — минимум/максимум и максимальная вероятность осадков. Есть дата прогноза, местное время расчёта, часовой пояс и время получения. Это модельный прогноз Open-Meteo. В сообщении чата сохраняются ссылки на прогноз и найденное место вместе со временем проверки.

Запросы проверяют координаты, единицы, числа и структуру данных. При сетевой ошибке, неоднозначном месте или некорректном ответе сервиса WileyAI сообщает об ошибке; ответ модели не используется вместо полученного прогноза.

### Верхняя панель — локальные изменения после 0.12.0

В общей шапке доступны дата по времени выбранного города, значок состояния, температура и «Ощущается». Нажатие открывает настройки погоды. На узком окне текст состояния скрывается, значок и ощущаемая температура остаются. Примеры используют Москву; сохранённое место пользователя не заменяется.

Панель запрашивает погоду только после сохранения разрешения и города. Черновик настроек и отдельная проверка другого места на неё не влияют. Обновление — раз в 30 минут в видимом окне; ядро делит один кеш между окнами. Переключение вкладок не перезагружает прогноз. При ошибке сохраняется предыдущий результат с отметкой «нет обновления», повтор — через 5 минут. Для другого города старый прогноз не показывается. Без разрешения сетевых запросов панели нет.

Перед синтезом Silero числа, даты и единицы прогноза преобразуются в слова: например, `-2.9 °C` — «минус две целых девять десятых градуса Цельсия». В чате остаётся исходная запись. Это локальная подготовка текста без модели общения и сетевого запроса.

## Сеть и данные

Геокодер получает название места, погодный сервис — его координаты. История чата и документы им не отправляются. Свободный API Open-Meteo предназначен для некоммерческого использования; условия сервиса нужно учитывать отдельно при коммерческом распространении.

При VPN с fake-IP системный DNS может возвращать служебные адреса: загрузчик их отклоняет. В разделе «Поиск» можно выбрать публичный DNS Cloudflare через HTTPS. Этот параметр действует только на загрузчик WileyAI и не меняет DNS Windows. Соединение привязано к проверенному публичному адресу с проверкой TLS имени сервера; переходы на локальные адреса запрещены.

## Проверки

Тесты ядра покрывают русские фразы, выбор региона, отдельный город, семь дней, ошибки данных, разрешения и отсутствие вызова модели. Сценарий Electron проверяет форму, карточки дней, отмену устаревшего результата и сохранение основного города при навигации. Внешние ответы в автоматических тестах подставные. Отдельно 20 октября выполнены настоящие запросы для двух населённых пунктов через публичный DNS; получены прогнозы и местные временные метки.

Документация источников: [прогноз Open-Meteo](https://open-meteo.com/en/docs), [геокодирование Open-Meteo / GeoNames](https://open-meteo.com/en/docs/geocoding-api).
