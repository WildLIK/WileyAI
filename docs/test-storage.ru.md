# Временные файлы проверок

Папки `wileyai-conversation-*`, `wileyai-e2e-*`, `wiley-settings-layout-*` и другие перечисленные в скрипте очистки профили создавались автоматическими тестами. Обычная работа WileyAI их не создаёт. Каждый профиль содержит тестовую SQLite-базу и отдельный Chromium/Electron-профиль с кэшем, поэтому частые прогоны раньше оставляли много одинаковых каталогов.

С версии 0.4.1:

- Playwright, `npm test` и проверка готовой сборки используют `local/test-runs/run-*` внутри проекта. TEMP/TMP дочерних процессов направляются туда же; для pytest задаётся отдельный `--basetemp`, если пользователь не указал свой.
- После прогона, в том числе при ошибке теста, временный каталог удаляется. Скриншоты и отчёт остаются в обычных каталогах результатов.
- Перед следующим запуском удаляются оставшиеся каталоги с маркером владельца, если создавший их процесс больше не существует. Активные прогоны пропускаются.
- Перед удалением проверяются абсолютный путь внутри `local/test-runs`, имя каталога, отсутствие перенаправления корня и маркер конкретного прогона. Ссылки на модели удаляются как ссылки; целевые веса сохраняются. Это отдельно проверено тестом.

Произвольная папка в `Temp`, исходные `data`, установленная программа, реальные модели и личные чаты в эту очистку не входят. Расположение пользовательских данных и моделей не менялось. Временная запись распознавания речи удаляется в `finally`; она не является многомегабайтным тестовым профилем.

## Старые профили в системном Temp

Скрипт `scripts/cleanup-test-profiles.ps1` распознаёт только прежние имена автоматических профилей с тестовой базой и каталогом Electron. Он не очищает Temp целиком. Каталоги с ссылками, неполной структурой или возрастом менее 10 минут пропускаются.

Просмотр без удаления, из каталога проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/cleanup-test-profiles.ps1
```

Удаление найденных старых профилей:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/cleanup-test-profiles.ps1 -Clean
```

Файлы установщиков других программ, включая Visual Studio, этим скриптом не затрагиваются.
