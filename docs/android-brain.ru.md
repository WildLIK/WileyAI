# Мозг Android-помощника WileyAI

30.10.2026, Android 0.11.0. Собственный сервер не обязателен.
Это этап инструментального помощника, а не обещание доступа к любому веб-аккаунту.
Состояние физических испытаний — в [отчёте выпуска](releases/android-0.11.0.ru.md).

## Как начать на телефоне

Откройте **Настройки → Мозг**. Выберите основной источник:

1. **Локальная модель** — уже установленная Qwen3 0.6B. Нажмите
   «Использовать локальную модель». Включённое «Понимать просьбы и предлагать
   действия» разрешает модели составлять планы. Скачивание других весов не нужно.
2. **ChatGPT · вход аккаунтом** — экспериментальный официальный SIWC.
   «Continue with ChatGPT» открывает официальный сайт в системном браузере.
   После возврата нажмите «Выбрать модель / проверить вход» и выберите модель
   из ответа OpenAI. Если доступ не выдан, продолжайте локально. Наличие Plus
   само по себе не подтверждает допуск конкретного Android-клиента.
3. **Прямое облачное подключение** — совместимый API самого сервиса.
   Для Gemini есть подготовленный адрес: получите свой ключ в официальном
   кабинете, вставьте его, нажмите «Получить модели», выберите модель и сохраните.
   Затем включите облачный разговор и подтвердите передачу текста. Бесплатная
   квота не означает отсутствие ключа; регион и тариф проверяются провайдером.
   Для другого совместимого API укажите его официальный HTTPS endpoint.
4. **Дополнительные подключения → Свой Gateway** — сохранённый добровольный
   вариант для владельца сервера. Для первых трёх вариантов он не нужен.

Для инструментов облачной модели отдельно нажмите
**«Разрешить инструменты выбранному облаку»**. Это разрешение связано с выбранным
источником/моделью и не переносится автоматически другому провайдеру.
«Проверить подключение и native tools» отправляет безопасную тестовую функцию
без данных телефона; она не выполняет действий, но расходует квоту аккаунта.
Если native tools не подтверждены, применяется проверяемый JSON fallback.

Примеры после выбора модели:

- «Будь добра, установи для музыки 30 процентов громкости».
- «Открой Telegram и сделай громкость 30 процентов».
- «Открой настройки Bluetooth».
- «Сохрани заметку: купить фильтр».
- «Напомни завтра в 18:00 купить продукты».
- «Какая погода в Екатеринбурге?».

Перед планом с изменениями или чтением личных данных WileyAI показывает шаги.
Нажмите «Выполнить» либо скажите «да» в голосовом помощнике. «Отмена» останавливает
новые шаги. Уже выполненное действие не откатывается автоматически.
Простые команды времени, даты, приложений, громкости и плеера продолжают
выполняться быстрым локальным обработчиком, когда формулировка однозначна.

Голос: «Окей, Вайли» → «Слушаю» → просьба → при необходимости подтверждение
плана → результат. Распознавание, синтез, следующий вопрос и режим разговора
сохраняются на Android. Введённый текст и распознанные слова используют один цикл.

## Архитектура

ASR / текст → быстрые команды → ModelManager → BrainProvider → BrainController
→ AndroidTools.validate → ToolRun → ToolPermissionManager → AndroidToolExecutor
→ проверенный Result → выбранная модель → фактический короткий ответ / TTS.

| Компонент | Ответственность |
|---|---|
| LocalProvider | Существующие веса и llama.cpp на Android, ограниченная JSON grammar |
| DirectCloudProvider | Явно настроенный совместимый endpoint без обязательного ключа; готового анонимного сервиса не подставляет |
| OfficialAPIProvider | Прямой совместимый API с добровольно заданным ключом |
| AccountOAuthProvider | Официальный прямой SIWC/Responses; фактический допуск требует живой проверки |
| RemoteGatewayProvider | Сохранённый дополнительный сервер, REST/SSE/отмена |
| AndroidTools / StrictJson | 29 разрешённых операций, типы, диапазоны, обязательные/лишние поля, ограничения JSON |
| BrainController / ToolRun | До 4 модельных раундов и 4 действий, одна попытка исправить схему, подтверждение и отмена |
| AndroidToolExecutor | Только локальные проверенные вызовы Android; модель не создаёт Intent/код |

В native-режиме результаты возвращаются с исходными tool_call_id; модель может
предложить следующие шаги в общем лимите. Для маленькой локальной модели разговор отделён от планировщика по намерению: это
ограниченная эвристика, не гарантия понимания любой фразы. Набор релевантных
инструментов сокращается для контекста Qwen; одиночное поручение ограничено одним
шагом, составное — числом явно найденных поручений до четырёх. Облачный провайдер
может выбирать инструменты семантически в общем лимите.
В JSON fallback выполняется один
подтверждённый план. Его фактические результаты возвращаются модели для продолжения,
а голосовой итог берётся из результатов исполнителя. Произвольный ответ модели
не заменяет проверку результата и не запускает дополнительные скрытые действия.

Локальная модель получает небольшой контекст предыдущего ответа; это не полная
агентная память. Резервная локальная модель выбирается и включается вручную.
Автоматической передачи локальных данных в облако и скрытого сменного провайдера нет.

## Возможности и границы

| Группа | Реализация | Проверка результата / ограничение |
|---|---|---|
| Приложения | Названия launcher apps, поиск, безопасный запуск | Неоднозначность требует уточнения; запуск Intent сам по себе не доказывает foreground |
| Музыка / YouTube | Play, pause, next, previous, состояние, поддержанный поиск | Доступ к медиасессиям выдаётся владельцем; проверяются состояние/метаданные; поиск не равен воспроизведению |
| Громкость | Установить, повысить, понизить, прочитать | AudioManager записывается и читается повторно; Samsung 0–150 отличается от процентов максимума |
| Устройство | Батарея, модель/Android, подключение, дата/время | Без идентификаторов, IP/SSID и чтения экрана |
| Настройки | Открыть Wi-Fi, Bluetooth, настройки приложения | Защищённые переключатели не меняются программно |
| Личные записи | Свои заметки/напоминания WileyAI, просмотр списка | Своя SQLite; уведомления требуют разрешения, AlarmManager неточный; после перезагрузки расписание восстанавливается |
| Будильник | Передать время в приложение часов с UI | Не заявляется запись/проверка закрытой базы часов; окончательная проверка владельцем в часах |
| Календарь | Открыть выбранное приложение календаря | Чтение/запись событий не реализованы, разрешения на них не запрашиваются |
| Недавнее приложение | Последнее resumed событие за 10 минут | Только с Usage Access; история «чем пользовался вчера» не реализована |
| Интернет | Открыть поиск по тексту | Не читает найденные страницы и не выдаёт их за исследование |
| Погода | Прямой документированный Open-Meteo по явному городу | HTTPS, без GPS; одноимённые города требуют уточнения; персональные некоммерческие условия сервиса |

Полномочия модели не отменяют разрешения Android. Для модельных инструментов
телефон должен быть разблокирован. Доступ к уведомлениям/Usage Access/показу
напоминаний не включается скрыто. Shell, root, произвольный код, Accessibility
автоматизация, контакты, отправка сообщений и платежи не предоставлены.

## Авторизация и конфиденциальность

Прямой SIWC использует собственную динамическую регистрацию, системный браузер,
одноразовый loopback 127.0.0.1, PKCE S256, state и nonce, проверку подписи OIDC
по официальным JWKS, issuer/audience/срока/subject. Токены защищены Android
Keystore; HTTPS не принимает произвольный сертификат. Сессии браузеров и других
приложений не читаются. ID моделей приходят из доступного каталога.

Отключение удаляет локальные данные авторизации и пытается отозвать refresh token.
Если отзыв не подтверждён сетью/провайдером, интерфейс сообщает об этом. Пароли,
cookies, токены и личные записи не выводятся в журнал. Ограничения допуска SIWC
описаны в [сравнении прямых подключений](research/android-direct-brains-2026-10-30.ru.md).

В облако по отдельному согласию могут передаваться результаты запрошенных
инструментов: названия приложений, состояние плеера/устройства, собственные
напоминания WileyAI. Они считаются недоверенными данными, а не инструкциями.
Любое следующее изменение снова проходит валидатор и подтверждение.

## Сборка и проверки

Сборка сохранена в `scripts/build-android.ps1 -Check`. JVM/pytest проверки:
`tests/test_android_tools.py`, `tests/test_android_identity.py`; Android fixture
проверки — `BrainProbe`, instrument runner `StageOneInstrumentation`.

`-e only brainConversation` проверяет обычный ответ настоящей модели без инструментов.
`-e only brainPlans` проверяет настоящие ответы установленной Qwen без исполнения.
`-e only brainLoop` проверяет полный цикл с реальным изменением громкости и
восстановлением исходного значения. `-e only brainNative` использует **подставную
модель**, но реальный исполнитель и громкость: возврат результатов, отказ,
отмена до исполнения и неизвестный инструмент. Это не проверка облачного аккаунта.
Инструментальные проверки требуют разблокированного тестового телефона.

После instrumentation Android может разорвать привязку VoiceInteractionService.
Нужно вернуть обычный APK и проверить живую привязку/голосовую активацию, прежде
чем объявлять фоновый помощник проверенным. История и сохранённые аккаунты при
обновлении не удаляются. Реальные результаты и оставшиеся шаги фиксируются в
[отчёте 0.11.0](releases/android-0.11.0.ru.md).
