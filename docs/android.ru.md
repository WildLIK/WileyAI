## Возможности

- Приложение открывается без ПК и интернета. Телефонные чаты, черновики и настройки
  хранятся локально. Есть создание/выбор/переименование/подтверждаемое удаление чатов.
- Текстовые команды запуска приложений, музыки и громкости не требуют LLM.
  Например: «открой Телеграм», «пауза», «следующий трек», «громкость пятьдесят процентов».
  Одинаковые названия требуют выбора приложения. Статус запуска/медиа — передача Android;
  фактическая громкость читается после изменения.
- Локальный русский ASR через устанавливаемый комплект Vosk; запись начинается кнопкой
  микрофона, завершается первой фразой, кнопкой ■ или через 15 секунд. При уходе в фон
  сессия чата отменяется и не выполняет позднюю команду. Отдельный режим системного
  помощника поддерживает включаемое пользователем ожидание фразы в фоне.
- Озвучка установленным русским офлайн-голосом Android: выбор, скорость, высота, прослушивание,
  остановка. Сетевые голоса автоматически не подставляются. Возможности зависят от
  установленного TTS-движка; собственный набор голосов Piper ещё не подключён.
- Четыре палитры WileyAI применяются к экрану и всем диалогам: «Аврора», «Ледяной свет»,
  «Красный контур», «Туманность». Системный режим выбирает светлую/тёмную палитру.
  Фоны статичные, без тяжёлой анимации. UI пока использует Java/Views.
- Удержание сообщения: копирование или перенос своего текста в поле для повторной
  отправки. Базовый Markdown: заголовки, жирный текст, строчный/блочный код.
- Телефонная история сначала показывает 200 последних сообщений; предыдущие доступны
  кнопкой вверху. Задачи/заметки ПК остаются в пространстве ПК.
- Сохранены сопряжение, pinning, потоковые чаты/остановка, задачи/заметки и голос через ПК.

Локальный разговорный чат Qwen3 0.6B работает через llama.cpp на поддерживаемых 64-битных Android. Веса устанавливаются отдельно. В «Компоненты → Облачные чаты» можно настроить совместимый Chat Completions API или свой HTTPS-мост и отдельно включить отправку контекста. По умолчанию этот режим выключен.

## Локальная разговорная модель

Откройте **Компоненты → Разговорная модель → Скачать / продолжить**.
В каталоге пока один проверенный файл: **Qwen3 0.6B Q4_K_M**, 378,3 МиБ.
Нужно 600 МиБ свободного места; по умолчанию только Wi-Fi. Есть пауза/продолжение,
SHA-256, пробная загрузка движком и импорт точного файла `Qwen3-0.6B-Q4_K_M.gguf`.
Произвольные GGUF, другие квантизации и большие модели пока не принимаются.

На проверяемом S23+ модель уже установлена. Нажмите **Открыть чат телефона**:
обычные вопросы обрабатываются на телефоне, команды приложений/медиа/громкости
обрабатываются отдельно и не нуждаются в LLM. Ответ модели не исполняется как команда.
Контекст — до 2048 токенов, ответ — до 256 токенов/90 секунд, есть остановка.
Модель выгружается после ответа. Отменённый/незавершённый ответ помечается.

Это очень небольшая модель: она может ошибаться даже в простых вопросах и хуже
следует инструкциям, чем крупные модели. Это рабочий начальный каталог, а не
заявление о высоком качестве русского диалога. Метаданные:
[Qwen3 и runtime](research/android-llm-catalog.json).

## Предпочитаемые приложения и команды

В **Компоненты → Музыка и YouTube** находятся выбор плееров, пауза/продолжение,
следующий/предыдущий, перемотка, состояние и поиск по названию. На S23+ выбраны
КИОН Музыка и обычный YouTube. Для адресованного управления включите доступ
к медиасессиям кнопкой в этом разделе. Android выдаёт его через доступ к уведомлениям;
их доставка в WileyAI отключена, тексты уведомлений не читаются.

«Пауза в Ютубе», «продолжи музыку», «следующее видео», «перемотай на 2:30 в Ютубе»,
«перемотай видео вперёд на тридцать секунд», «какая песня играет», «найди песню …»
и «найди видео …» работают как отдельные команды. Изменения проверяются по состоянию
плеера. Неподдерживаемая команда или отсутствие подтверждения явно сообщаются.
Для «включи видео … на Ютуб» WileyAI предлагает конкретные публичные ролики;
скажите «да»/номер либо нажмите результат. Автозапуск первого результата включается
в настройках плееров. Если публичный поиск недоступен, открывается поиск YouTube.
Музыкальный запрос по названию обрабатывает плеер; результат поиска
не объявляется началом воспроизведения. При пустой очереди сначала выберите трек
в самом музыкальном приложении.

В **Команды** выберите **Телеграм / мессенджер** и **Музыка**. В текущем сеансе
по просьбе владельца S23+ выбраны Nimarkogram и КИОН Музыка. «Открой Телеграм»
и «открой музыку» разрешаются в выбранные приложения, даже при наличии других клиентов.
Прямые названия приложений и свои псевдонимы тоже работают; неточного автоматического
запуска по похожему имени нет. Сканирование не добавляет иностранные слова в акустический
словарь Vosk: для нестандартного имени используйте обычное русское название команды.

Поддержаны «прибавить громкость», «сделай погромче», «сделай музыку потише»,
«увеличь громкость на десять процентов», «громкость до пятидесяти процентов»,
«выключи звук», «верни звук», «следующая песня», «пауза». Громкость относится
к потоку музыки и проверяется чтением после изменения. Медиакоманды адресуются
активному плееру Android; запуск приложения сам по себе не подтверждает воспроизведение.
Без LLM доступны также «сколько времени», «какая сегодня дата», «уровень заряда».

## Распознавание и улучшенная озвучка

**Компоненты → Распознавание речи → Распознавание**:

- **Vosk** — выбран по умолчанию, работает локально после установки комплекта.
- **Android · системная служба** — может использовать серверы и интернет;
  перед включением показывается отдельное объяснение и выбор пользователя.
- **Android · только на устройстве** — предлагается при наличии такого движка;
  русский язык должен поддерживаться/быть установлен в нём. Автоматического перехода на сеть нет.

Vosk проверен живым голосом владельца в режиме помощника. Точность системного
распознавателя и качество в шуме отдельно не оценивались. Аудиофайлы окружающей
речи не сохраняются. Частичные и окончательные расшифровки видны в интерфейсе.

На S23+ внутри WileyAI вместо Irina выбран установленный **Google TTS**, русский
офлайн-голос, темп 1,1× и высота 1,08×. Системный TTS Samsung не перенастраивался.
**Компоненты → Озвучка ответов → Выбрать движок озвучки** позволяет сравнить
Google/Samsung и отдельно установленную Irina; у каждого голоса есть «Прослушать».
Темп и высота регулируются отдельно. Субъективное качество следует оценить на слух.
Piper Irina не включён в APK WileyAI:
[источник и SHA-256](research/android-irina-voice.json),
[официальные TTS APK](https://k2-fsa.github.io/sherpa/onnx/tts/apk-engine.html).

## Вызов голосом и цифровой помощник Android

Откройте **Компоненты → Голосовой помощник → Назначить WileyAI помощником**.
На S23+ с текущей One UI: **Цифровой помощник → Цифровой помощник → шестерёнка
у «Других приложений» → WileyAI**. Затем вернитесь в WileyAI и включите
**Голосовую активацию**, разрешив микрофон и уведомления.

Скажите **«Окей, Вайли»**, дождитесь **«Слушаю»** и сигнала, затем произнесите команду. Ответ звучит
автоматически, затем снова включается ожидание. Вызов работает в фоне.
Кнопка **Фраза** предлагает также «Привет, помощник» и «Слушай, помощник».
Системный жест/кнопка помощника запускает команду сразу; постоянный микрофон
для такого вызова можно оставить выключенным.

По умолчанию после ответа есть ещё **8 секунд** на следующий вопрос без повторного
вызова. Например: «Какая дата?» → ответ и сигнал → «А время?». Тишина завершает
короткий сеанс. **«Окей, Вайли, давай поговорим»** включает разговор с ожиданием
следующей реплики до **30 секунд**. Выход: «Закончили» или «Хватит разговаривать».
Интервалы и выключатель короткого ожидания находятся в разделе голосового помощника.
Для защиты от бесконечного разговора сеанс ограничен 20 ответами/15 минутами.
Время и дата берутся из Android; поддерживается и форма «время какое».

Фоновая служба постоянно показывает уведомление **Остановить**. Программное
распознавание увеличивает расход батареи. На заблокированном экране доступны
время/дата/заряд и аудио; для открытия приложений и разговора с историей нужна
разблокировка. Текст сохраняется в отдельном чате, аудиофайлы не создаются.
После принудительной остановки/ограничения батареи может понадобиться снова открыть
приложение. Если Android потерял привязку службы, экран показывает это отдельно:
повторно выберите WileyAI в настройках помощника. [Подробности и проверки](releases/android-0.7.0.ru.md).

## Первый запуск и установка речи

1. Установите APK поверх предыдущей версии, сохранив данные приложения. Откроется чат.
2. Для текстовых команд установка моделей не нужна.
3. Для голоса откройте **Компоненты → Распознавание речи → Скачать**. Комплект
   `vosk-model-small-ru-0.22`, русский язык, Apache-2.0, архив **46 236 750 Б / 44,1 МиБ**.
   Перед загрузкой показывается подтверждение. Нужны 400 МиБ свободного места с запасом;
   это бюджет установки, а не объявленный распакованный размер.
4. По умолчанию загрузка разрешена только по Wi-Fi. Есть переключатель любой сети,
   прогресс, остановка с сохранением части файла и продолжение. При обрыве основной
   источник заменяется закреплённой копией на Hugging Face с теми же контрольными суммами. При потере Wi-Fi
   загрузка не переходит автоматически на мобильную сеть.
5. Можно импортировать точный официальный ZIP через системный выбор файла.
   Произвольные версии Vosk, GGUF и sherpa-модели этим импортом не поддерживаются.
6. Приложение проверяет размер, SHA-256, MD5, пути ZIP и распакованный размер,
   затем действительно загружает модель Vosk и декодирует тишину. Прежний комплект
   заменяется только после успеха. Это ещё не проверка точности русской речи.
7. Вернитесь в чат и нажмите микрофон. Разрешение запрашивается только для записи.
   По умолчанию ограниченные команды телефона выполняются сразу после распознавания.
   **Команды → Выполнять голосовые команды сразу** (выключить) включает проверку текста.
   Остальная речь остаётся в поле ввода и никуда автоматически не отправляется.
8. Для озвучки откройте **Компоненты → Озвучка ответов**, выберите голос и включите **Озвучивать ответы**. Карточки показывают движок, язык и оценку качества, сообщённую движком; каждый голос можно прослушать до выбора.
   Если голоса нет, используйте **Другие движки и сведения → Добавить голоса в Android**; размер его загрузки и условия
   показывает системный движок. WileyAI самостоятельно такие голоса не скачивает.

После установки ASR сеть и ПК для распознавания и телефонных команд не нужны.
Запуск сайта может требовать интернета. Установленный TTS-движок сам сообщает
приложению, что голос офлайн; независимый аудит его сетевого поведения не выполнялся.
Для чата ПК достаточно локальной сети, если его модели локальные; облачный провайдер
на ПК и Tailscale за пределами дома требуют соответствующей сети.

Размер/MD5 комплекта взяты из [официального каталога](https://alphacephei.com/vosk/models/model-list.json).
SHA-256 взят из [LFS-метаданных закреплённой копии](https://huggingface.co/localstack/vosk-models/blob/a0cabdd6801bd201c783afcc096208cde59fa182/vosk-model-small-ru-0.22.zip),
а не объявляется официальным SHA автора Vosk. Принимается только архив, совпавший
с обеими суммами. [Метаданные и происхождение](research/android-speech-catalog.json).

## Установка и сопряжение

1. На компьютере запустите версию WileyAI из проекта, содержащую раздел **Настройки → Телефон**. Выпущенный ранее установщик 0.14.0 этой функции не содержит.
2. Установите на телефон собранный `WileyAI-Android-0.6.0-debug.apk`. При установке из файла Android может попросить разрешить установку из выбранного приложения. Это тестовая сборка для самостоятельной установки.
3. В WileyAI на компьютере откройте **Настройки → Телефон**, нажмите **Включить подключение**, выберите адрес компьютера и покажите QR-код. Код действует пять минут и используется один раз.
4. Откройте QR камерой телефона или сканером. Если сканер не открывает ссылку WileyAI, скопируйте её текст и вставьте в приложение на телефоне. Подтвердите подключение в приложении. Без ссылки подключение открывается через **Компоненты → Использование ПК → Подключить компьютер**.
5. Для дома подключите телефон и компьютер к одной локальной сети. При запросе брандмауэра Windows разрешите WileyAI входящие подключения в частной сети. После изменения сетевых адресов нажмите **Обновить адреса**.

Подключение включается автоматически при последующих запусках WileyAI, если его не выключить в настройках. Сам WileyAI и компьютер должны работать; спящий или выключенный компьютер телефон не разбудит. Системный автозапуск WileyAI эта настройка не включает.

## Мобильный интернет

Установите и подключите Tailscale на компьютере и телефоне к одной частной сети. На компьютере в разделе **Телефон** выберите адрес Tailscale, обычно начинающийся с `100.`, и выполните сопряжение. Если телефон уже подключён по Wi-Fi, а адрес Tailscale появился позже, откройте **Компоненты → Использование ПК → Управление подключением → Изменить адрес компьютера** и добавьте его. При переходе с Wi-Fi на мобильную сеть на телефоне должен быть включён Tailscale. Проброс портов на роутере не требуется.

В зависимости от сети и правил брандмауэра соединение может требовать дополнительной настройки. Диагностика Tailscale: https://tailscale.com/kb/1452/connect-to-devices.

## Сканирование приложений и названия для голоса

В **Команды → Мои приложения → Приложения и названия для голоса** показаны названия, пакеты и
адреса запуска, прочитанные через Android PackageManager. Читаются доступные
приложения с экраном запуска текущего профиля; скрытые/отключённые приложения
и службы без такого экрана в список не входят. QUERY_ALL_PACKAGES и Accessibility
для этого не запрашиваются. Список и псевдонимы остаются на телефоне.

Сканирование выполняется в фоне при запуске, по кнопке обновления и при событиях
установки/удаления/изменения пакетов, пока процесс приложения работает.
Поиск поддерживает системное название, известные русские варианты, пакет и ваши
псевдонимы. Из карточки можно открыть приложение и проверить найденный адрес.

Чтобы имя распознавалось удобнее, выберите приложение → **Свои названия для голоса**:
до 12 названий по одному на строку, например «рабочий чат» или «любимая музыка».
Команда — «открой рабочий чат». Перед запуском проверяется существование и доступность
найденного компонента. Совпадения требуют выбора; неточное частичное совпадение
автоматически не запускает приложение.

Это не переобучение Vosk: новые иностранные слова не появляются в его акустическом
словаре только от сканирования. Для плохо распознаваемого имени используйте псевдоним
из обычных русских слов. Сканирование и сохранение псевдонимов проверены на S23+; запуск приложения по живой речи ещё требует проверки.

## Данные, безопасность и режим ПК

Режим выбирается над чатом. История телефона не пересылается при переключении.
ПК использует выбранную в Windows модель: локальную или облачную согласно его настройкам.
В разделе «Использование ПК» можно явно выбрать озвучку ответов ПК на телефоне; прежняя
озвучка через компьютер сохраняется. Запись в режиме ПК по-прежнему распознаётся
на компьютере, а текст появляется для проверки перед отправкой.

В чате ПК кнопка «Телефон»/«ПК» определяет устройство команды, а уточнение
«на телефоне»/«на компьютере» имеет приоритет. Телефонные действия в этом режиме
не попадают в историю ПК. Для их сохранения используйте чат телефона.

Сохранён прежний Keystore/AES-GCM профиль сопряжения. Частный HTTPS-шлюз на порту
48443 требует pin сертификата и отдельный bearer-ключ телефона. Ошибка чтения
профиля не удаляет его. Потерянный телефон можно отозвать в настройках ПК.
Публичная загрузка модели использует системную проверку HTTPS; TLS не отключается.

SQLite находится в закрытом каталоге приложения; API-ключей в ней нет. Отдельное
шифрование текста базы, экспорт истории, синхронизация и разрешение конфликтов
ещё не реализованы. Удаление телефонного чата не затрагивает ПК. Удаление приложения
средствами Android удаляет его локальную историю и скачанный ASR-комплект.

«Удалить речевой комплект» удаляет активную модель, сохраняя чаты. Частичная загрузка
удаляется отдельной кнопкой. При повреждении указателя модель не удаляется молча:
её можно явно удалить и установить заново. Прерванные распаковки очищаются при восстановлении.

## Сборка и тесты

Нужны JDK 17, Gradle 8.9, Android SDK с платформой/build-tools 34, NDK 28.2.13676358 и CMake 3.31.6. Перед первой сборкой выполните `python scripts/prepare-android-native.py`: это 39 МиБ закреплённых исходников llama.cpp с проверкой SHA-256, без весов. Затем: Из корня:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:GRADLE_USER_HOME = "$PWD\local\android-gradle"
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-android.ps1 -Check
```

Первой сборке нужны Maven-зависимости `vosk-android:0.3.75@aar` и `jna:5.18.1@aar`.
При заполненном кеше добавьте `-Offline`. Они содержат нативные библиотеки, а не веса
моделей. Лицензии включены в `assets/licenses`. Ключ из `local/android-signing`
нужно сохранять для обновлений поверх приложения.

Результат — `android/app/build/outputs/apk/debug/app-debug.apk`; копия выпуска —
`local/releases/WileyAI-Android-0.6.0-debug.apk`, SHA-256 рядом в `.apk.sha256`.

Сборка включает APK 14 основных инструментальных тестов. `-e speech true` добавляет синтез/распознавание, `-e iteration true` — изменение громкости с восстановлением и данные Android, `-e llm true` — нативный ответ и отправку через чат. Вместе 18 тестов; нужны предварительно установленные речевая и разговорная модели. Тестовый чат удаляется, прежний выбор восстанавливается. Запуск на выбранном устройстве:

```powershell
$adb = "$env:ANDROID_HOME\platform-tools\adb.exe"
& $adb install -r android/app/build/outputs/apk/debug/app-debug.apk
& $adb install -r android/app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
& $adb shell am instrument -w ru.wildlik.wileyai.mobile.test/ru.wildlik.wileyai.mobile.StageOneInstrumentation
```

При нескольких устройствах добавьте `-s SERIAL`. Тесты используют отдельную БД и
настройки, открывают главный экран/диалоги и пробуют загрузку нативной библиотеки;
они также проверяют навигацию, результат чтения громкости, каталог запуска и сохранение псевдонимов в отдельных тестовых настройках. Веса тестами не устанавливаются, микрофон не записывается, громкость не меняется. Для `-e speech true` сначала установите русский комплект через приложение; синтезированный WAV удаляется после теста.

Хостовые проверки:

```powershell
javac -encoding UTF-8 -d local/android-commands-probe android/app/src/main/java/ru/wildlik/wileyai/mobile/SpokenNames.java android/app/src/main/java/ru/wildlik/wileyai/mobile/PhoneCommands.java tests/android/PhoneCommandsProbe.java
java -cp local/android-commands-probe PhoneCommandsProbe
.venv/Scripts/python.exe -m pytest tests/test_android_speech.py tests/test_android_storage.py tests/test_mobile.py tests/test_mobile_commands.py tests/test_device_audio.py tests/test_verified_actions.py -q -p no:cacheprovider --basetemp=local/test-runs/android-stage2-check
```

`--basetemp` — только выделенный каталог тестов: pytest очищает его при повторе.
В данном Windows sandbox pytest потребовал запуск вне sandbox из-за ограничений ACL.
Для отдельного настоящего HTTPS/JVM pin-теста нужен свободный порт 48443 и переменные
`WILEYAI_MOBILE_NETWORK_TEST=1`, `WILEYAI_ANDROID_JVM_PROBE=1`; `PinProbe.java`
компилируется с `PinnedTls.java` в `local/android-java-probe`. При занятом порте
этот отдельный тест не запускайте одновременно с работающим шлюзом.
