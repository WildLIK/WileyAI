# Мастер первого запуска

В новой установке WileyAI 0.3 мастер открывается автоматически. В уже используемой программе его можно открыть через **Настройки → Данные и копии → Открыть мастер настройки**. Само обновление программы не сбрасывает настройки и не запускает мастер поверх старой переписки.

## 1. Начало

Выберите локальный мозг или облачный API. Локальная модель работает без интернета после загрузки; облако требует подключения и своего ключа. Голос можно добавить отдельно или пока оставить текстовый режим.

## 2. Мозг

Для локального режима установите Ollama, если его ещё нет, и нажмите **Запустить движок**. Укажите имя модели: доступны модели из каталога, установленного сервера и своё имя Ollama. **Скачать выбранную модель** запускает загрузку с прогрессом; её можно отменить. **Сохранить и проверить подключение** получает список моделей и проверяет наличие выбранной. Размер модели на диске не равен памяти, необходимой для работы.

Для облачного режима выберите OpenRouter, RouterAI или другой совместимый API, введите ключ и идентификатор модели. При переключении сервиса несохранённый ключ очищается. Проверка получает список моделей сервиса, не генерирует платный ответ. Отсутствие модели в списке не позволяет считать её готовой: проверьте имя или вернитесь в обычные настройки для нестандартного провайдера.

## 3. Голос и устройства

Можно выбрать текст, Piper с Ириной, голос Windows или оставить ранее настроенный движок. Другие голоса, облачная озвучка, Qwen3-TTS и OpenVoice доступны в обычных настройках.

Для Piper установите компонент, перезапустите программу, затем скачайте голос Ирина. Для голосового ввода включите соответствующий переключатель, установите Whisper, перезапустите и скачайте tiny, base или small. Шаг и выбранный режим сохраняются при перезапуске. Загрузка компонентов имеет отмену; для весов голоса и Whisper показывается анимированное ожидание без выдуманного процента. При принудительном завершении программы незавершённую загрузку весов понадобится повторить.

Выберите микрофон и динамик. Проверка микрофона показывает уровень сигнала без записи и отправки речи. Проверка динамика воспроизводит короткий сигнал. Пробу выбранного голоса можно остановить кнопкой, Escape или общей горячей клавишей. Для облачной пробы используется квота вашего сервиса. Устройства и модель распознавания сохраняются кнопкой **Сохранить и продолжить**.

## 4. Проверка

Мастер проверяет доступность сервера, наличие выбранной модели и готовность нужных движков/весов речи. Он не запрашивает ответ у мозга, не проверяет качество голоса и не гарантирует достаточную память для настоящего запуска модели. Первое общение загрузит модель в память.

Если всё необходимое настроено, нажмите **Начать общение**. Иначе вернитесь к нужному шагу или выберите **Настроить позже**. Эта кнопка закрывает мастер и сохраняет место остановки; открыть его снова можно из настроек.

Ключи не записываются в состояние мастера или резервную копию. Сохраняются только явно выбранные параметры; личность, разрешения Windows, чаты, память и параметры остальных сервисов не заменяются стандартным профилем.
