# Home Assistant

Доступно в 0.12.0. В боковом меню откройте **«Интеграции»**.

## Подключение

1. Укажите адрес своего работающего Home Assistant, например `http://homeassistant.local:8123` или HTTPS-адрес сервера. Нужен корень сервера, без `/api` и страницы панели.
2. В Home Assistant откройте профиль пользователя → **Безопасность → Долгосрочные токены доступа**, создайте токен для WileyAI и вставьте его в поле пароля. Регистрация приложения OAuth не требуется. Токен вводится в WileyAI, а не в чат.
3. Нажмите **«Проверить и сохранить подключение»**. WileyAI проверит REST API и конфигурацию; только после ответа сохранит адрес и токен в системное хранилище Windows. Ошибка нового подключения не удаляет прежнее.
4. Отметьте нужные устройства. Для изменения их состояния включите **«Разрешить управление выбранными устройствами в этом пространстве»** и сохраните доступ. Выбор и разрешение независимы для общих чатов и каждого проекта. В другом проекте по умолчанию ничего не разрешено.

Проверка соединения и обновление устройств выполняются по запросу. При открытии вкладки читаются устройства и журнал. Постоянного опроса сервера и самостоятельных действий нет. Отключение удаляет локальное подключение; сам токен можно отозвать в профиле Home Assistant.

## Поддержанные действия

| Тип | Возможности |
| --- | --- |
| `light` | Включить/выключить; яркость 0–100%, если светильник сообщает её поддержку |
| `switch`, `input_boolean` | Включить/выключить |
| `fan` | Включить/выключить; скорость 0–100%, если устройство сообщает процент скорости |
| `sensor`, `binary_sensor`, `climate`, `weather`, `cover`, `lock`, `alarm_control_panel`, `media_player` | Чтение текущего состояния; команды управления не предоставлены |

Показываются название, `entity_id`, состояние и поддержанные численные атрибуты. Список действий дополнительно проверяется по сервисам сервера. Недоступному устройству команда не отправляется. Яркость 0 означает выключение. Специальные шаги скорости отдельных вентиляторов могут не совпадать с запросом; результат останется неподтверждённым, если сервер вернул другой процент.

Перед командой WileyAI показывает устройство, действие и процент. Нужны отметка подтверждения и отдельное нажатие. Если состояние, подключение, проект или разрешение изменились после просмотра, старое подтверждение отклоняется. Предпросмотр действует пять минут и только в исходном чате. Уже достигнутое состояние подтверждается чтением без повторного запроса изменения.

## Чат и голос

Команды явно начинаются словами «умный дом»:

- «Умный дом, включи Кухня».
- «Умный дом, выключи Кухня».
- «Умный дом, яркость Кухня на 30».
- «Умный дом, скорость Вентилятор на 50».
- «Умный дом, покажи Температура» или «Проверь умный дом».

Название ищется среди выбранных устройств текущего пространства. При нескольких совпадениях WileyAI предложит список: ответьте «умный дом, выбери 1» с нужным номером. Затем она покажет действие. Для выполнения скажите **«подтверждаю умный дом»**, для отмены — **«отмена умный дом»**. Следующая посторонняя реплика сбрасывает ожидающее подтверждение. Общий ответ «да» домашнее устройство не включает.

Это точные локальные команды. Вывод модели и инструкции внутри документов не исполняются. Свободное планирование нескольких домашних действий, сцены, скрипты, автоматизации, замки, отопление и уведомления о событиях не реализованы.

## Проверка результата

После вызова сервиса WileyAI заново читает состояние конкретного устройства. Успех означает совпадение с целевым состоянием Home Assistant; это не независимый датчик физического эффекта. Для яркости допускается округление до трёх единиц шкалы 0–255, для скорости — до одного процента.

Журнал хранится локально и сохраняется при переходе между вкладками и перезапуске. Подтверждённая команда продолжает выполняться при закрытии вкладки или остановке ответа. Повторное нажатие старого подтверждения не отправляет команду ещё раз.

Если сервер отклонил запрос, результат отмечается как отказ. Если связь оборвалась или ожидаемое состояние не появилось, результат **не подтверждён**. Нажмите **«Проверить результат без повтора»**: будет выполнено только чтение состояния. Самостоятельной повторной отправки нет. После аварийного завершения WileyAI незавершённая запись также остаётся неподтверждённой.

Токен и разрешения управления не входят в резервные копии. Восстановление копии сбрасывает выбор/доступ и делает старые предпросмотры недействительными; существующее системное подключение остаётся. Удаление проекта удаляет его выбор устройств и журнал. Журнал не переносится резервной копией.

## Проверки и границы

Автоматические проверки используют искусственный HTTP-сервер Home Assistant и временные профили WileyAI: авторизация, протокол REST, сохранение секрета, проверка состояния, отсутствие ложного успеха, устаревшее подтверждение, проекты, копии, отмена ожидания, потеря ответа и запрет повторов. Electron проверяет полный интерфейс и переходы между разделами. Сеть владельца не сканировалась, настоящими устройствами тесты не управляли. Живая приёмка требует адреса сервера и токена, введённых владельцем в программе.

Адаптер использует [официальный REST API](https://contributors.home-assistant.io/core/internals/rest-api/) и [долгосрочные токены](https://contributors.home-assistant.io/core/internals/auth-api/). Для управления вызываются фиксированные сервисы устройства; запись отображаемого состояния `/api/states` для имитации выполнения не используется. Перенаправления запросов с токеном запрещены, размер ответа ограничен 8 МБ, время каждого запроса ограничено. Произвольные URL, шаблоны и команды сервера из модели не принимаются.
