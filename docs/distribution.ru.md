# Установка и обновления WileyAI 0.7

## На другом компьютере

1. Скачайте `WileyAI-Setup-0.7.1-x64.exe` из [выпусков GitHub](https://github.com/WildLIK/WileyAI/releases) или получите этот файл от владельца проекта.
2. Запустите установщик Windows 10/11 x64. Он устанавливает приложение для текущего пользователя; Node.js, Python, uv, Git и терминал не нужны. Встроены интерфейс, Python 3.12 и базовое ядро. Размер первой сборки — около 155 МБ.
3. Пройдите [мастер первого запуска](setup.ru.md) либо откройте **Модели → Компоненты**. Установите только нужные движки. Доступны Ollama, Whisper, Piper, Silero / Torch CPU и отдельное окружение Qwen3-TTS CPU. Показаны примерный объём, состояние, анимированный ход установки и отмена. После установки библиотек речи нажмите **Перезапустить**; после Ollama — **Запустить движок**.
4. В категориях **Мозг**, **Озвучка**, **Распознавание голоса** скачайте нужные веса. Затем выберите модели и устройства в настройках.
5. Вместо локального мозга или озвучки можно настроить облачный API. Для него установка локального движка не требуется. Голосовой ввод требует Whisper и его весов. 3D-персонаж загружается вашим файлом VRM.

Простой локальный комплект: Ollama + подходящая вашему компьютеру языковая модель, Whisper tiny/base и Piper с Ириной. Для Qwen3-TTS нужны несколько гигабайт свободной ОЗУ сверх памяти языковой модели; установка CPU-движка не гарантирует достаточную память или высокую скорость синтеза. Дополнительные веса, облачные ключи, документы и аватар в установщик не включены.

Программа пока не подписана сертификатом разработчика. Windows может показать предупреждение о неизвестном издателе. Проверяйте происхождение файла и его SHA-256 по `SHA256SUMS.txt` в выпуске.

## Где хранятся данные

У установленной программы: `%APPDATA%\WileyAI\data` — переписка, документы, настройки, модели, компоненты и журналы. Приложение устанавливается отдельно; переустановка сохраняет эти данные. Ключи API — в системном хранилище Windows. Для проверки можно переопределить папку переменной `WILEYAI_DATA_DIR`.

Запуск из исходников продолжает использовать прежнюю папку `data` проекта. Автоматического переноса из исходников в установленную программу нет. Для переноса чатов используйте **Настройки → Данные и копии**. Модели скачиваются заново либо копируются отдельно; ключи вводятся на новом компьютере. Не передавайте свою рабочую папку `data` другому человеку.

Компоненты ставятся встроенным uv в отдельные каталоги; готовность отмечается только после успешной проверки импорта. Незавершённая загрузка не становится действующим компонентом. Библиотеки работающего ядра не заменяются. Для Ollama проверяется официальный SHA-256 архива и пути при распаковке; используется переносной выпуск v0.40.4 без системной службы и изменения PATH. Если на localhost уже работает внешний Ollama, WileyAI использует его и не останавливает.

## Уведомления об обновлениях

**Настройки → Данные и копии → Обновления WileyAI**: версия, ручная проверка, переключатель автоматической проверки, переход к выпускам и доступ к закрытому репозиторию. Проверка выполняется через 15 секунд после запуска и затем раз в 6 часов, если включена. Источник — стабильный GitHub Release с тегом `vX.Y.Z`; простой push без нового выпуска не означает новую версию программы.

Если найдена более новая версия, появляется компактное уведомление в интерфейсе и уведомление Windows один раз на версию. Его можно скрыть. Файлы не загружаются и не устанавливаются автоматически: откройте выпуск и запустите новый установщик, предварительно завершив WileyAI через меню выхода в трее.

Репозиторий WileyAI сейчас **закрытый**. Для загрузки выпуска в браузере нужен аккаунт с доступом. Для проверки из программы сохраните отдельный GitHub personal access token с правом чтения **Contents** этого репозитория. Ключ хранится отдельно в Windows, не возвращается в интерфейс и не попадает в резервные копии. Ключи OpenRouter/RouterAI для GitHub не используются. При публичном репозитории ключ не нужен. Ошибки сети, недоступный закрытый проект и отсутствие выпуска показываются отдельно от состояния «актуальная версия».

## Сборка разработчиком

На Windows x64 с Node.js 24 и uv:

```powershell
npm ci
uv sync --locked --extra dev
npm run package:win
```

`prepare:runtime` скачивает закреплённый переносной CPython 3.12.13 в `local/packaging`, устанавливает базовые зависимости из `uv.lock` в его копию и кладёт uv.exe. Дополнительные компоненты получают закреплённые списки зависимостей. Окружение разработчика и глобальный Python не изменяются. `electron-builder` упаковывает только `desktop`, `dist`, `core`, нужный скрипт OpenVoice и подготовленный runtime. Папки `data`, `.venv`, `.git`, локальные голоса и веса не входят в дистрибутив.

Результат: `local/releases/WileyAI-Setup-<версия>-x64.exe`. `npm run package:dir` создаёт развёрнутую сборку для проверки. `node scripts/test-packaged.mjs` запускает её с пустыми данными, посторонней рабочей папкой и PATH без Python/Node/Git. Дополнительный `--install-piper` проверяет реальную установку и синтез после перезапуска, используя уже имеющийся локальный тестовый голос `data/models/piper/irina`.

Workflow `.github/workflows/release.yml` собирает Windows-артефакт вручную; при push тега `v<версия из package.json>` публикует установщик и SHA-256 в GitHub Releases. Версии в `package.json`, `pyproject.toml` и `core/version.py` должны совпадать. Каждый новый дистрибутив получает новый номер.
