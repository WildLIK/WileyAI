# Установка и обновления WileyAI

Скачивайте WileyAI из [выпусков проекта на GitHub](https://github.com/WildLIK/WileyAI/releases). На странице каждого выпуска есть дата, список изменений и файлы для доступных платформ.

## Windows 10 и 11 x64

1. Выберите файл `WileyAI-Setup-<версия>-x64.exe` в последнем обычном выпуске.
2. Сверьте SHA‑256 файла со строкой для этого имени в `SHA256SUMS.txt` того же выпуска. Это можно сделать в PowerShell встроенной командой `Get-FileHash -Algorithm SHA256`:

   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath '.\WileyAI-Setup-0.14.44-x64.exe'
   ```

3. Откройте установщик и следуйте шагам на экране. WileyAI ставится для текущего пользователя. Python, Node.js, Git и среда разработчика не требуются.

Windows-установщик не использует Authenticode. Windows может показать неизвестного издателя. При сомнении в источнике или несовпадении контрольной суммы остановите установку. Для независимой проверки подписи манифеста первой загрузки предусмотрен [верификатор](../scripts/verify-release-download.py). Он читает [открытый ключ проекта](updates/release-trust.json) из доверенной копии исходников. Для его запуска нужны Python 3.12 и зависимости проекта.

## Android 8.0 и новее

1. Выберите `WileyAI-Android-<версия>-release.apk` из того же выпуска и откройте его из «Загрузок».
2. Если Android попросит разрешение установки из этого источника, проверьте имя приложения и источник APK. Нажмите системное подтверждение и дождитесь завершения.
3. Откройте WileyAI. Чтобы пользоваться голосом и локальным чатом, добавьте нужные компоненты в настройках самого приложения.

Android применяет обновление поверх совместимой версии и сохраняет локальный профиль. Если Android сообщает о конфликте подписи, остановитесь. Локальная debug-версия и публичная release-версия используют разные сертификаты. Удаление старой копии стирает её локальные данные. Переход с неё требует отдельного согласованного переноса данных.

## Обновления

Откройте **Настройки → О приложении → Проверить обновления**. В Windows раздел находится во вкладке **Данные и копии**. Обе версии получают последний обычный GitHub Release. WileyAI проверяет цифровую подпись манифеста и SHA‑256, показывает изменения и предлагает установить проверенный файл. Android подтверждает установку через системный экран.

Обновление рассчитано на сохранение настроек, памяти, истории и файлов моделей. Перед переустановкой или сменой сертификата воспользуйтесь доступным резервным копированием. При проблеме с запуском сохраняйте данные и дождитесь исправленного выпуска с более высоким номером. Скачанные пользователем модели и данные не входят в установщик.

## Модели и обратная связь

На Windows откройте **Модели → Компоненты** и установите только нужные движки. В Android компоненты и источники выбираются в настройках приложения. Размеры дополнительных моделей показаны перед загрузкой.

Для сообщения об ошибке откройте **О приложении → Сообщить об ошибке**. Проверьте состав архива, сохраните ZIP и самостоятельно выберите получателя.
