# Облачная озвучка WileyAI

Проверено 17 октября 2026 года по документации и открытым каталогам API. Это исследование для следующего адаптера: облачная озвучка пока не подключена. Платные запросы и обращения к аккаунтам не выполнялись.

Облачный TTS позволит оставить мозг и распознавание локальными, а синтезировать голос на сервере. На ПК останутся сетевой запрос, очередь фраз и проигрывание аудио; веса TTS загружать не потребуется. Скорость и качество русского нужно проверить на одинаковых фразах: рекламные оценки и задержки агрегатора этого не гарантируют.

## Кандидаты

| Сервис | Модель | Оплата и назначение |
| --- | --- | --- |
| OpenRouter | `fish-audio/s2.1-pro-free:free` | Бесплатная версия S2.1 Pro для прототипов и небольшого использования, без гарантий задержки и доступности. Первый кандидат для пробы. |
| RouterAI / OpenRouter | `google/gemini-3.8-flash-tts` | Повествование, персонажи и выразительная речь. Через агрегаторы платная. В RouterAI на дату проверки: примерно 54 ₽ / млн входных текстовых токенов и 978 ₽ / млн выходных аудиотокенов. |
| RouterAI / OpenRouter | `google/gemini-3.8-flash-lite-tts` | Более быстрый и дешёвый вариант для разговорного режима. В RouterAI примерно 54 ₽ / млн входных и 652 ₽ / млн выходных токенов. |
| RouterAI / OpenRouter | `x-ai/grok-voice-tts-1.0` | Русский язык, готовые голоса. В RouterAI около 1630 ₽ / млн символов, то есть 1,63 ₽ за 1000 символов. Для мягкого характера стоит сравнить Ara и Eve; документация описывает Ara как тёплый и дружелюбный. |
| Google Gemini API напрямую | `gemini-3.8-flash-tts`, `gemini-3.8-flash-lite-tts` | У Google заявлен бесплатный API-уровень с квотами. Нужен отдельный Google API key; бесплатность не переносится на RouterAI/OpenRouter. Россия отсутствует в официальном списке доступных регионов, поэтому это дополнительный вариант при наличии подходящего доступа. |

Источники: [Fish Free](https://openrouter.ai/fish-audio/s2.1-pro-free:free), [RouterAI Gemini](https://routerai.ru/models/google/gemini-3.8-flash-tts), [RouterAI Gemini Lite](https://routerai.ru/models/google/gemini-3.8-flash-lite-tts), [RouterAI Grok](https://routerai.ru/models/x-ai/grok-voice-tts-1.0), [голоса и языки xAI](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech), [цены Google](https://ai.google.dev/gemini-api/docs/pricing), [регионы Google](https://ai.google.dev/gemini-api/docs/available-regions).

В открытом [каталоге RouterAI](https://routerai.ru/api/v1/models) найдено 34 модели с выходной модальностью `speech`; нулевых цен среди них на момент проверки нет. [Каталог OpenRouter с фильтром speech](https://openrouter.ai/api/v1/models?output_modalities=speech) подтверждает нулевые входную и выходную цены именно у `fish-audio/s2.1-pro-free:free`. Название модели и тариф важны: платная `fish-audio/s2.1-pro` — другой идентификатор. Обычные бесплатные чат-модели не являются TTS.

У бесплатных моделей есть ограничения частоты и доступности. Остатки квоты OpenRouter следует читать по ключу через `GET /api/v1/key` и обрабатывать HTTP 429 с `Retry-After`, а не обещать фиксированный безлимит. При разбиении ответа на фразы каждая фраза может расходовать отдельный запрос. См. [правила лимитов](https://openrouter.ai/docs/api_reference/limits).

## Подбор мягкого женского голоса

Для Gemini сначала сравнить Achernar (мягкий), Vindemiatrix (нежный), Sulafat (тёплый), затем Aoede и Despina. Это кандидаты по описаниям, окончательный выбор — после русских проб. Готовые голоса и русский перечислены в [документации Google](https://ai.google.dev/gemini-api/docs/speech-generation); каталог агрегатора подтверждает эти идентификаторы.

У Fish Free поле `supported_voices` в каталоге пустое: нельзя обещать готовую Serena или произвольный ID голоса из другой модели. [API конечных точек](https://openrouter.ai/api/v1/models/fish-audio/s2.1-pro-free:free/endpoints) сообщает `supports_voice_cloning: true`. Для стабильного персонажа стоит проверить один короткий разрешённый образец и его воспроизведение на русском; отправка образца в облако должна быть отдельной понятной настройкой. Набор голосов, язык и модель — разные параметры, см. [документацию Fish Audio](https://github.com/fishaudio/docs/blob/main/agents/build/voice-language.mdx).

## Подключение к WileyAI

1. Сохранить три независимых раздела: **Мозг**, **Озвучка**, **Распознавание голоса**. В озвучке добавить отдельный режим «Облачный API», провайдера, адрес, модель, голос, формат и стиль. Мозг не должен переключаться вместе с голосом.
2. Оба агрегатора принимают `POST /api/v1/audio/speech` с `model`, `input`, `voice`, `response_format` и Bearer API key. Каталог моделей получать по модальности `speech`, голоса — из `supported_voices`. Оставить ручной ввод для других совместимых сервисов. Источники: [RouterAI TTS](https://routerai.ru/docs/guides/overview/multimodal/text-to-speech), [OpenRouter TTS](https://openrouter.ai/docs/guides/overview/multimodal/tts).
3. Хранить ключ озвучки отдельно от ключа мозга в системном хранилище Windows. Отправлять только текст текущих фраз, без истории чата, памяти и документов целиком. Сохранение параметров и проверка доступности не должны запускать платный синтез.
4. Использовать существующую очередь фраз: начинать чтение до завершения ответа, поддерживать Escape и немедленную остановку проигрывания, отменять сетевой запрос и последующие фразы. Отмена не гарантирует возврат стоимости уже обработанного текста на стороне провайдера. Бесплатный тариф учитывать отдельно: объединять короткие фразы без чрезмерного расходования запросов.
5. Сохранять правильный формат: MP3 возвращается как `audio/mpeg`; сырой PCM необходимо обернуть WAV-заголовком либо подавать в потоковый плеер. Через эти агрегаторы Gemini TTS требует PCM16 / 24 кГц / моно. Стиль в OpenRouter задаётся `instructions`, а в RouterAI — `provider.options.google-ai-studio.speech_metadata.style`: одинаковый внешний формат не означает одинаковую поддержку всех опций.
6. Явно показывать активную облачную модель, ошибку и ограничения. Не переключать автоматически на платную модель или другой голос. В мониторинге показывать локальные затраты ядра/плеера и длительность запроса; серверные CPU, ОЗУ и VRAM провайдер не раскрывает.

Рекомендуемый порядок: бесплатный Fish Audio в OpenRouter → проба Gemini и Grok через существующий аккаунт RouterAI → сравнение естественности русского, устойчивости голоса, задержки первой фразы и расхода квоты на реальных диалогах.
