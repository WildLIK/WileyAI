# Облачная озвучка WileyAI

Проверено 17 октября 2026 года. Адаптер OpenRouter / RouterAI и совместимых API реализован. Запросы, форматы, отмена, хранение ключей и интерфейс проверены с тестовым сервисом. Дополнительно успешно выполнена настоящая проба Fish Free с голосом «Мита Кепочка» через сохранённый ключ OpenRouter; платные внешние запросы при разработке не выполнялись.

## Как попробовать три варианта

1. Открыть **Настройки → Речь и озвучка → Движок озвучки → Облачная озвучка · API**.
2. Выбрать **Сервис озвучки**: OpenRouter, RouterAI или другой совместимый API. Показываются только его настройки. Вставить и сохранить отдельный ключ озвучки; после сохранения блок ключа сворачивается. Ключ хранится в системном хранилище Windows под сервисом `WileyAI.Speech`, отдельно от ключа мозга. В настройки, резервные копии и Git ключи не включаются.
3. В списке моделей OpenRouter выбрать **Fish Audio Free**, в RouterAI — **Gemini Flash TTS**, **Gemini Flash Lite TTS** или **Grok Voice TTS**. Для сравнения менять модель и нажимать **♪ Прослушать голос** под блоком облачной озвучки. Выбор модели и голоса сразу сохраняется для ответов в чате; при переключении сервиса восстанавливаются его прежние модель, голос, стиль, формат и адрес API, в том числе после перезапуска программы. Каждая проба расходует квоту либо баланс сервиса. До нажатия кнопки синтез не запускается.
4. По умолчанию у Gemini используется тёплый Sulafat; среди других кандидатов — Achernar, Vindemiatrix, Aoede и Despina. Grok настроен на Ara, также можно сравнить Eve. Готовые голоса выбираются из списка; свой ID, стиль и формат доступны в **Дополнительно: API, голос и формат**. Там же можно обновить каталог выбранного сервиса и указать ID другой модели. Впечатление от русского нужно оценить на собственных пробах.
5. Для другого совместимого сервиса указать адрес API и ID модели. Список моделей и ключи других сервисов в этом блоке не показываются. Мозг и распознавание остаются независимыми от выбора озвучки.
6. В чате включить автоматическую озвучку либо нажать значок голоса у готового ответа. Escape и кнопки остановки прерывают проигрывание, текущий запрос и оставшуюся очередь. Отмена не гарантирует возврат оплаты за уже обработанный сервисом текст.

### Мита Кепочка и другие голоса Fish Audio

В OpenRouter с моделью **Fish Audio Free** нажать **Мита Кепочка**, затем **♪ Прослушать голос**. Это [голос от Alex](https://fish.audio/ru/m/ff1ae409865e4c7493db061913d77a79/), ID `ff1ae409865e4c7493db061913d77a79`. Выбор сохраняется для чата и голосового разговора, отключает WAV-образец Serena и использует голос Fish по ID. Скачивать модель или аудио для этого не нужно.

Для любого другого голоса вставить адрес его страницы Fish в видимое поле **Ссылка или ID голоса Fish Audio** и перейти к следующему полю. Из ссылок `fish.audio/ru/m/ID/`, `fish.audio/m/ID/` и прежнего варианта `fish.audio/app/m/ID/` извлекается ID; страница и аудио автоматически не загружаются. Ключ сохраняется отдельно, как и раньше.

Добавлен второй готовый вариант — **Добрая Мита (Miside)** от Тимофея, ID `303b89e345f04bf4b3755e0ddf1b41c4`. Выбран именно [вариант с фразой «Привет душка»](https://fish.audio/fr/m/303b89e345f04bf4b3755e0ddf1b41c4/), совпадающий со скриншотом пользователя: у автора есть другой одноимённый голос. Настоящая короткая проба через Fish Free прошла: MP3 66 454 байта, полный запрос 3,13 с. Выбор сохраняется для ответов и отключает WAV-образец.

Перенести ID Fish напрямую в Piper или Silero нельзя. Для проверки подготовлены [локальные аудиопримеры Piper/Silero с конвертером тембра OpenVoice](local-voice-conversion.ru.md); в основной интерфейс локальный конвертер пока не подключён.

В пробе с настоящим OpenRouter короткая фраза «Привет! Я Уайли. Давай спокойно обсудим твои планы.» дала корректный MP3 объёмом 78 993 байта. Заголовки ответа пришли через 3,64 с, полное аудио — через 6,33 с. Это один замер, не гарантия скорости. Веб-пример пользователя создан на Drama 3; тот же ID в S2.1 Pro Free может отличаться по подаче. Перехода на платную модель автоматически нет.

### Женский голос из собственного образца

В OpenRouter с моделью `fish-audio/s2.1-pro-free:free` нажать **Женский голос · образец Serena**, затем **♪ Прослушать голос**. Кнопка появляется, если на ПК уже сохранён локальный пример Serena. Повторная загрузка Qwen и генерация нового примера не требуются: используется готовый WAV. Другой вариант — **Загрузить свой WAV** с женской речью: PCM16, 1–30 секунд, до 5 МБ. Загруженный образец автоматически включается, его имя отображается над кнопками. Флажок **Использовать WAV-образец для Fish** позволяет вернуться к голосу без образца.

Serena — имя исходного локального голоса Qwen, не встроенный голос Fish. Слово `female` также не является ID. Fish подражает голосу из образца; сходство и произношение зависят от записи и модели. Если есть ID голоса из Fish Audio, его можно ввести в **Ссылка или ID голоса Fish Audio**: это отключит образец, чтобы введённый ID применялся однозначно.

При включении образец отправляется OpenRouter с каждой фразой Fish; для Gemini/Grok он не отправляется. Образец хранится только на этом ПК и не включается в переносимую резервную копию. У Fish Free нет списка готовых голосов в `supported_voices`: голос по умолчанию зависит от сервиса, а для устойчивого тембра рекомендуется выбранный ID или образец. Поддержка аудио-образца подтверждается [описанием конечной точки](https://openrouter.ai/api/v1/models/fish-audio/s2.1-pro-free:free/endpoints) и [документацией OpenRouter](https://openrouter.ai/docs/guides/overview/multimodal/tts#voice-cloning).

## Что дешевле

Тарифы на дату проверки; окончательная стоимость определяется сервисом. В бесплатном Fish есть ограничения частоты и доступности, а также нет гарантий задержки. Платная `fish-audio/s2.1-pro` — отдельная модель, автоматического переключения на неё нет.

| Вариант | Ориентир стоимости |
| --- | --- |
| OpenRouter `fish-audio/s2.1-pro-free:free` | 0 ₽ в пределах действующих лимитов |
| RouterAI `google/gemini-3.8-flash-lite-tts` | Около 0,98 ₽ за минуту аудио **плюс входной текст** |
| RouterAI `google/gemini-3.8-flash-tts` | Около 1,47 ₽ за минуту аудио **плюс входной текст** |
| RouterAI `x-ai/grok-voice-tts-1.0` | Около 1,63 ₽ за 1000 символов текста |

Расчёт Gemini — оценка: 25 аудиотокенов/сек × 60 сек × 652 / 978 ₽ за млн аудиотокенов. Вход стоит примерно 54 ₽ за млн текстовых токенов. У Grok цена за символы, поэтому сравнение по минутам зависит от темпа. Если за минуту произносятся 1000 символов, получится примерно 1,63 ₽/мин. Это допущение, а не единый тариф всех сервисов.

Источники: [Fish Free](https://openrouter.ai/fish-audio/s2.1-pro-free:free), [RouterAI Gemini](https://routerai.ru/models/google/gemini-3.8-flash-tts), [RouterAI Gemini Lite](https://routerai.ru/models/google/gemini-3.8-flash-lite-tts), [RouterAI Grok](https://routerai.ru/models/x-ai/grok-voice-tts-1.0), [Google: 25 аудиотокенов в секунду](https://ai.google.dev/gemini-api/docs/pricing).

В проверенном каталоге RouterAI бесплатных speech-моделей не найдено. В OpenRouter нулевая цена подтверждена именно для `fish-audio/s2.1-pro-free:free`. Лимиты бесплатных запросов зависят от аккаунта и конечной точки; при доступе к ключу их можно проверить через `GET /api/v1/key`. Готовые фразы объединяются в пределах 300 символов. Это компромисс между числом запросов и ожиданием большого аудиофрагмента; автоматических повторов платного синтеза и смены голоса при ошибке нет. См. [правила OpenRouter](https://openrouter.ai/docs/api_reference/limits).

## Паузы и длительность Qwen

Память и скорость синтеза — разные характеристики. Измеренные ранее около 2,9 ГБ — рабочий набор процессов на CPU в конкретном запуске, а не жёсткий лимит Qwen и не объём видеопамяти. Длинные ответы уже озвучиваются частями; допустимая длина ответа задаётся мозгом и его контекстом/лимитом ответа. Дополнительная ОЗУ сама по себе не ускоряет подготовку звука.

На RTX 4060 Laptop в режиме Auto фактически выбрана CUDA. Первая короткая фраза вместе с загрузкой заняла 10,83 с при длительности аудио 1,28 с. Следующая — 3,33 с синтеза для 2,16 с аудио; более длинная — 5,79 с для 3,84 с. Тёплый синтез примерно в 1,5 раза медленнее проигрывания. Поэтому одного упреждающего фрагмента недостаточно для полностью непрерывного чтения. Увеличение начального буфера отсрочило бы первую фразу, но при постоянном отставании буфер всё равно закончится.

В очередь добавлено объединение уже готовых коротких фраз: до 240 символов для Qwen и до 300 для облака. Для облака первый фрагмент ограничивается примерно 180 символами. Короткому вступлению вроде «Поняла» даётся до 200 мс на объединение с началом основного ответа; готовый короткий ответ и содержательная первая фраза этой паузы не ждут. Следующий фрагмент готовится во время проигрывания предыдущего. Отказ от прежних блоков до 800 символов сокращает объём аудио, которое нужно подготовить до продолжения чтения. Соединение HTTP переиспользуется между фразами, чтобы не повторять установку соединения на каждом запросе; при выходе пул закрывается.

Сейчас каждый фрагмент всё ещё загружается целиком перед проигрыванием. Это не потоковое воспроизведение входящих аудиобайтов: задержка сервера и загрузки остаётся. У бесплатного Fish [нет гарантии задержки](https://openrouter.ai/fish-audio/s2.1-pro-free:free). Модель Qwen переиспользуется внутри ответа и освобождается после его завершения; первый запуск следующего ответа снова включает загрузку.

## Совместимость адаптера

Базовый путь — `/audio/speech` относительно указанного адреса API. Передаются `model`, `input`, `voice`, `response_format`; стиль в OpenRouter/совместимых сервисах — `instructions`, в RouterAI Gemini — `provider.options.google-ai-studio.speech_metadata.style`. В Auto для Gemini выбран PCM16 / 24 кГц / моно с упаковкой в WAV, для остальных — MP3. Есть ручной выбор формата и модели. Каталог загружается по кнопке без синтеза и без скачивания весов.

Источники: [RouterAI TTS](https://routerai.ru/docs/guides/overview/multimodal/text-to-speech), [OpenRouter TTS](https://openrouter.ai/docs/guides/overview/multimodal/tts). В мониторинге облачные модели показаны отдельными строками с длительностью операций; серверные CPU/ОЗУ провайдер не раскрывает, локальные затраты остаются в ядре и интерфейсе.
