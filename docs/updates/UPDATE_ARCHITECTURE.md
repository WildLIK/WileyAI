# Обновления WileyAI

## Единый поток выпусков

Windows и Android используют `/releases/latest`. Черновики и предыдущие предварительные выпуски не участвуют в обновлении. Windows сравнивает номер версии по числам. Android также требует строго возрастающий целочисленный `versionCode`. Устаревший выбор канала сбрасывает только кэш проверки обновлений. Автоматическая проверка, срок хранения журнала и пользовательский профиль сохраняются.

Клиенты читают публичный GitHub Releases по HTTPS и ищут `wiley-update-v2.json`. Последний выпуск без манифеста нельзя установить из приложения. История и список изменений сохраняются на странице GitHub Releases. Для установки токен GitHub не используется. [GitHub Releases API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release).

Проверка при старте отложена на 15 секунд. Windows выполняет последующие проверки раз в шесть часов, если функция включена. На Android проверку в фоне планирует JobScheduler. Сеть, Doze и квоты ОС могут сдвинуть её. Доступное обновление отображается в приложении и показывается как системное уведомление при наличии разрешения ОС. Нажатие на уведомление Android открывает «О приложении». Обе платформы показывают версию, подписанную дату, изменения, размер и состояние загрузки. В «О приложении» можно выключить автоматическую проверку или запустить ручную.

## Windows

Существующий Python-сервис проверяет манифест и скачивает установщик NSIS в отдельный каталог частного профиля. Electron запускает установку после нативного подтверждения. Сначала останавливается голос и закрывается локальный Python-процесс. До запуска NSIS помощник ждёт окончания старых процессов и повторно проверяет SHA‑256. Перезапуск выбирается пользователем на последней странице NSIS. Прежняя ручная ссылка на GitHub и поддержка оповещений о релизах без манифеста доступны в старых сборках и сборках без доверенного ключа.

Настройки, история и модели хранятся отдельно от каталога установки. При ошибке можно повторить проверку и загрузку. Проверенный файл переиспользуется после сверки. При повреждении установки повторно запустите установщик после проверки по подписанному манифесту. Автоматический откат файлов NSIS здесь не реализован.

Текущий NSIS совместим с electron-updater. Этот путь использует `latest.yml` и свои правила подписи и каналов. В этапе выбран один формат подписанного выпуска для Windows и Android, поэтому используется готовый NSIS и узкий запускатель вокруг него. Дифференциальное скачивание через blockmap остаётся возможной отдельной оптимизацией. [Electron-builder Auto Update](https://www.electron.build/v26/docs/features/auto-update/).

## Android

Клиент выбирает APK с меткой `universal`. Подготовка релиза проверяет наличие `arm64-v8a` и `x86_64`. Перед открытием APK повторно проверяются хеш, размер, точные package ID, `versionCode`, версия и совпадение сертификата установленного приложения с APK и манифестом. Файл передаётся системному установщику с временным URI-доступом только для чтения. Android показывает своё подтверждение. При необходимости пользователь выдаёт WileyAI разрешение на установку из этого источника самостоятельно.

Скачивание можно завершить отдельно от установки. Взломанный или оборванный файл из временного пути нельзя передать установщику. APK для добровольной установки хранится в локальном кэше, который система может очищать. Следующая проверка получает новую авторизованную ссылку и сверяет кэш. Пропуск установки сохраняет обычную работу приложения.
