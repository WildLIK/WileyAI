# Отчёт об ошибке

В «Настройки → О приложении» выберите «Сообщить об ошибке». Опишите шаги, откройте предпросмотр и сохраните `WileyAI-feedback.zip` через системный диалог. Пользователь выбирает адресата и передаёт файл самостоятельно.

| Платформа | Содержимое |
| --- | --- |
| Windows | `system.json` с версией ОС и WileyAI, ID сборки, Git commit, признаком изменённого дерева и выбранными моделями и настройками LLM, STT, VAD, TTS. `diagnostics.json` с кодами проверок, загрузок и аварий. `description.txt` с описанием пользователя. |
| Android | `settings.txt` с автоматической проверкой и сроком хранения. `diagnostics.txt` с версией, versionCode, ID сборки, Git commit и признаком изменённого дерева, моделями LLM/STT/фонового вызова, настройками TTS и техническими событиями. `description.txt` с описанием пользователя. |

Штатные модели указаны по имени. Для произвольных имён моделей и голосов применяется короткий технический идентификатор `custom-…`, поскольку имя может содержать путь, URL или идентификатор аккаунта. Для системного движка показывается, что выбор делает ОС. Отчёт показывает текущий выбор и известную локальную доступность, а не подтверждает загрузку модели в память.

Собранный клиент использует метаданные, записанные при сборке. Запуск Windows непосредственно из исходников показывает ID локального запуска и пустые сведения о Git, так как эта копия не является собранным артефактом.

Пользовательское описание сохраняется как введено и доступно в предпросмотре. Перед экспортом из него следует убрать сведения, которые получатель не должен видеть. Служебные части формируются из разрешённых полей. Пароли, токены, история чатов, память, распознанный текст, аудио, системные дампы и необработанные crash logs не собираются в ZIP. Для аварий экспортируются время и коды, без трассировок и сообщений процессов.

Срок хранения выбирается из 1, 7 и 30 дней. По умолчанию 7 дней. Технический журнал Android ограничен 5 МиБ, журнал обновлений Windows и файл кодов аварий — последними 100 событиями каждый. Для истории аварий Android срок применяется при экспорте. Исследовательские голосовые архивы и пользовательские данные хранятся отдельно.
