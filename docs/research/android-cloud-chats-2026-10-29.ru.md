# Облачные чаты для WileyAI Android

Проверено 29 октября 2026 года. В 0.9.0 добавлен выключенный по умолчанию
коннектор Chat Completions: HTTPS-адрес, ID модели и ключ пользователя либо его
моста. Включение отдельно подтверждает передачу до восьми последних сообщений
текущего чата. Ключ зашифрован Android Keystore, аудио и каталог приложений
не передаются. Текст модели не исполняется как команда. Это работает поверх
совместимого API, а не через захват экрана веб-чата.

## Что дают рассматриваемые проекты

| Вариант | Как подключается | Ограничения и решение для WileyAI |
| --- | --- | --- |
| Token-Free Gateway | По README предоставляет `/v1/chat/completions`, используя вход пользователя в веб-чаты через Chrome/CDP | Мост рассчитан на настольную систему с Chrome; это не встроенный Android SDK. Лимиты исходных аккаунтов сохраняются. WileyAI может обратиться к собственному HTTPS-адресу такого моста; работоспособность конкретного аккаунта отдельно проверяется. |
| Puter / Puter API Bridge | Официальный интерфейс — `puter.ai.chat()` и вход в Puter; совместимый сторонний мост может предоставить Chat Completions | Пользователь получает бесплатную месячную квоту, дальнейшее использование оплачивается его аккаунтом. Название «Puter API Bridge» неоднозначно: конкретный репозиторий не установлен, официальный мост с таким именем не подтверждён. В 0.9.0 поддержан протокол собственного совместимого моста, без встроенного обхода входа или лимитов. |
| Pollinations | Текущий адрес `https://gen.pollinations.ai/v1`, требуется авторизация | Официальные инструкции описывают Pollen, ключи и подключение кошелька пользователя. Старые утверждения об анонимном безлимите не используются. Для полноценного публичного клиента предпочтителен OAuth/PKCE/BYOP; готовая регистрация приложения WileyAI у сервиса не выполнена. |
| DeepSeek Harness для Android | Порт запускает отдельную среду агента и настраивает провайдера. В актуальном китайском README описан также вход в аккаунт DeepSeek через официальный браузерный путь | Английский README отстаёт и описывает прежде всего API-ключи. Это не библиотека бесплатного веб-чата для встраивания в WileyAI. Объём окружения, права и обновления существенно сложнее лёгкого API-клиента. Бесплатная квота входа не подтверждена. Установка стороннего Harness и Shizuku не проводилась. |
| GigaChat | Официальный API с собственной авторизацией, либо совместимый мост | Документация для действующих физических лиц содержит Freemium; новых клиентов с 1 сентября 2026 направляют на cloud.ru. Нельзя переносить старый лимит на новый аккаунт без проверки. Прямой обмен токенов GigaChat в 0.9.0 не реализован. |
| Алиса / Yandex AI Studio | API моделей AI Studio; навыки Алисы используют другой интерфейс | У API есть тарификация и биллинг. Бесплатное размещение backend навыка Алисы не означает бесплатный доступ к модели. На страницах пробного периода и быстрого старта есть расхождения; обещания бесплатного гранта нет. |

## Следующий практический шаг

Для разговора без постоянно работающего ПК исследовать официальный вход Puter
в выделенном веб-контексте и ограниченный мост только текстовых запросов/ответов,
после проверки фактической квоты аккаунта. Для существующего собственного
Token-Free/Puter-моста можно уже использовать коннектор 0.9.0. Для GigaChat
сначала определить доступный тип аккаунта и действующие условия, затем добавить
его отдельный адаптер авторизации.

Управление телефоном продолжает использовать проверяемые локальные действия.
Если позже модель будет предлагать новые действия, нужны типизированный список
допустимых команд, уточнение неоднозначных приложений и проверка результата.
Общая оболочка, произвольные shell-команды и чтение экрана сюда не добавлены.
