# Аудит WileyAI перед отдельным Gateway

29 октября 2026. Проверяется текущий checkout `D:\projects\WileyAI`, включая
незакоммиченные Android-этапы. Настольный core — 0.14.0, Android — 0.9.0.

| Подсистема | Текущая реализация | Решение |
| --- | --- | --- |
| Android UI | Java 17 / Views, API 26+, общая тема `MobileUi`/`WileyDialogs`, четыре палитры | Добавить экран подключений в существующую навигацию; Compose/Electron не переносить |
| Телефонная история | `LocalChatRepository`, SQLite, чаты/черновики/сообщения; `LocalChatController` | Сохранять локально. Не смешивать ID диалога провайдера с ID телефонного чата |
| Чат телефона | `MainActivity`, Qwen через `LocalLlm`; простой `CloudChat` Chat Completions в 0.9 | Выделить клиент нового протокола; сохранить старый API-коннектор и локальную генерацию |
| Каталог локальных моделей | `LlmModels`, проверяемые загрузки GGUF, один совместимый Qwen3 | Не изменять формат/проверки; облачный каталог независим от GGUF |
| Речь | Vosk/Android ASR, системный offline TTS, `SpeechRuntime` с кэшем весов | Аудио остаётся на телефоне по умолчанию |
| Помощник | VoiceInteractionService/Session + явный FGS-микрофон, wake-фраза, последовательные вопросы | Новый удалённый чат использовать только после выбора владельцем; команды остаются локальными |
| Android-действия | `PhoneCommands`, `AppCatalog`, `PhoneActionEngine/Core`, медиасессии и проверка результата | Не выполнять произвольный текст ответа/`tool_calls` без отдельной политики разрешений |
| Настольные модели | `core/providers.py`: Ollama, совместимые API, отдельный `core/chatgpt.py` | Не менять работающие настольные адаптеры |
| ChatGPT на ПК | PKCE, динамическая регистрация, проверка ID token/JWKS, плановая scope, OS keyring | Не читать пользовательский Codex/Chrome профиль. Для VPS нужен собственный зашифрованный vault и отдельный цикл входа |
| Мобильный шлюз ПК | `core/mobile.py`: частные IPv4/VPN, TLS pinning, 48443, связь с desktop runtime | Не превращать этот порт в публичный VPS API. Создать независимое приложение Gateway |
| Общий runtime | Python 3.12, FastAPI, httpx, pydantic, cryptography уже доступны | Gateway можно отделить без нового тяжёлого runtime и постоянно запущенного браузера |
| Проверки | pytest, JVM-пробы Android, SDK instrumentation, Gradle/lint | Добавить изолированные mock/provider и реальные HTTP/SSE проверки; отдельно отмечать реальные аккаунты |

## Границы реализации

Gateway не наследует права настольного процесса, не получает файловую систему ПК,
не открывает мобильный шлюз 48443 в интернет и не читает существующие секреты.
Авторизация клиента Gateway отделена от авторизации провайдера. Каждый аккаунт и
диалог принадлежат владельцу токена Gateway. Удалённые расширения автоматически
не загружаются и не исполняются.

Текущий Android APK 0.9.0 собран и проверен на хосте; USB перед установкой был
отключён. Физическая проверка нового Gateway-клиента требует восстановления ADB
либо отдельного Android-устройства. Отсутствие телефона не мешает HTTP/SSE-тестам
сервера и сборке приложения.
